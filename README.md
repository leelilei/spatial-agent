# Research Workspace

This repository is organized as a research monorepo. Each numbered directory is an independent project workspace.

## Projects

- `1-SpatialAgent/`: empirical SpatialAgent project and shared spatial-agent research assets.
- `2-GAME-AGENT/`: game-agent environment prototype and evaluation scripts.
- `3-SMGA/`: SMGA proposal, experiments, benchmarks, and paper workspace.
- `4-SpatialAgent-Survey/`: SpatialAgent survey/scoping-review workspace.
- `5-Chinese-ASR-Compression/`: cross-architecture Chinese ASR compression research plan.

## Repository Notes

- Project-specific code, plans, papers, and results stay inside their project directory.
- Temporary files, caches, local settings, and run logs are ignored at the repository root.
- Large generated artifacts should be reviewed before committing.
