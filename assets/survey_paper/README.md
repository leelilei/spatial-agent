# Survey Paper Collection

用于维护当前 survey 写作、筛选和背景综述资料。

## 目录说明

- `phase1/`
  当前 Phase 1 检索、筛选、复核与判定文件。
- `pdfs/phase1_core/`
  Phase 1 Core corpus 正式归档。
- `pdfs/phase1_adjacent/`
  Phase 1 Adjacent corpus 正式归档。
- `pdfs/phase1_foundational/`
  Phase 1 Foundational corpus 正式归档。
- `pdfs/phase1_placeholders/`
  失败下载得到的 HTML 占位文件。
- `pdfs/review_library/`
  与当前主题相关的综述、scoping review 写法参考，以及对应表格索引。
- `reading_notes/`
  已做的精读笔记。
