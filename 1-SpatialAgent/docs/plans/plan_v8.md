## 第零部分：单一核心贡献声明

### 本研究的主要贡献

**Primary Contribution (唯一主张)**:  
结构化空间表征（inspired by Space Syntax）能够系统性地改变 LLM Agent 的行为模式，且这种改变的一部分沿着空间理论预测的方向发生。

**Supporting Contributions (支撑机制，不独立成为主张)**:
1. `C6m/C6f/C4` 分解揭示效应进入管道的位置（到位后认知 vs Movement vs Sampling）
2. `BSR/TAR` 双指标区分"响应存在性"与"理论对齐性"
3. MIC 设计作为方差控制工具

**Not Claimed as Primary**:
- 完整验证 Space Syntax 理论
- 证明文本 Agent 等价于物理空间人类
- 建立通用的长时程 Agent 实验方法论
- 证明所有社会涌现由空间构型决定

### 论文的核心问题

**单一核心问题**:  
当 LLM Agent 被提供结构化的空间描述时，它们的行为是否会系统性地响应这些描述，且响应方向是否部分符合空间理论预期？

**不是本文核心问题**:
- Space Syntax 在文本世界中是否完全成立？（过强）
- 哪种空间表征格式最优？（工程问题）
- 长时程模拟是否收敛？（方法论问题）

## 第一部分：研究动机与理论定位

### 1.1 问题的起源

现有 LLM Agent 研究通常较好建模了两类信息：
- **WHO**：身份、人格、目标、背景
- **WHAT**：事件、记忆、任务与互动历史

但对第三类信息的系统建模仍然不足：
- **WHERE**：空间构型、深度、可达性、瓶颈性

本研究关注的不是"有没有地点信息"，而是是否存在**构型级空间表征**对行为的系统性影响。

### 1.2 三个理论跳跃与本研究的定位

| 跳跃 | 从 → 到 | 本研究的立场 |
|------|---------|-------------|
| 跳跃1 | 真实人类 → LLM Agent | **本研究主要检验此跳跃**：LLM 是否习得空间-行为关联 |
| 跳跃2 | 物理空间 → 文本化空间 | **本研究需论证此跳跃的合理性**（见 1.3） |
| 跳跃3 | 个体行为 → 群体涌现 | **不作为主论文必要条件**，降级为可选扩展 |

### 1.3 为什么文本化空间描述可能保留因果机制？（新增节，回应 Review1-Major#1）

**核心论证**:

Space Syntax 的核心不是物理感知本身，而是**拓扑关系对行为可能性的约束**。这种约束可以通过符号化描述传递，只要描述保留了关键的结构信息。

**三层论证**:

1. **抽象性论证**：  
   Space Syntax 指标（Integration, Depth, Control）本身就是抽象的拓扑度量，不依赖具体的物理尺度、材质或视觉细节。它们描述的是"位置在网络中的结构角色"。这种角色可以通过语言传达。

2. **类比论证**：  
   人类在阅读建筑平面图、文字描述或导航指令时，也能形成空间心智模型并据此做出行为推断（"这是死胡同" → "不适合逃生路线"）。LLM 的训练语料中包含大量此类空间-行为关联的文本。

3. **实证前提**：  
   本研究的预实验包含"空间理解门控"（comprehension ≥85%）和"空间推理测试"（behavioral inference ≥70%），确保模型能从文本描述中提取结构信息并做出合理推断。

**承认的局限**:

- 文本描述无法完全复现物理空间的 embodied affordance（如视线、声音传播、身体舒适度）
- 本研究检验的是"LLM 是否习得了空间-行为的语言关联"，而不是"LLM 是否进行了真正的空间推理"
- 因此本研究定位为 **proof of concept**，而非 Space Syntax 的完整验证

**如果这一论证不成立会怎样？**

即使文本化空间无法保留 Space Syntax 的因果机制，本研究仍有价值：它揭示了 LLM 在多大程度上习得了人类关于空间-行为关联的常识。这对于设计更可信的 Agent 系统仍然重要。

## 第二部分：研究问题与主张边界

### 2.1 研究问题（简化版）

**RQ1（验证性，核心）**：  
结构化空间表征是否比基线条件（无空间、地点名、行为 affordance）更能诱发空间响应行为？

**RQ2（验证性，核心）**：  
这种响应中有多少沿着 Space Syntax 理论方向发生？

**RQ3（验证性，机制）**：  
效应主要来自到位后认知、Movement 决策，还是 Action Sampling？

**RQ4（探索性）**：  
效应更接近结构性推理还是语义常识激活？

### 2.2 主张边界

**本研究尝试支撑的结论**:
- 结构化空间表征可以系统性影响 LLM Agent 行为
- 这种影响在关键比较中超出行为 affordance 基线
- 其中有一部分影响沿着 Space Syntax 理论方向发生

**本研究不预先声称**:
- 完整验证 Space Syntax
- 证明文本 Agent 等价于物理空间人类
- 排除所有中小效应的不存在
- 证明单一空间指标具有跨环境普适性

**检测目标**:  
本研究主要检测**中到大效应**（d ≥ 0.5），不试图穷尽性排除小效应。

## 第三部分：理论框架与指标（简化版）

### 3.1 三个假设（保持不变）

#### H1：Integration 与社交频率
高 Integration 位置 → 更多主动接触、停留、公开互动

#### H2：Mean Depth 与私密行为
高 Mean Depth（深层）位置 → 更多低声交流、敏感信息分享

#### H3：Control Value 与守门行为
高 Control 位置 → 更多巡视、拦截、信息筛选行为

### 3.2 主因变量：BSR 与 TAR（简化呈现）

**主文只报告一对核心指标**:

#### BSR (Behavioral Spatial Responsiveness)
衡量：行为是否随空间特征系统性变化（不区分方向）

#### TAR (Theory-Aligned Responsiveness)  
衡量：变化是否沿理论预测方向发生

**其他指标变体（entropy, hypothesis-specific BSR, 时间窗口分析）全部移至附录**

### 3.3 TAR_run 计算 protocol（保持 v7 的显式定义）

1. 按 location 聚合行为率（访问次数 ≥5）
2. 计算 location-level Spearman 相关
3. Fisher z 变换生成 run-level 标量
4. 正值 = 理论对齐，负值 = 反向，零 = 无方向性

## 第四部分：核心实验设计（简化版）

### 4.1 设计原则（回应 Review2-Major#3）

**Stage 2 是论文的绝对中心**:
- Stage 1 仅用于证明表征有效性
- Stage 3 是可选扩展，不影响主结论
- 人类评估是主要结果之一，不是可选项

### 4.2 核心条件（简化为 3+2）

#### 主要对比条件

| 条件 | Movement 信息 | 对话空间描述 | Sampling | 用途 |
|------|---------------|--------------|----------|------|
| **C1 Topology-Only** | 邻接 + 地名 + 在场数 | 无 | 无 | 主基线 |
| **C2 Behavioral Affordance** | 同 C1 | 行为 affordance 描述 | 无 | 行为启动基线 |
| **C4 Full Spatial** | 空间指标 + 邻接 + 地名 | Absolute Structural | 有 | 完整系统 |

#### 机制分解条件（仅用于分解，不作为独立主张）

| 条件 | 用途 |
|------|------|
| **C6m Perception-Matched-Movement** | 分离到位后认知效应 |
| **C6f Perception-Free-Movement** | 分离 Movement 贡献 |

**分解逻辑**:
```
C4 - C1 = 总系统效应
  = (C6m - C1)  # 到位后认知
  + (C6f - C6m) # Movement 贡献
  + (C4 - C6f)  # Sampling 贡献
```

### 4.3 C2 的重新定义（回应 Review1-Major#2）

**v8 的诚实表述**:

C2 不再声称是"非空间控制"，而是：
> **行为 affordance 基线**：提供直接的行为启动线索，但不提供结构性空间信息

**承认的问题**:
- 在真实环境中，affordance 与空间结构本质上耦合
- C2 提供的是"现象学"线索，C6m 提供的是"结构性"信息
- C6m > C2 可能反映"间接 vs 直接行为提示"，而非"空间 vs 非空间"

**新增 C2b**（补充对照）:
- 描述非空间的结构性特征（"此房间有 3 扇窗、2 扇门、木地板"）
- 测试是否"结构性描述格式"本身就能产生效应

**解释策略**:
- 若 C6m > C2 且 C6m > C2b：支持空间结构信息的独特作用
- 若 C2 > C6m：说明直接行为启动比结构推理更有效（仍是有价值的发现）
- 若 C2b ≈ C6m：说明效应可能来自"结构性描述"的格式，而非空间内容

### 4.4 样本量与地图设计（回应两个 review 共识）

#### Stage 2 核心设计

**地图**: 3 张（Plaza, Labyrinth, Bridge）  
**MIC seeds**: 20 per map  
**条件**: 5 个（C1, C2, C6m, C6f, C4）  
**轮次**: 200-300（由收敛 pilot 决定）  
**NPC**: 10

**总运行数**: 20 seeds × 3 maps × 5 conditions = 300 runs

**理由**:
- 减少 seeds（30→20）：Review 共识认为 MIC 价值有限
- 增加 maps（1→3）：跨地图泛化比 seed blocking 更有科学价值
- 在 Stage 2 而非 Stage 3 做多地图：使跨地图泛化成为验证性证据

#### 功效重估

按 20 seeds、保守独立组估计：
- 最小可检测效应：d ≥ 0.82
- 这符合"只检测中到大效应"的定位

若考虑 MIC 的早期方差缩减（ICC ≈ 0.1-0.2），实际功效可能略高，但不依赖此假设。

## 第七部分：结果-主张决策矩阵（新增，回应 Review2-Major#4）

### 7.1 为什么需要此矩阵？

预注册解释逻辑，避免事后合理化。明确在不同结果模式下，论文可以（和不可以）主张什么。

### 7.2 主要结果模式与对应主张

#### 模式 1：完全成功
**结果**: C4 > C1 显著，BSR 显著，TAR 显著且正向，人类偏好 C4  
**可主张**: 结构化空间表征系统性改变行为，且部分沿理论方向  
**论文定位**: 强证据论文

#### 模式 2：响应存在但方向弱
**结果**: C4 > C1 显著，BSR 显著，但 TAR 弱或不稳定  
**可主张**: 空间表征改变行为，但不一定沿 Space Syntax 方向  
**论文定位**: 表征有效性论文，理论对齐作为开放问题

#### 模式 3：机制不清晰
**结果**: C4 > C1 显著，但 C6m/C6f 不能清晰分离  
**可主张**: 完整系统有效，但效应来源需进一步研究  
**论文定位**: 系统级证据，机制作为 future work

#### 模式 4：仅早期窗口有效
**结果**: 前 50 轮显著，后期衰减  
**可主张**: 空间信息作为 priming 有效，但被记忆吸收  
**论文定位**: 时间动态论文，讨论记忆-空间交互

#### 模式 5：C2 强于 C6m
**结果**: C2 > C6m  
**可主张**: 直接行为启动比结构推理更有效（仍是有价值发现）  
**论文定位**: affordance vs structure 论文

#### 模式 6：Stage 1 强但 Stage 2 弱
**结果**: 微任务中 C4 > baselines，但长时程模拟中效应消失  
**可主张**: 空间表征在短期任务中有效，但长期模拟中被稀释  
**论文定位**: 任务复杂度调节论文

#### 模式 7：零效应
**结果**: 所有主要比较均不显著  
**可主张**: 当前形式的结构化空间表征不足以改变 LLM Agent 行为  
**论文定位**: 零结果论文（仍可发表，对领域有价值）

### 7.3 不允许的事后解释

无论结果如何，以下解释**不被允许**（因为未预注册）:
- "效应虽小但理论上重要"（除非预先定义了小效应的理论意义）
- "某个未预注册的子群体中效应显著"（除非有先验理论预测）
- "虽然主效应不显著，但交互项显著"（除非交互项是预注册假设）

- 至少一个主比较FDR-corrected p < 0.05且d ≥ 0.5

## 附录A：详细技术规格（保留v7精华）

### A.1 TAR_run完整计算protocol

**Step 1**: 事件级到location-level汇总
- 每个run中，按location聚合行为
- 只保留访问次数≥5的location
- 计算行为率（如sociality_rate, privacy_rate）

**Step 2**: Location-level单调关联
```
rho_H1 = Spearman(sociality_rate, standardized_Integration)
rho_H2 = Spearman(privacy_rate, standardized_MeanDepth)
rho_H3 = Spearman(gatekeeping_rate, standardized_Control)
```

**Step 3**: Fisher z变换
```
TAR_Hk_run = atanh(rho_Hk_run)
```

**Step 4**: BSR计算
```
BSR_Hk_run = abs(TAR_Hk_run)
```

### A.2 编码信度protocol

**Coding manual**: 包含定义、边界案例、正反例  
**Pilot coding**: 200-300样本，双人独立编码  
**信度阈值**: 
- 行为类型 κ ≥ 0.70
- 交互强度 κ ≥ 0.67
- 信息敏感度 κ ≥ 0.67
- 守门行为 κ ≥ 0.60

**LLM-human校准**: 若某维度κ < 0.60，该维度不进入主结果

### A.3 MIC有效窗口预检

比较matched vs unmatched条件差异方差：
```
ICC(seed) = Var_between_seeds / (Var_between_seeds + Var_within_seeds)
```

报告0-50、51-100、101-200三个窗口的ICC。

5. **增强**: 人类评估升级，Llama鲁棒性检验

**v8的定位**: 一个聚焦、诚实、可执行的proof-of-concept研究，而非试图一次性解决所有问题的宏大计划。
