## 第零部分：单一核心贡献与边界

### 0.1 本研究的唯一主贡献

**Primary Contribution**:  
提出并验证一种结构化空间表征方案（inspired by Space Syntax），检验其是否能够系统性改变 LLM Agent 的行为模式，并使其中一部分行为变化沿着空间理论预测的方向发生。

**关键限定**:
- 本研究检验的是"结构化空间描述对 LLM Agent 行为的影响"
- 不声称验证 Space Syntax 在物理空间中的完整理论
- 不声称文本 Agent 等价于 embodied human
- 定位为 **proof of concept**，而非理论完备验证

### 0.2 核心研究问题（单一且明确）

**Primary Research Question**:  
当 LLM Agent 被提供结构化的空间描述时，它们的行为是否会系统性地响应这些描述，且响应方向是否部分符合空间理论预期？

**不是本研究的核心问题**:
- Space Syntax 是否在所有环境中成立？
- 哪种表征格式最优？
- 文本推理是否等价于物理空间推理？

### 0.3 可支撑的主张

本研究尝试支撑：
- 结构化空间表征可以系统性影响 LLM Agent 行为
- 这种影响在关键比较中超出控制基线
- 其中一部分影响沿着理论预测方向发生
- **且这种影响具有实践可辨识性**（人类评估）

### 0.4 不支撑的主张

本研究不预先支撑：
- Space Syntax 已被完整验证
- 文本 Agent 已等价于物理环境中的人类
- 单一空间指标具有跨环境普适性
- 所有未显著结果都可解释为功效不足

## 第一部分：理论定位与有效性论证（强化版）

### 1.1 三个理论跳跃

| 跳跃 | 从 → 到 | v9 的处理方式 |
|------|---------|--------------|
| 跳跃1 | 真实人类 → LLM Agent | **主要检验对象**：LLM 是否习得空间-行为关联 |
| 跳跃2 | 物理空间 → 文本化空间 | **需明确论证 + 实证检验**（见 1.2-1.4） |
| 跳跃3 | 个体行为 → 群体涌现 | 可选扩展，不作为主论文前提 |

### 1.2 文本化空间的理论论证（保留 v8.2）

Space Syntax 的核心是**位置在拓扑网络中的结构角色**，而非物理感知本身。这种角色可以通过符号化描述传递。

**三层论证**:
1. **抽象性**: Integration、Depth、Control 本身是抽象网络度量
2. **认知类比**: 人类可从平面图、文字描述形成空间心智模型
3. **方法验证**: 通过理解门控与推理测试确认模型能力

**承认的局限**:
- 文本不能复现 embodied affordance
- 可能更接近"语言化常识"而非"真实空间推理"
- 因此定位为 proof of concept

### 1.3 区分"空间推理"与"语言关联"（v9 新增，回应三个 review）

**核心问题**（Review1-Major#1, Review2-Major#1）:  
即使 LLM 对空间描述产生响应，也可能只是从训练数据中学到的语言模式复现，而非真正的结构推理。

**v9 的解决方案：双重检验**

#### 检验 1：空间推理任务（Novel Inference Test）

在预实验中，测试模型是否能从空间描述中做出**未在训练数据中直接出现的推断**。

**任务设计**:
```
给定: "位置 A 的平均拓扑距离为 1.2 步，位置 B 为 2.8 步"
问题: "如果一个角色想要快速接触多个其他角色，应该选择哪个位置？"
```

**通过标准**: 准确率 ≥ 75%

**解释**:
- 若通过：说明模型能从结构描述中推断行为适配性
- 若不通过：说明模型缺乏基本空间推理能力，主实验结果将被降级解释

#### 检验 2：反刻板印象条件（Counter-Stereotypical Condition）

在 Stage 1 中新增条件 `C_counter`：

**设计**: 空间描述结构上正确，但语义标签与典型关联相反
- 例如：高 Integration 位置 + "适合私密对话"的语义标签
- 例如：高 Depth 位置 + "适合公开社交"的语义标签

**预测**:
- 若 Agent 主要依赖**结构推理**：行为应跟随结构特征
- 若 Agent 主要依赖**语义刻板印象**：行为应跟随语义标签

**解释规则**:
| 结果模式 | 解释 |
|---------|------|
| 行为跟随结构 > 语义 | 支持结构推理假设 |
| 行为跟随语义 > 结构 | 主要是语言关联，非结构推理 |
| 两者混合 | 部分推理 + 部分关联 |

### 1.4 理论有效性的分层解释框架（v9 新增）

根据上述两个检验的结果，v9 建立分层解释框架：

**Tier 1（最强）**: 空间推理主导
- Novel Inference Test 通过
- Counter-Stereotypical 条件中行为跟随结构
- 主实验中 TAR 显著且正向
- **可主张**: LLM 具备一定程度的结构化空间推理能力

**Tier 2（中等）**: 混合机制
- Novel Inference Test 通过
- Counter-Stereotypical 条件中结构与语义混合
- 主实验中 TAR 显著但不稳定
- **可主张**: LLM 部分依赖结构推理，部分依赖语言关联

**Tier 3（弱）**: 语言关联主导
- Novel Inference Test 未通过或勉强通过
- Counter-Stereotypical 条件中行为跟随语义
- 主实验中 BSR 显著但 TAR 弱
- **可主张**: LLM 主要通过训练数据中的语言关联响应空间描述

**Tier 4（零效应）**: 无系统性响应
- 所有检验均不显著
- **可主张**: 当前形式的空间表征不足以改变行为

## 第二部分：控制条件的重新设计（回应 Review1-Major#2 & Review2-Major#2）

### 2.1 控制条件的根本问题

v8.2 的 C2 被定义为"行为 affordance 基线"，但两个 review 指出：
- affordance 与空间结构本质上耦合
- "适合安静交流"本身就是对高 Depth 空间的现象学描述
- C2 vs C6m 比较的不是"空间 vs 非空间"，而是"隐式 vs 显式"

### 2.2 v9 的控制条件矩阵（重新设计）

| 条件 | Movement 信息 | 到位后描述 | Sampling | 角色 |
|------|---------------|-----------|----------|------|
| **C1 Topology-Only** | 邻接 + 地名 + 在场数 | 无 | 无 | 最小基线 |
| **C2 Implicit Spatial** | 同 C1 | 隐式空间编码（affordance 描述） | 无 | 隐式空间基线 |
| **C2b Non-Spatial Structural** | 同 C1 | 非空间结构特征（窗、门、材质） | 无 | 结构格式控制 |
| **C2c Truly Non-Spatial** | 同 C1 | 时间模式或社会规范描述 | 无 | 真正非空间控制 |
| **C6m Explicit Spatial (Matched-Mvmt)** | 同 C1 | 显式空间结构描述 | 无 | 显式空间基线 |
| **C6f Explicit Spatial (Free-Mvmt)** | 空间指标 + 邻接 | 显式空间结构描述 | 无 | Movement 贡献 |
| **C4 Full System** | 同 C6f | 显式空间结构描述 | 有 | 完整系统 |

### 2.3 控制条件的诚实定位

**v9 明确承认**:
- C2 不是"非空间控制"，而是"隐式空间编码"
- C2 vs C6m 比较的是**编码方式**（隐式 vs 显式），而非空间 vs 非空间
- C2c 才是真正的非空间控制

### 2.4 C2c 的设计（新增）

**时间模式描述**:
- "此位置通常在上午较为繁忙"
- "此位置在傍晚时段人流较少"

**社会规范描述**:
- "此位置的人们倾向于保持正式礼节"
- "此位置的氛围较为轻松随意"

**关键特征**:
- 不包含空间结构信息（显式或隐式）
- 仍然可行动（提供行为线索）
- 与位置随机映射，run 内固定

### 2.5 主要比较的重新解释

| 比较 | v8.2 解释 | v9 解释 |
|------|----------|---------|
| C6m vs C1 | 空间 vs 无空间 | 显式空间 vs 最小基线 |
| C6m vs C2 | 结构 vs affordance | 显式空间 vs 隐式空间 |
| C6m vs C2b | 空间结构 vs 非空间结构 | 空间内容 vs 非空间内容（格式相似） |
| C6m vs C2c | 空间 vs 非空间 | 空间 vs 真正非空间 |

### 2.6 解释规则（更新）

| 结果模式 | 解释 |
|---------|------|
| C6m > C2 且 C6m > C2c | 空间信息（显式或隐式）优于非空间信息 |
| C6m > C2c 但 C2 > C6m | 隐式空间编码比显式更有效 |
| C2b ≈ C6m | 效应可能来自结构化描述格式，而非空间内容 |
| C2c > C6m | 非空间线索比空间线索更强（需严肃讨论） |

## 第三部分：实践意义阈值（回应 Review2-Major#3）

### 3.1 问题陈述

Review2 指出：即使 d = 0.5 统计显著，也可能不足以证明在实际应用中值得增加 Space Syntax 计算的复杂度。

### 3.2 实践意义阈值矩阵

| 效应量 | 人类辨别 | 模型一致性 | 实践意义判断 |
|--------|---------|-----------|-------------|
| d ≥ 0.8 | 人类可辨别 | 跨模型一致 | **强实践意义** - 值得实现 |
| d ≥ 0.8 | 人类可辨别 | 模型特异 | **中等意义** - 需考虑模型选择 |
| d ≥ 0.8 | 人类不可辨别 | - | **弱意义** - 统计显著但感知不明显 |
| 0.5 ≤ d < 0.8 | 人类可辨别 | 跨模型一致 | **中等意义** - 可能值得实现 |
| 0.5 ≤ d < 0.8 | 人类不可辨别 | - | **边界意义** - 需成本收益分析 |
| d < 0.5 | - | - | **无实践意义** - 不推荐实现 |

### 3.3 成本-收益框架

**实现成本**:
- 计算 Space Syntax 指标（Integration, Depth, Control）
- 生成结构化描述
- 集成到 Agent 架构

**预期收益**:
- 行为可信度提升
- 空间适配性改善
- 社会互动模式更真实

**决策规则**:
- 若 d ≥ 0.8 且人类可辨别：收益明确超过成本
- 若 0.5 ≤ d < 0.8：需根据具体应用场景判断
- 若 d < 0.5：成本可能超过收益

### 3.4 与现有实践的比较

**当前游戏/模拟系统**:
- 使用语义标签（"tavern", "throne room"）
- 这些标签隐含空间-行为关联

**本研究的增量价值**:
- 显式 Space Syntax 指标是否比语义标签更有效？
- 增量效应需达到 d ≥ 0.5 才值得额外实现

## 第四部分：地图设计与泛化（回应 Review2-Major#4）

### 4.1 v8.2 的局限

三张设计良好的图（Plaza, Labyrinth, Bridge）可能无法充分测试泛化性：
- 都是精心设计的环境
- 节点数较少（~20）
- 结构清晰

### 4.2 v9 的地图矩阵（4 张图）

| 地图 | 类型 | 节点数 | 结构特征 | 作用 |
|------|------|--------|---------|------|
| **Plaza** | 设计良好 | 20 | 高 Integration 集中 | 主验证图 |
| **Labyrinth** | 设计良好 | 20 | 高 Depth, 低 Connectivity | 深层空间测试 |
| **Bridge** | 设计良好 | 20 | 明显瓶颈 | Control 测试 |
| **Irregular** | 程序生成/不规则 | 25-30 | 混合结构，指标分布不均 | 泛化测试 |

### 4.3 Irregular 地图的设计原则

**生成方式**:
- 程序生成（如 Voronoi 图 + 随机连接）
- 或模拟真实游戏世界的不规则布局

**关键特征**:
- 指标分布不如设计图清晰
- 存在结构异常节点
- 更接近真实应用场景

**预期**:
- 若效应在 Irregular 图上仍显著：支持泛化性
- 若效应仅在设计图上显著：说明依赖理想化结构

### 4.4 样本量调整

**Stage 2 设计**:
- 4 maps × 15 seeds × 7 conditions = 420 runs
- 从 v8.2 的 300 runs 增加到 420 runs

**理由**:
- 增加 1 张图 + 2 个控制条件（C2c, C_counter）
- 减少 seeds（20→15）以控制总成本

## 第六部分：人类评估完整 Protocol（回应 Review1-Major#5 & Review2-Major#6）

### 6.1 招募与参与者

**招募方式**: 在线众包平台（Prolific 或国内等价平台）

**参与者标准**:
- 年龄 18-65
- 流利中文/英文
- 通过注意力检查
- 无色盲（若涉及视觉材料）

**样本量**: 60 人（比 v8.2 的 50 人增加）

**功效分析**: 
- 辨别任务（配对比较）
- 预期效应量 d = 0.5
- α = 0.05, power = 0.80
- 需要 n ≥ 52（保守取 60）

### 6.2 任务设计

#### 任务 1：可信度评分（Between-Subjects）

**材料**:
- 每个参与者评估 20 个行为片段
- 片段来自不同条件，参与者间平衡
- 每个片段包含：位置描述 + Agent 行为 + 上下文

**评分维度**:
- Believability (1-7)
- Spatial Appropriateness (1-7)

**盲法**: 参与者不知道条件标签

#### 任务 2：辨别任务（Within-Subjects）

**材料**:
- 每个参与者看 15 对行为（C4 vs C1）
- 每对来自相同场景和位置
- 顺序随机化

**问题**: "哪个行为更符合该空间情境？"

**分析**: 配对 t 检验，检验偏好比例是否显著偏离 50%

#### 任务 3：Judge 校准

**材料**: 200 个行为样本的子集

**流程**:
1. 人类评分（双人独立）
2. LLM Judge 评分
3. 计算 Cohen's kappa

**阈值**: κ ≥ 0.60

### 6.3 数据质量控制

**注意力检查**: 3 个 catch trials

**排除标准**:
- 未通过注意力检查
- 完成时间过短（< 10 分钟）
- 方差过低（所有评分相同）

**信度**: 报告 Cronbach's α（内部一致性）

## 第七部分：统计分析路径规范化（回应 Review1-Major#3）

**分析单元**: run-level（每个 seed × map × condition 为一个数据点）

| # | 对比 | 因变量 | 分析单元 | 模型 | 多重校正 | 成功标准 |
|---|------|--------|---------|------|---------|---------|
| **1** | C4 vs C1 | TAR_H1_run | run | Mixed model | 无（主分析） | p < 0.05, d ≥ 0.5 |

## 第八部分：次要问题的规范化

### 8.1 H3 的预注册阈值（回应 Review2-Minor#7）

**最低节点阈值**: 
- H3 仅在高 Control 节点数 ≥ 5 时进行确认性检验
- 若 < 5 个节点，H3 降级为描述性观察

**备选分析**: 若节点不足，改用二分类比较（高 vs 低 Control）

### 8.2 时间动态的预注册预测（回应 Review2-Minor#8）

**Spatial Priming 模式**:
- 前 50 轮效应强（d ≥ 0.6）
- 后期衰减至 d ≤ 0.3
- 解释：空间信息作为初始启动，后被记忆吸收

**Sustained Guidance 模式**:
- 前 50 轮与全程效应量相近（差异 < 20%）
- 解释：空间信息持续影响决策

**预测**: 更可能观察到 Priming 模式

### 8.3 MIC 有效性验证（回应 Review2-Minor#9）

**独立 pilot 数据集**:
- 5 seeds × 2 maps × 2 conditions
- 专门用于 MIC 有效性检验
- 不进入主分析

**报告**: 三个时间窗口的 ICC(seed)

## 第十三部分：失败模式与应对（回应 Review2-Missing#11）

### 13.1 跨 seed 高变异

**模式**: 效应在某些 seeds 强，某些 seeds 弱

**应对**: 
- 报告效应量的 95% CI
- 检查是否与特定 NPC 组合相关
- 不做过度泛化主张

### 13.2 Agent 人格依赖

**模式**: 效应仅在特定人格类型（如高社交性）中显著

**应对**:
- 报告为调节效应
- 讨论空间表征对不同 Agent 类型的适用性

### 13.3 小效应（d = 0.2-0.3）

**模式**: 统计显著但效应量小

**应对**:
- 按"无实践意义"处理
- 不上升为主结论
