# 研究计划

## 研究问题 (Research Questions)
- RQ1: 空间感知（基于 Space Syntax）能否提升 LLM Agent 行为的空间合理性？
- RQ2: 不同空间构型如何影响多 Agent 系统中的社会行为涌现？
- RQ3: 哪些 Space Syntax 指标对 Agent 行为影响最大？

## 核心假设
- H1: 高 Integration 区域 → Agent 社交互动频率更高
- H2: 低 Visual Depth 区域 → Agent 更倾向透露秘密信息
- H3: 高 Control Value 节点 → Agent 更容易涌现领导者角色
- H4: 空间 Connectivity 分布 → 影响信息传播速度
- H5: 空间构型整体差异 → 导致不同的社会涌现模式

## 方法概述
1. 构建基于 Space Syntax 的空间计算模块
2. 设计空间感知 Agent 架构（SpatialAgent）
3. 在三种不同空间构型中运行多 Agent 模拟
4. 通过自动评估和人类评估验证假设

## 时间线
