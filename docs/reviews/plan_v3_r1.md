# SpatialAgent Research Plan v3 审稿式评审总结

> 评审对象：`../plans/plan_v3.md`
> 评审视角：AAMAS / AAAI 匿名审稿人
> 评审立场：严格但建设性，关注可发表性、识别质量与执行可信度

---

## 一、总体判断

`v3` 是一次非常成熟的方法学收口。和 `v2` 相比，你不是简单“加更多实验”，而是在系统修补最危险的识别漏洞：

- 把评估从“规则表直接判适配”改成“两阶段分离评估”
- 用“信息访问矩阵”明确各条件到底能看到什么
- 正面引入 `Judge-Only`
- 用反直觉空间条件去碰触“理论验证 vs 常识激活”这个最核心的问题
- 补上了 `MVP` 路线，避免整个计划被阶段3拖死

从专业审稿角度看，`v3` 已经不再像一份“概念很好但容易被打穿”的 proposal，而更像一份**有明确投稿潜力的论文蓝图**。

但新的问题也很清楚：你现在最大的风险已经不是“idea 不成立”，而是**方案过度复杂后，主比较是否依然干净、统计论证是否自洽、工程范围是否开始侵蚀论文主线**。

### 审稿结论

- 如果这是一个研究计划：**Weak Accept / 强烈建议推进**
- 如果这是一份准备直接落成顶会论文的方法蓝图：**Major Revision**

原因不是它不强，而是它已经进入最后一层方法学打磨阶段，任何一个小的不自洽点都会被严厉审稿人放大。

---

## 二、最重要的五个问题

## 1. 功效分析与“独立样本单位”的定义仍然没有完全对齐

这是我认为 `v3` 当前最需要优先修正的问题。

你在 `6.3` 里写了：

- 独立样本单位以 `run` 为核心
- 全流程使用 `Mixed-Effects Model`

但在 `6.4` 的功效分析里，你又通过 `200` 轮和 `ICC` 去推导“每组有效样本约为 `66`”。这在统计叙述上会让审稿人立刻警觉，因为它容易被理解为：

> 你一方面说 `run` 才是独立样本，另一方面又在功效分析里部分借用了 `run` 内重复观测来扩充有效样本。

这会被质疑为两种样本单位逻辑混用。

### 为什么这是关键问题

- 如果真正的独立样本是 `run`，那 `20 runs / cell` 对阶段3的交互效应仍可能偏弱
- 如果你打算使用事件级数据增强功效，就必须更明确地建模时间相关性、同一 agent 的重复行为、同一 pair 的依赖结构
- 目前的写法容易被看作“统计上合理，但论证上不够防守”

### 建议

- 明确区分两类分析：
  - `run-level confirmatory analysis`
  - `event-level exploratory analysis`
- 对主假设检验坚持以 `run` 或 `run-aggregated metric` 为主
- 把事件级模型写成补充分析，而不是隐含地参与主功效论证
- 如果保留当前 `ICC` 推导，需要更明确说明该推导对应的是哪一类 `DV`

如果这一点不收紧，审稿人会认为你的统计计划“很复杂”，但不一定“很稳”。

---

## 2. `RQ2` 的核心比较仍然没有完全分离“空间表征效应”与“动作选择机制效应”

`v3` 比 `v2` 大幅进步的一点是你终于给出了信息访问矩阵。但在主实验 `Exp2` 中，`C1 Topology-Only` 和 `C4 SpatialAgent-Lite` 的差异依然不只一层。

当前两者至少同时不同于：

- Actor 是否能看到空间指标
- 对话时是否注入空间描述
- 是否使用 `Spatial Action Sampling`

也就是说，当你在主结果中看到 `C4 > C1` 时，严格来说你证明的是：

> 完整空间化架构优于 topology-only 架构

而不一定能直接证明：

> 仅仅空间结构化表征本身造成了差异

### 为什么这会影响主张

因为 `Perception` 和 `Action Sampling` 都可能单独制造行为偏移。虽然你后面加入了 `JudgeOnly`、`Perception-Only` 和 `Rule-Based Scorer`，这是正确方向，但它们现在更像“补充消融”，而不是支撑 `RQ2` 主结论的核心对照。

### 建议

- 在论文主叙事里，把 `RQ2` 的表述改成更保守的：
  - “空间化认知架构的增量效应”
  - 而不是更窄的“空间表征本身的认知效应”
- 或者把 `Perception-Only vs Topology-Only` 上升为主比较之一
- 确保正文最核心图表中，能直接看到：
  - `Topology-Only`
  - `Perception-Only`
  - `JudgeOnly`
  - `Full`

否则审稿人会认为你虽然补了很多控制，但主结论仍然来自一个混合处理。

---

## 3. 反直觉空间条件是对的，但目前更像“冲突提示词实验”，还不完全是“理论归因实验”

`Exp1C` 是 `v3` 最聪明的新增内容之一，我非常支持保留。但按当前写法，它仍有一个识别层面的风险：

当你同时给出：

- 高 `Integration` 的结构事实
- “偏僻小巷”这样的语义标签

模型面对的是**矛盾线索**。这时它的输出可能反映的不是“更相信 Space Syntax 还是更相信常识”，而是：

- 更偏好哪类文本线索
- 更服从标签词还是数值描述
- 更受 prompt 顺序、表述强度、措辞显著性影响

换句话说，这个实验当前最直接测到的，可能是**冲突信息条件下的提示词支配关系**，而不是纯粹的理论归因。

### 建议

把 `Exp1C` 进一步做成显式的因子设计，而不只是几个冲突场景：

- `topology high / low`
- `semantic label public / private`

形成至少一个 `2 x 2` 设计。

然后分别比较：

- 仅拓扑
- 仅标签
- 拓扑与标签一致
- 拓扑与标签冲突

这样你才能更清楚地估计：

- 拓扑信号主效应
- 语义标签主效应
- 两者交互效应

如果不这么做，`RQ4` 很有价值，但还不够“可识别”。

---

## 4. `Exp3-Minimal` 的目标非常好，但在 `20` 节点图上未证明可操作

你现在把 `Exp3-Minimal` 从点缀升级成系统操控实验，这是正确的方向。但我仍然担心它在当前图规模上会遇到现实困难：

- 只修改 `1-2` 条边就想让目标指标变化 `±1σ`
- 同时要求其他指标变化 `< 0.5σ`
- 还要保证整体连通性与地图可解释性

对于只有 `20` 个节点的手工图，这个约束可能过于乐观。

### 为什么这是潜在问题

- 如果最后能生成的有效变体很少，`Exp3-Minimal` 会退化为少数作者挑选的例子
- 如果其他指标总是一起变化，那么“最小差异对”就仍然不是最小差异
- 审稿人会怀疑这是一个写得很漂亮、但未必真能跑通的设计

### 建议

- 在正式计划里加一句更强的执行前提：
  - 先做小规模地图生成 pilot
  - 证明每类操控至少确实能产出 `>= 5` 个合格实例
- 如果 pilot 失败，应提前准备降级方案：
  - 把 `Exp3-Minimal` 改成描述性证据
  - 主论文只保留最稳定的一类操控

目前 `v3` 写得像它已经肯定能做出来，但从审稿视角，我还需要看到“可生成性”的先验证据。

---

## 5. 方案已经开始出现“过度控制导致主线分散”的风险

这是 `v3` 相比 `v2` 新出现的问题。

你现在同时想完成：

- 表征格式比较
- `Openness` vs `Mean Depth` 决策
- `Schema` vs 自然语言格式
- `Temperature` 敏感性
- `encounter probability` 敏感性
- `JudgeOnly`
- `Rule-Based Scorer`
- 反直觉条件
- 三阶段主实验
- `Exp3-Minimal`
- 人类评估

这在方法上当然很完整，但也开始逼近一个危险区间：

> 你可能最终做出的是一套非常完整的研究计划，却不是一篇主线足够集中的论文。

### 我的担忧

- 正文页数放不下这么多“都重要”的实验
- 每个实验都变成略讲一点，反而削弱主证据链
- 实际执行中，最先牺牲的往往是最花时间但理论最重要的部分

### 建议

尽早明确论文主 spine，只保留一条最可 defend 的主链：

1. 阶段1：哪种空间表征真正有效
2. 阶段2：空间化架构是否优于 topology-only
3. `RQ4`：这种效应更接近结构理论还是语义常识

如果这三条能成立，论文已经够强。`Exp3` 和大规模人类评估更适合作为增强项，而不是让全文失焦的主负担。

## 三、主要优点

### 1. 评估协议终于真正摆脱了“把理论写回评分标准”的问题

`6.1` 的两阶段分离评估是 `v3` 最重要的改进之一。先盲标行为，再做空间关联分析，这在逻辑上明显优于 `v2` 的适配规则表。它不能彻底消除解释争议，但已经把最明显的循环定义风险降下来了。

### 2. 信息访问矩阵是全文最有说服力的澄清工具

这是一个非常好的写法。因为审稿人真正关心的不是你“口头上说 topology-only”，而是：

- 它到底看到了什么
- 在哪个决策层看到
- 哪一步用了空间信息

`v3` 终于把这一层说清了，这会显著提高 `RQ2` 的可 defend 性。

### 3. 你开始真正把“负面结果”纳入主设计，而不是作为口头退路

`MVP` 路线、`JudgeOnly`、`反直觉条件` 都说明你已经接受：

- 有些结果可能不会支持原本最强的理论叙事
- 但它们依然可以形成有价值的论文

这对顶会方法论文非常重要。

### 4. 理论姿态明显更成熟

第三个理论跳跃的加入很必要。你不再直接默认“个体空间行为差异”自然会累积成“群体社会涌现”，而是把这一步也作为待验证对象。这个姿态更稳。

### 5. `Absolute Structural` 取代 `Neutral Structural` 作为主方案是正确的

这一改动虽然看起来小，但很重要。因为百分位本身就带有相对比较语义，容易被模型直接当作“这个地方更中心”的结论信号。改成绝对事实后，主方案确实更干净。

## 四、次要问题

### 1. `Rule-Based Scorer` 不能自动解决归因问题

它确实能去掉第二个 LLM 的先验偏见，但也会重新引入另一种问题：

> 你手工写的规则，是否又把作者预期重新编码回了系统？

因此它更适合作为鲁棒性对照，而不应自动升级为“更客观”的主方案。

### 2. `Schema` 格式虽然紧凑，但也可能损伤行为推理自然性

你把它作为备选是对的，但不要默认它一定优于自然语言。很多模型对紧凑 schema 的事实抽取更强，但对行为推理未必更好。建议把评价指标拆成：

- 事实理解准确率
- 行为推理一致性
- token 成本

而不是只看一个综合表现。

### 3. `常驻 / 访问` 状态值得保留，但不要过早扩张成新变量

这是一个很好的理论细节，但如果你进一步让它进入主实验，就会再新增一个交互因素。更稳妥的做法是：

- 先作为上下文注释或 exploratory factor
- 不要在首篇论文里把它扩成主要假设

### 4. 人类评估仍然需要一个更明确的“失败也有价值”的定位

如果自动指标支持方法，而人类评估不支持，你需要提前定义如何解释：

- 是方法不 believable
- 还是人类直觉与 Space Syntax 预测本来就有张力

这件事 `v3` 已经有所意识，但还可以写得更前置一些。

## 五、我会给出的评分

以下评分按“顶会审稿人阅读研究计划 / 论文蓝图”的标准给出。

| 维度 | 评分（5分制） | 评语 |
|------|--------------|------|
| 新颖性 | 4.6/5 | 跨 Space Syntax 与 LLM multi-agent 的结合仍然很有辨识度 |
| 问题重要性 | 4.3/5 | 问题真实，且兼具游戏AI、Agent建模与空间理论价值 |
| 方法清晰度 | 4.2/5 | 比 `v2` 更清楚，但主比较仍有少量混合处理问题 |
| 评估严谨性 | 4.1/5 | 已显著提升，但统计功效与主对照解释还需再收口 |
| 理论扎实度 | 4.0/5 | 理论对话明显成熟，但 `RQ4` 识别还可以更干净 |
| 可执行性 | 3.4/5 | 最大短板在这里：方案已非常大，存在范围膨胀风险 |

### 综合判断

`v3` 是一个**明显强于 `v2` 的版本**。如果 `v2` 的问题是“容易被打穿”，那 `v3` 的问题则变成了“太想把所有洞一次补完”。这是一种更高级的问题，也意味着你的计划已经走到了值得认真实现的阶段。

## 六、最优先修改建议

如果只允许我给三条最高优先级建议，我会给这三条：

### 1. 重新收紧功效分析叙述

把 `run-level` 与 `event-level` 分析彻底分开，避免样本单位混用。

### 2. 把 `RQ2` 的主结论改写为“空间化架构增量效应”

除非你愿意把 `Perception-Only` 抬升为主比较之一，否则不要把主结论写得比设计实际能支持的更窄、更强。

### 3. 把 `Exp1C` 改成因子化设计

不要只做若干“矛盾场景”，而要能显式估计拓扑信号与语义标签的主效应和交互效应。

---

## 七、最终结论

从专业审稿角度看，`v3` 已经达到了一个很好的节点：**核心方法论漏洞基本都被你主动识别并开始修补**。这很难得。很多 proposal 到这个阶段仍在试图“把故事讲得更大”，而你是在认真让识别更干净、对照更透明、失败路径更可发表。

我对 `v3` 的总体评价是积极的，但这种积极不是“已经完全 ready”，而是：

> 它已经足够强，值得进入实现；但要想成为一篇真正强的顶会论文，还需要最后一轮“减法式”的方法收口。

如果你下一步继续扩内容，我会担心项目失焦；如果你下一步开始做减法，把主证据链压缩得更锋利，我会显著看好这篇工作的可投稿性。

**一句话总结：`v3` 的主要问题已经不再是“想法够不够好”，而是“如何在不继续膨胀的前提下，把最关键的三条证据链做得足够硬”。**
