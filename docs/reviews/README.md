# Reviews Index

本目录存放两类评审材料。

## 文件说明

- `reviewer_challenge_report_v1.md` 到 `reviewer_challenge_report_v4.md`
  - 独立的 reviewer challenge 报告，按版本号递增。
- `spatial_agent_research_plan_v*_review_*.md`
  - 对特定 research plan 版本的评审稿。
  - 命名中的最后一个数字表示同一版本下的第几轮 review。

## 建议阅读顺序

1. `reviewer_challenge_report_v4.md`
2. `spatial_agent_research_plan_v6_review_2.md`
3. 如需追溯，再看更早版本 review
