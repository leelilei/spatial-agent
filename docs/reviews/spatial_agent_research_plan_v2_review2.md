## 一、总体评价

V2 相比 V1 有脱胎换骨的改进：主张从"首次证明因果"收缩为"提供控制性证据"，核心模块从 4 个精简到 2 个以利于归因，baseline 从 1 个扩充到 6 个梯度化对照，实验从平行设计改为三阶段递进验证。这些修改直接回应了 V1 的主要批评，显示出作者具有较强的自我审视和方法论反思能力。

然而，在肯定整体框架进步的同时，本评审将聚焦于**尚未被充分讨论的深层方法论问题**。这些问题不构成致命缺陷，但若不在论文中正面处理，将成为挑剔审稿人的有效攻击面。

## 二、主要优势（Major Strengths）

### S1. 严谨的因果识别策略
三阶段递进设计（机制验证 → 行为效应 → 社会涌现）加上"前一阶段不通过则不进入下一阶段"的门控逻辑，是方法论上的亮点。特别是 Topology-Only Agent 的设计——控制移动策略一致、仅剥离对话时的空间信息——巧妙地分离了拓扑必然效应与认知效应，这是全文实验设计的灵魂。

### S2. 梯度化 Baseline 体系
6 条件设计（No Space / Name Only / Rich Non-Spatial / Raw Numeric / Neutral Structural / Shuffled Signal）构成了一条完整的证据链。尤其是 C2（Rich Non-Spatial）和 C5（Shuffled Signal）分别排除了"任何额外信息都有效"和"随机空间信息即可"两种替代解释。

### S3. 表征风格消融（Exp1B）
将 Neutral Structural 与 Interpretive（v1 风格）进行对比，正面回应"循环论证/prompt 泄漏"的批评。更重要的是，计划中坦诚声明"如果 Interpretive 优于 Neutral 但 Neutral 不优于 Name Only，则需诚实报告负面发现"——这种学术诚信是加分项。

### S4. 投稿策略调整
从 AAAI 转向 AAMAS 作为首选目标会议，这一判断是正确的。AAMAS 社区对多 Agent 社会模拟和涌现行为有更深的理解，能更准确地评估本工作的方法论贡献。

### S5. 假设表述的修订
H1-H4 的修订显著改善了可证伪性。特别是 H2 从单因子单方向改为双因子交互假设（Openness × Connectivity），H3 从"领导者"修正为"守门人/中介者"，H5 降级为探索性目标——这些调整都更符合 Space Syntax 理论本身的精度。

## 三、主要问题（Major Concerns）

### C1. 构念效度问题：Openness 对 Visual Depth 的替代是否成立？

**问题核心**：V2 将物理空间中的 Visual Depth（基于 isovist/视域分析）重新定义为图模型中的 Openness（可视节点比例）。这一简化在 20 节点的离散图中存在严重的构念效度（construct validity）风险。

**具体隐患**：
- 在物理空间中，Visual Depth 是连续的、方向敏感的、受几何遮挡影响的度量；而 Openness 是离散的、无方向的、仅受拓扑遮挡影响的二值函数的求和。二者之间的理论等价性缺乏论证。
- 在 20 节点的小图中，Openness 极易与 Connectivity 高度共线（r > 0.8 的可能性很高），因为直接相连的节点通常也是可见的。虽然计划提到"如 r > 0.8 则合并讨论"，但这一合并将直接导致 H2（依赖 Openness）失去独立的检验能力。
- 文中提到"含有视线遮挡的图中两者可以显著不同"，但 20 节点图中能设计出多少条"弯曲走廊"？如何系统性地定义文本世界中的"视线遮挡"？这需要明确的操作化规则。

**建议**：
1. 在预实验阶段，先计算三种构型中 Openness 与 Connectivity 的实际相关系数。如果确实 r > 0.8，应提前考虑备选方案——例如改用 **Mean Depth**（平均拓扑深度）替代 Openness，作为"隐蔽程度"的操作化指标。
2. 在论文中明确讨论此替代的理论代价，不能仅用一句"坦诚承认"带过。应回答：如果 Openness ≠ Visual Depth，那么 H2 中关于"隐私敏感行为"的理论依据是否依然成立？

### C2. Spatial Action Sampling 的循环论证风险

**问题核心**：Spatial Action Sampling 模块使用一个独立的 Judge LLM 评估候选行为与空间条件的"匹配度"（SpatialFitness）。但 Judge 的评分标准本身就依赖于 LLM 对"什么行为在什么空间中合理"的先验知识。

**循环论证链**：
```
Space Syntax 理论 → 空间描述（Neutral Structural）→ Actor LLM 生成候选行为
                                                     ↓
Judge LLM 评估"空间匹配度" ← Judge 的先验知识（来自训练数据中的人类空间行为模式）
```

如果 Judge 的评分本质上反映的是"LLM 认为人类在该空间中会怎么做"，那么最终行为表现出的空间一致性可能来自 **LLM 共享的训练数据偏见**，而非 Space Syntax 理论的指导。这使得 SpatialAgent 的表现优势无法被明确归因于空间结构化表征还是 LLM 的固有空间常识。

**建议**：
1. 在消融实验（Exp2-Ablation）中增加一个关键条件：**Judge-Only**——不注入任何空间描述给 Actor，但仍让 Judge 基于空间信息对候选行为打分。如果 Judge-Only 接近 Full SpatialAgent 的表现，说明效果主要来自 Judge 的先验知识，而非 Perception 模块。
2. 考虑一个替代的 Judge 设计：使用**基于规则的评分器**（即 6.1 节中定义的空间-行为适配规则表），而非第二个 LLM。这可以完全排除 Judge 引入的 LLM 偏见。

### C3. 20 节点图的统计功效与 Space Syntax 理论适用性

**问题核心**：经典 Space Syntax 研究通常处理的是数百甚至数千条轴线的城市级别图。在 20 节点的小图上，Integration、Control Value 等指标的分布范围极窄，节点间的差异可能不足以产生可检测的行为效应。

**具体隐患**：
- Integration 的 denominators 范围仅为 19 到 19×max_depth，在 20 节点图中区分度有限。
- Control Value 在节点度数普遍较低的小图中容易饱和（大多数节点的 Control Value 在 0.5-2.0 之间）。
- H3（高 Control Value → 守门人角色）需要图中存在明显的拓扑瓶颈，但 20 节点图中瓶颈节点数量可能只有 1-2 个，样本量不足以做统计推断。

**建议**：
1. 在论文的 3.3 节中，不仅报告相关矩阵，还应报告每种构型中各指标的 **分布直方图和变异系数（CV）**。如果某指标 CV < 0.2，说明在该构型中该指标几乎没有区分力，对应的假设检验应标注为"不适用"。
2. 考虑是否需要在至少一种构型中增加节点数（如 30-40 个），以确保有足够的 high/low 极端节点支撑假设检验。这会增加计算成本，但比在 20 节点上做出不可靠的推断更好。
3. 对 H3（守门人假设），给出定量的样本量论证：在三种构型中分别有多少个"高 Control Value"节点？如果每种构型只有 1-2 个，该假设事实上不可检验。

### C4. 缺乏正式的统计功效分析（Power Analysis）

**问题核心**：计划声明 n≥15 runs，使用 Mixed-Effects Model，但未给出任何功效分析的依据。

**关键缺失**：
- 期望效应量是多少？Cohen's d = 0.3（小效应）还是 0.8（大效应）？这直接决定了所需样本量。
- 对于 Mixed-Effects Model，还需要考虑组内相关系数（ICC）。如果同一 run 内的轮次高度相关（ICC > 0.5），实际有效样本量远小于 15 × 200 = 3,000。
- 阶段 3 的 2×3 设计（agent_type × layout）有 6 个 cell，如果每 cell 只有 15 个 run，交互效应的检测力可能不足。

**建议**：
1. 至少做一个简易的功效分析：假设 Cohen's d = 0.5（中等效应），α = 0.05，power = 0.8，双侧检验，所需每组样本量约 64。这意味着 n=15 只有在 ICC 很低或效应很大时才够用。
2. 如果正式功效分析表明 n=15 不够，可以考虑增加 runs 或者在论文中声明"本研究为探索性研究，统计结果将报告效应量和置信区间，不仅依赖 p 值"。

### C5. Space Syntax 理论验证 vs. LLM 空间常识激活——无法区分的根本困境

**问题核心**：这是本研究面临的最深层方法论挑战，在 V2 的理论框架中虽有提及（3.1 节末尾），但讨论深度不够。

即使所有实验结果完美支持 H1-H4，仍存在两种不可区分的解释：

**解释 A（Space Syntax 理论在虚拟 Agent 中成立）**：空间构型的社会效应具有超越物理实体的普遍性，即使在文本世界中也能塑造 Agent 行为。

**解释 B（LLM 训练数据中的空间-社会常识被激活）**：LLM 在海量文本中学到了"人在开阔地方更社交"、"人在隐蔽处更放松"等常识。Neutral Structural 描述仅仅是激活了这些已有知识，与 Space Syntax 理论本身无关——用日常语言描述同样的空间特征可能产生相同效果。

V2 在 3.1 节末尾提到这一问题，但仅声明"将在 Discussion 中讨论"。这不够。一个可操作的实验设计可以帮助区分两种解释。

**建议**：
1. 增加一个**反直觉空间条件**作为关键测试：设计一个空间场景，其中 Space Syntax 理论的预测与日常直觉相反。例如：一个拓扑上高度 Integrated 但被描述为"偏僻小巷"的节点（即空间拓扑结构与语义标签矛盾）。观察 Agent 是遵循拓扑指标还是语义标签——如果遵循前者，支持解释 A；如果遵循后者，支持解释 B。
2. 这个测试可以集成到阶段 1 的 Exp1A 中，成本不高但理论价值巨大。

## 四、次要问题（Minor Concerns）

### C6. Rich Non-Spatial Baseline（C2）的设计需要更多细节

C2 条件要求提供"等长度非空间描述（天气、历史、NPC 衣着）"。但如果这些描述内容**不具有行为引导性**（如干巴巴的历史介绍），LLM 会自动忽略它们，使 C2 沦为一个过弱的稻草人（straw man）。

C2 的描述应包含**同样具有行为可供性（affordance）的非空间信息**。例如："这个区域弥漫着刺鼻的硫磺气味，空气中悬浮着肉眼可见的黑色颗粒" → 可能引导回避行为；"周围传来欢快的音乐和嬉笑声" → 可能引导社交行为。只有 C2 同样能引导行为但引导的方向与空间特征不同，C4 > C2 的结论才有说服力。

### C7. 路径偶遇概率的参数敏感性

移动模型中"50% 概率与在场 Agent 产生短暂交互"是一个硬编码超参数，但在 Labyrinth 这类串联通道密集的构型中，该参数对社交网络密度的影响可能是非线性的。

**建议**：在预实验或附录中报告 encounter probability = {0.2, 0.5, 0.8} 三个水平下的关键指标敏感性分析。

### C8. Judge-Actor 模型差异引入的混淆

使用不同模型作为 Actor（Qwen-Max）和 Judge（GPT-4o）可以避免同模型偏好问题，但引入了新的混淆：两个模型的空间-社会知识结构可能不同。如果 Judge（GPT-4o）的空间理解能力比 Actor（Qwen-Max）更强或更弱，会系统性地高估或低估 SpatialFitness。

**建议**：报告 Judge 的内部一致性（同一输入多次评分的标准差），以及两个 Judge（GPT-4o 和 DeepSeek-V3）之间的一致性（Cohen's κ）。如果 κ < 0.6，需要讨论 Judge 可靠性不足的问题。

### C9. 人类评估的空间认知偏差

40-50 名被试通过简化示意图理解空间关系，然后评估 Agent 行为是否"符合所处位置的特点"。但被试自身对空间-行为关系的理解可能与 Space Syntax 的理论预测不一致（例如，普通人可能认为"走廊"就应该是"快速通过的地方"，而 Space Syntax 可能将某些走廊识别为高 Integration 的社交热点）。

**建议**：
- 在被试人口学数据中增加"空间推理能力"的简短测试（如 Mental Rotation Test 的缩短版）
- 按空间推理能力分组，分析评分是否存在交互效应

### C10. 时间线的可行性风险

从 3 月下旬到 7 月投稿，共约 4 个月。其中需要完成：文献精读、引擎搭建、三个阶段的实验（预计 10 周）、人类评估（2 周）、论文撰写（4 周）。计划中每个阶段有"决策点"（如果失败需要调整方案），但调整方案本身需要额外时间。如果阶段 1 在第 5 周失败并需要调整表征方案，整个时间线将被压缩到不可行的程度。

**建议**：明确一个"最低可投稿版本"（minimum viable paper）：即使阶段 3 的涌现分析不完整，阶段 1 + 阶段 2 的结果是否足够支撑一篇有价值的论文？如果是，这可以作为保底方案。

## 五、具体章节评论

### 第一部分（研究背景）

- **1.2 节**的空白界定比 V1 精确了很多。特别是将"空间盲"修正为"缺乏构型级空间认知"，并承认 Generative Agents 有语义标签级的空间意识——这一区分是重要的。
- **1.3 节**两个理论跳跃的声明很好，但建议加入第三个跳跃的讨论：**从个体空间行为 → 群体社会涌现**。Space Syntax 的实证主要是关于个体行人流的（natural movement），将其推广到多 Agent 社会涌现是一个额外的、未被充分论证的跳跃。

### 第三部分（理论框架）

- **3.1 节**与 Hillier 的理论对话是正确的方向，但当前讨论仍偏浅。建议增加对 Hillier **"空间句法二元性"（inhabitants vs. visitors / 居民 vs. 访客）**的讨论——这一区分在 Agent 模拟中是否有对应物？例如，"常驻"在某区域的 Agent 与"路过"的 Agent 是否应有不同的空间认知输入？

### 第四部分（技术架构）

- **4.2 节** Neutral Structural 描述中使用百分位排名（"在所有位置中排第 X 百分位"）看似客观，但实际上已经隐含了"比较"的语义——Agent 可能据此推断"这个位置比大多数位置更容易到达"。一个真正中立的描述应该只给出绝对数值或绝对事实，不做任何相对比较。建议在 Exp1B 中增加一个"Absolute-Only"条件（只给绝对数值，不给百分位），以检验排名信息本身的影响。
- **4.3 节** temperature 参数的选择未讨论。temperature 过低退化为 argmax（空间完全决定行为），过高退化为均匀采样（空间无影响）。建议报告 temperature 的选择逻辑和敏感性。

### 第五部分（实验设计）

- **阶段 1** 微任务设计很好，特别是"位置选择"和"停留/离开"两个任务直接对应空间决策，比"秘密透露"更能测试空间理解。
- **阶段 2** 的 150,000 次调用量意味着每次完整实验约需 10,000 次调用（10 Agent × 200 轮 × 5 行为/轮）。这里隐含了一个假设：每 Agent 每轮产生约 1 次有效 LLM 调用。需要确认是否准确，或是否有额外的 Judge 调用。
- **阶段 3** 的最小差异对实验（Exp3-Minimal）是亮点，但操作细节需要补充：对 A 中"将中心广场拆为两个小广场"如何保证"其他控制不变"？节点分裂必然改变部分节点的 Connectivity 和 Control Value。

### 第六部分（评估体系）

- **6.1 节**从开放评分改为结构化行为标注是重要改进。但预定义的"空间-行为适配规则表"本身是研究者的主观判断，等于在评估中引入了先验假设。建议在论文中讨论：这些规则的理论依据是什么？是否可以让独立的建筑学研究者验证规则表的合理性？

### 第九部分（资源预算）

- 混合方案（阶段 1-2 用 DeepSeek，阶段 3 用 Qwen-Max）引入了跨阶段的模型混淆。如果阶段 2 中 SpatialAgent > Topology-Only 的效应在 DeepSeek 上成立，但阶段 3 切换到 Qwen-Max 后效应变大或变小，无法判断是构型效应还是模型切换的结果。**建议全流程使用同一模型**，或至少在阶段 3 中同时跑 DeepSeek 作为复现检查。

## 六、缺失的讨论点

以下议题建议在论文的 Discussion 或 Limitation 部分正面讨论：

1. **模型泛化性**：所有结论是否仅适用于特定 LLM（如 Qwen-Max）？不同 LLM 的空间推理能力差异可能导致结果不可复现。
2. **世界主题泛化性**：中世纪奇幻 RPG 是一个空间线索丰富的主题。如果换成现代办公室场景或科幻空间站，结论是否成立？
3. **Agent 数量的影响**：10 个 Agent 在 20 节点上的密度约为 0.5 Agent/节点。如果增加到 50 Agent 或减少到 5 Agent，空间效应是否变化？
4. **长期适应效应**：200 轮是否足够长，以观察 Agent 社交网络的稳态？是否需要报告网络指标随轮次的收敛曲线？
5. **与 Embodied AI 文献的对话**：论文结构草案中提到了 2.4 节"Embodied AI / Spatial Reasoning in LLMs"，但正文中对此讨论几乎为零。建议与 SpatialVLM、SQA3D 等空间推理 benchmark 建立联系。

| **P3（锦上添花）** | C7-C10：参数敏感性、Judge 一致性、被试筛选、保底方案 | 方法论完备性 |

### 最终判断

本研究计划展示了一个具有真正创新性的跨学科研究议程。V2 的实验设计在多 Agent 社会模拟文献中属于上乘水平。最大的方法论薄弱点在于**无法区分 Space Syntax 理论验证与 LLM 空间常识激活**（C5），这一问题不解决的话，论文的理论贡献将大打折扣——它将从"Space Syntax 在虚拟 Agent 中成立"降级为"LLM 可以被空间描述 prompt 影响行为"，后者的新颖性和理论深度远不及前者。

建议作者在正式开展实验前，将 C5 中提出的"反直觉空间条件"纳入阶段 1 的实验设计，这将使论文的理论贡献从"interesting"提升到"insightful"。
