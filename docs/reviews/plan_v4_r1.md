# SpatialAgent Research Plan v4 审稿式评审总结

> 评审对象：`../plans/plan_v4.md`
> 评审视角：AAMAS / AAAI 匿名审稿人
> 评审立场：严格但建设性，关注理论可辩护性、识别干净度与投稿可执行性

---

## 一、总体判断

`v4` 是目前为止最成熟、也最接近“可投稿方法蓝图”的版本。与 `v3` 相比，这一版最重要的进步，不是又新增了几个实验，而是你开始真正做**减法式收口**：

- 把 `RQ2` 明确改写为“空间化架构增量效应”
- 把 `Perception-Only` 升格为主比较条件
- 把 `Exp1C` 从“几个冲突场景”改成显式 `2×2` 因子设计
- 把 `run-level` 与 `event-level` 统计分析硬性分层
- 把 NPC 角色设计、位置随机化、时间收敛性这些此前隐性的内部效度问题显式写进方法部分
- 把核心证据链、增强证据、探索性扩展分层

从专业审稿视角看，`v4` 已经不再是“一个很有意思的 idea”，而是一份**开始具备投稿级自我防守能力**的研究计划。

但也正因为它现在已经接近论文级蓝图，剩下的问题会更集中地暴露在“主因变量是否定义得足够硬”“验证性分析是否真的有足够功效”“某些控制条件是否引入了新的人工性”这几个层面。

### 审稿结论

- 作为研究计划：**Weak Accept / 强烈建议继续推进**
- 作为会议论文方法蓝图：**Borderline Accept 到 Major Revision 之间**

如果接下来还能再做一轮收紧，我会明显看好它的投稿潜力。

---

## 二、最重要的四个问题

## 1. `BSR` 的构念比 `BSC` 更好，但主因变量仍然偏“存在性”而非“理论方向性”

把 `BSC` 改成 `BSR` 是 `v4` 的一个非常正确的修正。因为你现在的两阶段分离评估，测到的确实更接近“行为是否随空间特征系统性变化”，而不是“是否符合某个预定义的一致性标准”。

但新问题是：当前 `BSR` 的主操作化仍然偏向**是否有响应**，而不是**是否按理论预测方向响应**。

你现在的主要 DV 包括：

- 行为分布是否随空间特征系统性变化
- 交互模式差异
- 指标与行为的偏相关强度

这很好，但存在一个重要风险：

> 一个条件完全可能表现出很强的空间响应性，却沿着与 `H1-H3` 相反的方向变化。

比如：

- 高 `Integration` 节点上行为确实变化了
- 但不是更社交，而是更警觉或更回避

从 `BSR` 看，这依然是“强响应”；但从 Space Syntax 理论验证角度看，这其实是**负向证据**。

### 为什么这是关键问题

- 如果主结果图只强调“响应性更强”，摘要中很容易被误读为“理论得到支持”
- 但你真正想主张的并不是“空间信息会影响行为”，而是“某些结构化空间特征会沿可解释方向地影响行为”
- 若方向性不被单独凸显，`Space Syntax` 的理论含量就会再次被稀释成一般性的 context effect

### 建议

- 把主要 DV 明确拆成两层：
  - `unsigned responsiveness`
  - `signed theory-aligned responsiveness`
- 在正文主结果中，不能只报告 `BSR` 强弱，还要同步报告：
  - 方向是否与 `H1-H3` 的推导表一致
  - 若不一致，是理论失效还是角色/语义标签/任务条件覆盖了理论
- 最稳妥的写法是：将“方向正确率”或“按假设方向的效应量”升级为主表之一，而不是只放在辅助分析里

目前 `v4` 已经把“有无响应”讲清楚了，但“响应是否支持理论”还可以再硬一点。

---

## 2. Run-Level 验证性分析虽然更干净，但 `d ≥ 0.91` 的可检测门槛过高，会直接限制主结论强度

`v4` 在统计论证上比 `v3` 更诚实，也更专业。你终于明确写出了：

- 主结论只基于 `run-level`
- `event-level` 只作为探索性补充
- `20 runs/cell` 在验证性层面只能可靠检测大效应

这是优点，不是缺点。

但从审稿角度看，新的问题是：

> 当验证性分析只能检测 `d ≥ 0.91` 这类大效应时，你的“未显著”几乎不能被解读为“无效应”，而只能解读为“未检测到大效应”。

这会对论文定位产生直接影响。因为如果你在摘要或贡献里仍然使用接近确认性的措辞，审稿人会立刻反问：

> 你真的有能力验证这些假设吗，还是你只是能发现极强效应？

### 为什么这是关键问题

- 这不仅影响统计显著性，更影响 claim 的语气边界
- 阶段2如果 Run-Level 不显著、Event-Level 显著，你其实更接近一篇 `pilot / methodological study`
- 阶段3本来又是探索性的，那整篇论文的“强验证”部分可能只剩阶段1的一部分比较

### 建议

- 在总目标和贡献表述里进一步降调：
  - 用 `tests for large, policy-relevant effects`
  - 而不是笼统地说 `tests whether`
- 认真考虑两个替代方案之一：
  1. 缩减主条件数，换取更多 `runs/cell`
  2. 保持当前规模，但把论文明确定位为 `pilot + methodology`
- 如果资源允许，最值得加样本的不是阶段3，而是阶段2核心链：
  - `C1`
  - `C4a`
  - `C6`
  - `C5`

因为真正支撑主论文的，其实就是这几个条件。

换句话说，`v4` 现在的统计框架是诚实的，但它也诚实地暴露出：**你的确认性证据仍然偏贵、偏稀缺。**

## 3. `C2 Rich Non-Spatial` 虽已与位置解耦，但“每轮随机抽取描述”可能把基线变成高噪声条件，而不是强对照条件

`v4` 对 `C2` 的修正是对的。你看到了 `v3` 的问题：如果作者手写的非空间描述与位置特征存在系统关联，那 `C2` 根本不是独立基线。

所以你现在改成：

- 预先写 20 条非空间描述
- 每轮、每位置随机抽取
- 引导方向长期均匀

这解决了“与空间耦合”的问题，但又引入了另一个问题：

> 这个 `C2` 现在更像“动态噪声注入条件”，不再像一个稳定的、可比较的替代信息源条件。

### 为什么这会成为审稿攻击点

- 同一位置在相邻轮次收到完全不同的氛围描述，可能破坏场景连贯性
- LLM 可能把这种频繁变化解读为世界本身不稳定，而不是额外上下文
- 如果 `C2` 的效果被噪声稀释，你最终证明的可能只是：
  - 稳定结构信息优于高频随机扰动
  - 而不是空间结构信息优于非空间但同样可行动的信息

### 建议

- 把 `C2` 的随机化粒度调粗：
  - 优先按 `run-level per location` 随机
  - 或至少按 `episode/block-level` 固定，而不是每轮变化
- 维持“与空间解耦”，但让非空间描述在一个 run 内具有局部稳定性
- 最好的表述是：
  - `C2 provides persistent non-spatial affordance context, randomized across runs but stable within run`

这样你得到的是一个更强、更公平的对照，而不是一个人为加噪的弱对照。

## 4. `Exp1C` 的因子设计已经成立，但语义标签操控仍可能混入情感价和叙事脚本，而不仅是“公/私”维度

`v4` 在 `Exp1C` 上的升级很大，基本回应了 `v3` 最关键的一个问题。现在你终于能显式估计：

- 拓扑主效应
- 语义标签主效应
- 交互效应

这很好。

但新的剩余问题是：你给出的语义标签例子，比如：

- `偏僻小巷`
- `废弃地窖`
- `开放露台`
- `光明大厅`

这些词不只操控“公共 / 私密”，还同时操控了：

- 安全感
- 明亮度
- 氛围
- 危险感
- 叙事脚本联想

也就是说，你的 `semantic_label` 因子现在不是一个纯粹的“public/private semantics”操作，而更像一个**高维语义包**。

### 为什么这是问题

- 如果模型在 `废弃地窖` 中更谨慎，不一定是因为“私密性”
- 也可能因为“危险 / 肮脏 / 阴暗 / 可疑”
- 这会让你对 `RQ4` 的解释再次变宽

### 建议

- 在正式实验前对语义标签做一个小型 lexical norming：
  - 让人类或独立 LLM 标注每个标签的 `publicness`, `privacy`, `danger`, `warmth`, `valence`
- 选出那些在“公/私”维度上区分明显、但在其他情感维度上差异尽量小的标签
- 或者把标签直接改成更中性的功能称谓：
  - `公共区域`
  - `内部区域`
  - `中央节点`
  - `深层节点`

如果你想保留叙事味道，那就至少需要证明这些词主要在你要操控的维度上分离。

## 三、主要优点

### 1. 理论链终于从“引用 Space Syntax”升级到了“显式推导 Space Syntax”

`2.4` 的假设推导表是 `v4` 最重要的理论升级之一。它把每个假设拆成：

- Hillier 原始理论
- 物理空间实证
- 文本 Agent 推导
- 失效条件

这非常关键。因为直到 `v3`，`Space Syntax` 仍然部分像一个理论标签；到 `v4`，它开始变成真正进入假设结构的理论来源。

### 2. NPC 角色设计与位置随机化补上了此前最危险的内部效度盲点

这是 `v4` 非常大的进步。此前最容易被忽略、但实际上最致命的问题之一，就是：

> 你测到的是空间效应，还是角色-位置耦合？

现在你至少正面处理了：

- 角色维度标准化
- 初始位置随机化
- 前5轮敏感性分析
- 角色协变量入模

这使得阶段2的内部效度明显更可信。

### 3. 时间动态与收敛性分析让阶段3终于不再建立在“200轮应该够了”的默认假设上

这也是一个关键进步。你现在至少承认：

- 社交网络是动态对象
- 200轮不是天然合理的
- 需要稳态判据和分段比较

这让阶段3即便仍然是探索性的，也比之前更像真正的动态系统研究。

### 4. 核心 / 增强 / 探索性分层非常正确

这会显著提升可投稿性。因为你终于不再试图让所有实验都承担同等权重，而是开始明确：

- 什么是正文必须讲清楚的
- 什么是增强机制解释的
- 什么是如果时间允许再展开的

这是从“做研究计划”走向“写论文”的关键一步。

### 5. `Fixed-Path` 作为机制探测条件是聪明的

虽然它不能完全给出纯粹的因果分离，但它是一个很有价值的机制探针。至少它会帮助你回答：

- 效应有多少来自位置选择
- 有多少来自到达同一位置后的行为差异

这对 `Discussion` 很有帮助。

## 四、次要问题

### 1. `Rule-Based Scorer` 的定位已经摆正，但可以更明确地弱化其篇幅占比

你已经正确地把它降成鲁棒性对照，而不是“更客观方案”。建议在正文中只保留一句方法说明和一张附录对照表，不要让它继续占据主叙事空间。

### 2. `Bridge` 构型比 `Grid` 更合理，但地图三元组仍应避免“命名即结论”

现在三种图的指标意图更明确了，这是好事。但在写作中仍要避免让名称本身带结论，比如 `Plaza = 中心化`、`Labyrinth = 私密化`。最好强调是**指标分布**定义构型，而不是名字定义构型。

### 3. “排除前5轮”最好预先固定，而不是结果导向决定

你已经说会报告包含/排除前5轮的差异，这是好的。建议更进一步：在方法里写清楚“主分析默认排除前5轮，附录报告全量结果”，避免被怀疑是事后挑选窗口。

### 4. 行为熵很有价值，但不要让它取代行为适配方向分析

行为熵回答的是“更丰富还是更刻板”，这很好；但它不等于“更 spatially believable”。建议始终把它放在辅助结果区，而不是让它和主 DV 并列竞争解释权。

## 五、评分

以下评分按“顶会审稿人阅读研究计划 / 论文蓝图”的标准给出。

| 维度 | 评分（5分制） | 评语 |
|------|--------------|------|
| 新颖性 | 4.6/5 | Space Syntax 与 LLM multi-agent 的结合依然很有辨识度 |
| 理论扎实度 | 4.3/5 | 假设推导表是显著进步，但理论方向性 DV 还可更清晰 |
| 方法严谨性 | 4.3/5 | 角色随机化、双层统计、收敛分析都很强；仍有少数构念与基线问题 |
| 评估设计 | 4.2/5 | 两阶段分离评估和主线分层较成熟，但 `C2` 和 `Exp1C` 还有最后一轮打磨空间 |
| 可执行性 | 3.6/5 | 比 `v3` 更收敛，但总体工程量仍大，验证性功效仍偏紧 |
| 投稿潜力 | 4.2/5 | 已进入“值得认真实现”的区间，关键在于后续是否继续做减法 |

### 综合判断

`v4` 是一个**明显强于 `v3` 的版本**。如果说 `v3` 的核心问题是“太想把所有漏洞一次补完”，那 `v4` 已经开始学会：

- 哪些东西必须讲
- 哪些东西应当降级
- 哪些局限性需要提前承认

这使它第一次真正接近一篇可 defend 的顶会方法论文。

## 六、三条最高优先级修改建议

### 1. 给 `BSR` 配一个明确的“理论方向性”主指标

不要只测是否响应，还要测是否按 `H1-H3` 的预测方向响应。

### 2. 重新设计 `C2` 的随机化粒度

保持与位置解耦，但不要每轮随机；改成 run 内稳定、run 间随机，会是更强的公平基线。

### 3. 对 `Exp1C` 的语义标签做预标定

确保你操控的是“公/私语义”，而不是一整包危险感、明亮度和叙事脚本。

---

## 七、最终结论

从专业审稿角度看，`v4` 已经表现出很强的研究成熟度。它最可贵的地方在于：你不再只是在“让结果更可能显著”，而是在主动清理那些会让结果**即使显著也不够可信**的方法漏洞。

这是一个很重要的阶段性变化。

我对 `v4` 的结论是积极的，但这种积极带着一个明确前提：

> 现在最需要的不是再扩实验，而是把主因变量、主基线和主比较链再收紧半步。

如果下一版继续做减法，而不是重新膨胀，我会认为这个项目已经非常接近真正的投稿状态。

**一句话总结：`v4` 已经把“大部分明显漏洞”补上了，剩下的任务不再是加内容，而是把“主结论到底由哪几个最硬的证据支撑”再压得更锋利。**
