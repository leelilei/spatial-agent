| 维度 | v3 | v4 | 修改理由 |

| RQ2表述 | "空间认知效应分离" | **"空间化架构增量效应"** + Perception-Only升为主比较 | R1-§2: 主结论不应强于设计能支撑的 |
| Exp1C设计 | 若干矛盾场景 | **2×2因子设计**（拓扑高/低 × 语义标签公/私） | R1-§3: 需显式估计主效应和交互效应 |
| 论文主线 | 所有实验并重 | **三条主证据链 + 明确的核心/增强分层** | R1-§5: 过度控制导致主线分散 |
| 地图选择 | 三种构型未论证选择逻辑 | **指标空间最大散布原则 + 雷达图可视化** | R2-P1§4: 缺乏系统性论证 |
| C2描述 | 作者手写行为可供性描述 | **C2描述与位置解耦 + 随机分配协议** | R2-P1§5: 手写描述可能隐含空间假设 |
| 预注册 | 未区分验证性/探索性 | **显式分层**：H1-H3为预注册验证性；RQ4、H5、阶段3为探索性 | R2-P1§7: 边界模糊削弱假设检验框架 |

| Movement混淆 | Movement与Interaction均受空间影响 | **新增Fixed-Path条件 + 控制位置后的条件效应分析** | R2-P2§9: 需隔离认知效应 |

### 1.2 研究空白（精确界定，沿用v3）

### 1.3 三个理论跳跃（沿用v3）

| 跳跃 | 从 → 到 | 合理性论证 | 风险 |
|------|---------|-----------|------|
| 跳跃1 | 真实人类 → LLM Agent | LLM训练数据包含海量人类空间行为描述，可能具有隐含空间-社会常识 | LLM可能只是模仿表面模式，不具真正空间推理 |
| 跳跃2 | 物理空间 → 文字描述的空间 | 在文本世界中，Space Syntax指标代表空间特征的语义抽象 | 抽象化可能丧失物理空间的核心行为引导力 |
| 跳跃3 | 个体空间行为 → 群体社会涌现 | 微观空间行为通过交互累积产生宏观社会结构 | 个体效应可能在群体互动中被稀释或覆盖 |

> 本研究不预设这三个跳跃必然成立，而是将其作为**待检验的实验性假设**。三阶段实验分别对应这三个跳跃的验证。

## 第二部分：研究目标与问题

### 2.1 总体目标

（沿用v3，措辞谨慎。）

### 2.2 研究问题

**RQ1（表征验证）**：Space Syntax衍生的空间结构化表征，能否提升LLM Agent的行为环境响应性（Behavioral Spatial Responsiveness, BSR），且效果超出一般性上下文丰富化？

> v4术语变更：将"行为环境一致性（BSC）"改为"行为空间响应性（BSR）"。原因：BSC暗示存在一个预定义的"一致"标准，但我们的两阶段分离评估实际测量的是"行为是否随空间特征系统性变化"——这是响应性（responsiveness），不是一致性（consistency）。

**RQ2（架构增量效应）**：在控制拓扑必然效应的前提下，空间化认知架构（Perception + Action Sampling）能否显著改变Agent的行为策略与交互模式？

> v4表述变更：从"认知效应分离"改为"架构增量效应"，更准确反映设计能支撑的结论层级。

**RQ3（指标效应）**：各空间指标中，哪些对Agent行为影响最稳定？

**RQ4（理论归因 — 探索性）**：观察到的空间-行为关联，是Space Syntax理论预测的结构性效应，还是LLM训练数据中空间常识被激活的结果？

> v4明确标注RQ4为**探索性**，因为当前Exp1C的样本量和因子设计只能提供先导性证据，不足以做确认性推断。

### 2.4 空间-行为假设及推导链（v4关键新增）

v3的假设缺少从Hillier理论到文本Agent世界的完整推导。v4为每个假设建立显式推导表。

#### H1: Integration → 社交频率

| 层级 | 内容 | 来源 |
|------|------|------|
| **Hillier原始理论** | "Natural movement"：行人流量与Integration成正比。高Integration空间自然汇聚更多人流 | Hillier et al. (1993) "Natural movement" |
| **物理空间实证** | 伦敦街道研究：Integration值top-20%的街段承载了60%+的行人流量；相应地这些区域有更高的面对面社交互动频率 | Hillier & Iida (2005); Penn et al. (1998) |
| **文本Agent推导** | LLM Agent不行走物理街道，但 (a) Movement Policy中高Integration节点更可能被选为目的地 → 更多Agent共处 → 更多交互机会；(b) Spatial Perception描述"连接度高、全局可达性强"可能激活LLM训练语料中"公共空间→社交行为"的关联 | 推导，待实验验证 |
| **可能失效条件** | (1) 20节点图中Integration差异不够大，无法驱动显著的Movement偏好差异；(2) LLM不像真实行人那样受"最短路径"吸引；(3) 角色设定（如内向性格）覆盖空间效应 | — |

#### H2: Depth/Openness → 隐私行为

| 层级 | 内容 | 来源 |
|------|------|------|
| **Hillier原始理论** | 空间深度（depth）与隐私梯度相关：从公共入口到私密内部的拓扑距离递增，行为相应从公开转向私密 | Hillier & Hanson (1984) Ch.4 |
| **物理空间实证** | 住宅和办公空间研究：深层空间（高Mean Depth）中的对话更私密、持续时间更长、涉及更敏感话题 | Hanson (1998); Peponis et al. (2004) |
| **文本Agent推导** | 当空间描述传达"此处远离主要通路、需经过多步才能到达"时，LLM可能激活"偏僻→隐私安全"的语义关联，从而选择分享更敏感的信息或进行更私密的对话 | 推导，待实验验证 |
| **可能失效条件** | (1) Openness与Connectivity高度共线（r>0.8）→ 改用Mean Depth；(2) LLM缺乏"空间深度→隐私"的隐含知识；(3) Agent没有"隐私需求"的角色设定 | — |

#### H3: Control Value → 守门行为

| 层级 | 内容 | 来源 |
|------|------|------|
| **Hillier原始理论** | 高Control Value节点是空间结构的"瓶颈"，占据者对通过流量有不成比例的影响力 | Hillier & Hanson (1984) Ch.3 |
| **物理空间实证** | 建筑入口、走廊交汇点研究：高Control Value位置的占据者更频繁地拦截/引导他人、充当信息中介 | Peponis (1985); Bafna (2003) |
| **文本Agent推导** | 当空间描述传达"该位置控制多条通路的进出"时，LLM可能生成监控、拦截、信息过滤类行为。但这取决于角色设定是否包含"权威性"或"守卫"属性 | 推导，待实验验证 |
| **可能失效条件** | (1) 20节点图中高Control Value节点太少（<3个）→ 降级为描述性观察；(2) 守门行为需要特定角色设定配合，单纯空间信息不足以触发 | — |

#### H4: 空间指标交互效应

| 层级 | 内容 | 来源 |
|------|------|------|
| **Hillier原始理论** | 空间属性不独立作用；例如高Integration+高Control = 权力核心；高Depth+低Connectivity = 避难所 | Hillier (1996) "Space is the Machine" |
| **文本Agent推导** | 当多个空间指标同时呈现时，LLM可能产生比单一指标更复杂的行为响应。交互效应方向由指标组合的语义含义决定 | 探索性 |

> **关键声明**：上述推导链中，"物理空间实证→文本Agent推导"这一步是本研究最核心的理论跳跃（跳跃1+2）。如果实验结果支持假设方向但机制不同（如LLM通过语义联想而非空间推理达到相同行为模式），论文将诚实报告这一区别，并讨论其对"Space Syntax在AI Agent中的适用性"这一问题的含义。

## 第四部分：技术架构——SpatialAgent-Lite

### 4.1 架构总览

（沿用v3的2模块设计：Spatial Perception + Spatial Action Sampling。）

### 4.2 模块一：Spatial Perception（v4微调）

**四种表征方式**（沿用v3）：Raw Numeric / Absolute Structural（主方案）/ Neutral Structural / Interpretive。

**Prompt位置控制（v4新增）**：

LLM对prompt中信息的位置敏感（primacy/recency effect）。v4增加以下控制：

- 预实验中测试空间描述在prompt中**三个位置**的效果差异：
  - 位置A：系统prompt末尾（在角色设定之后、当前情境之前）
  - 位置B：当前情境描述中间（在位置描述和在场人物之间）
  - 位置C：用户prompt开头（紧接在"你现在要做什么？"之前）
- 如果三个位置效果差异显著（效应量d>0.3）：选择效果最稳定的位置作为全流程标准
- 如果差异不显著：选择位置B（语义上最自然的位置），并在方法中报告位置无关性

**所有实验中，空间描述的prompt位置固定，并在方法部分明确报告。**

**紧凑Schema表征 / 常驻-访问状态标注**：沿用v3。

### 4.3 模块二：Spatial Action Sampling（v4微调）

**两种评分器**（沿用v3）：LLM Judge / Rule-Based Scorer。

**v4定位澄清**：Rule-Based Scorer定位为**鲁棒性对照**，而非"更客观"的备选主方案。因为手工编写的评分规则同样编码了作者的理论预期，只是换了一种形式的偏见。两种评分器的对比用于检测**LLM Judge特有的先验偏见是否放大了效应**，而非判断哪种"更好"。

**Temperature参数**：沿用v3（默认τ=0.5，预实验测试敏感性）。

### 4.4 所有Agent条件的信息访问矩阵（v4扩展）

| Agent条件 | Movement Policy | 空间指标 | 动态在场信息 | 拓扑邻接 | 对话空间描述 | Action Sampling |
|-----------|:-:|:-:|:-:|:-:|:-:|:-:|
| **C0: Random Walk** | 随机选相邻节点 | ✗ | ✗ | ✓(隐式) | ✗ | 标准LLM |
| **C1: Topology-Only** | LLM CoT（拓扑邻接+地名+在场数） | ✗ | ✓ | ✓ | ✗ | 标准LLM |
| **C2: Rich Non-Spatial** | 同Topology-Only | ✗ | ✓ | ✓ | 随机分配的非空间描述 | 标准LLM |
| **C3: Shuffled Signal** | 同SpatialAgent | ✓(错配) | ✓ | ✓ | 错配空间描述 | Spatial Sampling |
| **C4a: SpatialAgent-Lite** | LLM CoT（空间指标+拓扑+地名） | ✓(正确) | ✓ | ✓ | Absolute Structural | Spatial Sampling |
| **C5: Judge-Only** | 同C1（无空间指标） | ✗ | ✓ | ✓ | ✗ | Spatial Sampling(Judge有空间) |
| **C6: Perception-Only（v4升级为主条件）** | 同SpatialAgent | ✓(正确) | ✓ | ✓ | Absolute Structural | **标准LLM（无Spatial Sampling）** |
| **C7: Fixed-Path（v4新增）** | **预定义路径**（所有条件相同移动轨迹） | ✓(正确) | ✓ | — | Absolute Structural | Spatial Sampling |

**C6 Perception-Only升级为主条件的理由**：

v3中Perception-Only仅在消融实验中出现。但RQ2的核心问题是"空间化架构的增量效应"，而完整架构包含Perception和Action Sampling两个模块。如果不把单模块条件提升为主比较，RQ2的结论无法归因到具体模块。

v4的主比较链变为：

```
C4a (Full) vs C1 (Topology-Only)     → 完整空间化架构的增量效应
C4a (Full) vs C6 (Perception-Only)   → Action Sampling的独立贡献
C6 (Perception-Only) vs C1           → Perception模块的独立贡献
C4a vs C5 (Judge-Only)               → Perception给Actor的额外价值
C4a vs C2 (Rich Non-Spatial)         → 不只是"更多context"
C4a vs C3 (Shuffled)                 → 正确空间信息是关键
```

**C7 Fixed-Path条件的作用**（v4新增）：

Movement决策的结果（Agent去了哪里）直接影响谁和谁相遇。如果SpatialAgent倾向于去高Integration位置，它自然会遇到更多Agent，产生更多社交行为——这是Movement驱动的效应，不是认知驱动的。

C7消除Movement差异：所有Agent按预定义路径移动（每个Agent的路径在run开始时随机生成，但跨条件保持一致）。如果C7(Fixed-Path+Perception+Sampling) ≈ C4a(Free+Perception+Sampling)，说明空间认知效应不依赖Movement差异；如果C4a > C7，说明Movement选择本身是效应的重要来源。

> C7仅在阶段2中运行，作为机制探测条件，不在主结论链中。

### 4.5 NPC角色设计与位置随机化协议（v4关键新增）

#### 4.5.1 角色设计标准化

10个NPC按以下维度系统性设计：

| 维度 | 水平 | 分布 |
|------|------|------|
| **社交倾向** | 高(外向) / 中 / 低(内向) | 4 / 3 / 3 |
| **职业角色** | 公共型(商人、酒保) / 中性型(旅者、学者) / 隐蔽型(密探、刺客) | 3-4 / 3 / 3-4 |
| **目标类型** | 社交型(寻求盟友) / 信息型(收集情报) / 独立型(完成个人任务) | 3-4 / 3 / 3-4 |

**设计原则**：

1. **社交倾向与职业角色正交**：存在"外向的刺客"和"内向的酒保"，避免维度混淆
2. **无NPC-特定空间偏好**：角色设定中**不包含**任何空间偏好暗示（如"喜欢在阴暗角落"）。空间行为应由Spatial Perception模块驱动，不由角色设定预编码
3. **10个NPC的完整人设在附录D中公开**，包括每个维度的具体取值

#### 4.5.2 位置随机化协议

**核心原则：NPC初始位置在每次run中随机分配。**

| 策略 | 描述 | 适用阶段 |
|------|------|---------|
| **完全随机** | 每次run中，10个NPC随机分配到10个起始节点（从20节点中随机选10个） | 阶段1-2 |
| **分层随机** | 确保每次run中，高Integration节点和低Integration节点各有至少2个NPC起始 | 阶段3（需要足够的空间覆盖） |

**禁止**：将特定NPC固定在语义匹配的位置（如"酒馆老板Finn固定在酒馆"）。

> **理由**：如果Finn总在酒馆，那我们观察到Finn在酒馆的高社交行为，无法区分是"酒馆的空间特征"还是"Finn的角色设定+酒馆的语义标签"。随机化确保每个位置被不同角色的NPC占据，使空间效应的估计不被角色-位置混淆污染。

**叙事一致性的处理**：

随机位置可能破坏叙事合理性（如刺客出现在广场中央）。处理方案：

- NPC的**初始位置**随机，但其**角色背景故事**不引用具体位置
- NPC在第1轮的对话prompt中仅表述为"你刚到达[位置名]"，不预设其在此停留
- 分析时排除前5轮（让NPC有时间"自然"移动到符合角色的位置），但报告包含/排除前5轮的结果差异

#### 4.5.3 角色效应的统计控制

在Mixed-Effects Model中加入角色属性：

```
阶段2主模型：
  DV ~ agent_type + social_tendency + (1|run) + (1|agent_id)

阶段2交互模型（探索性）：
  DV ~ agent_type * social_tendency + (1|run) + (1|agent_id)
```

> 如果agent_type × social_tendency交互显著，说明空间化架构对外向/内向NPC的影响不同——这本身是一个有趣的发现。

### 阶段1：机制验证（预计2周）

#### Exp1A: 表征方式对比（7条件，沿用v3）

条件C0-C5沿用v3设计。

**Rich Non-Spatial (C2) 的改进设计（v4进一步修订）**：

v3中C2使用作者手写的"行为可供性描述"。v4发现问题：如果作者为高Integration位置写了高社交暗示的C2描述，则C2不再是独立基线。

**v4方案：C2描述与位置解耦**

1. **描述池**：预先编写20条等长度、具有行为可供性的非空间描述（涵盖社交/警惕/放松/好奇等不同行为引导方向），例如：
   - "周围传来嘈杂的争吵声和酒杯碰撞声" → 社交/放松引导
   - "远处传来低沉的鼓声和规律的金属撞击声" → 警惕引导
   - "空气中弥漫着新鲜面包的香气，有人在轻声哼歌" → 放松/好奇引导

2. **随机分配**：每次run中，为每个位置-每轮**随机**从描述池中抽取一条C2描述。描述与位置之间无系统性关联。

3. **引导方向平衡**：描述池中四种引导方向各5条，确保长期来看每个位置接收到的引导方向是均匀的。

> 这确保C2提供了"同等token量的行为可供性上下文"，但其内容**与空间特征完全解耦**。如果C4a仍优于C2，说明空间结构信息的行为引导力不可被随机的非空间上下文替代。

#### Exp1C: 反直觉空间条件（v4改为2×2因子设计）

**v3问题**：仅设计了若干矛盾场景，测到的可能是"冲突信息下的prompt支配关系"而非理论归因。

**v4方案：显式因子设计**

| | 语义标签=公共 | 语义标签=私密 |
|---|:---:|:---:|
| **拓扑=高Integration** | 一致（公共+枢纽） | **冲突（私密+枢纽）** |
| **拓扑=低Integration（高Depth）** | **冲突（公共+深层）** | 一致（私密+深层） |

每个cell = 5个独立场景 × 20个微任务/场景 = 100个数据点/cell。

**4个cell的具体实现**：

| Cell | 场景示例 | 空间指标 | 地点名称 |
|------|---------|---------|---------|
| 一致-公共 | 中央广场 | Integration top-20% | "繁忙集市"、"公共喷泉广场" |
| **冲突-私密枢纽** | 暗名称但高连接 | Integration top-20% | "偏僻小巷"、"废弃地窖"、"隐蔽暗道" |
| **冲突-公共深层** | 亮名称但低连接 | Depth top-20% | "开放露台"、"宽敞庭院"、"光明大厅" |
| 一致-私密 | 深层密室 | Depth top-20% | "秘密密室"、"地下藏身处" |

**分析模型**：

```
behavior_sociality ~ topology_level * semantic_label + (1|scenario)

核心检验：
  - topology_level主效应 → 拓扑结构对行为的影响（支持Space Syntax）
  - semantic_label主效应 → 语义标签对行为的影响（LLM常识）
  - 交互效应 → 冲突条件下哪种信号主导
```

**结果解释框架**：

| 结果模式 | 解释 | 论文定位 |
|---------|------|---------|
| topology主效应显著，semantic不显著 | 强烈支持Space Syntax理论效应 | 论文标题保持"Space Syntax-Informed" |
| 两者都显著，topology更大 | Space Syntax效应存在但与常识混合 | "Space Syntax提供超越常识的结构性引导" |
| 两者都显著，semantic更大 | 常识主导，Space Syntax贡献有限 | 重新定位为"空间上下文对LLM Agent的影响" |
| semantic主效应显著，topology不显著 | 不支持Space Syntax理论效应 | 诚实报告负面结果，讨论迁移失败原因 |

### 阶段2：行为效应（预计4周）

#### Exp2: 同地图多Agent行为效应

#### 时间动态分析（v4关键新增）

##### 收敛性分析

在每次run中，每20轮计算一次以下指标：

```
社交网络密度（density）
聚类系数（clustering coefficient）
度分布基尼系数（degree Gini）
平均交互强度（mean interaction intensity）
```

**稳态判据**：连续3个窗口（60轮）内，所有指标变化幅度 < 5%。

- 如果预实验显示200轮不足以达到稳态 → 增加轮次至300-400轮
- 如果稳态在100轮内即达到 → 论文中报告，并讨论后100轮是否仅是噪声

##### 分段比较

在主分析外，额外报告：

```
前100轮 vs 后100轮的空间效应差异：
  DV ~ agent_type * time_half + (1|run) + (1|agent_id)
```

如果agent_type × time_half交互显著：
- 空间效应随时间增强 → 说明Agent在学习利用空间信息（或记忆累积放大了空间影响）
- 空间效应随时间减弱 → 说明初始空间引导逐渐被Agent自身经验覆盖

#### Exp2-Ablation: 架构消融（v4精简版）

| 条件 | Perception | Action Sampling | 评分器 | 核心比较 |
|------|:-:|:-:|:-:|------|
| C4a: Full-LLMJudge | ✓ | ✓ | LLM Judge | 主方案 |
| C6: Perception-Only | ✓ | ✗ | — | **C4a vs C6 → Sampling贡献** |
| C5: Judge-Only | ✗ | ✓ | LLM Judge(有空间) | **C4a vs C5 → Perception给Actor的价值** |
| Full-RuleScorer | ✓ | ✓ | Rule-Based | **C4a vs RuleScorer → Judge LLM偏见** |
| C7: Fixed-Path | ✓ | ✓ | LLM Judge | **C4a vs C7 → Movement选择的贡献** |
| C1: Topology-Only | ✗ | ✗ | — | = NoModule基线 |

**核心分解**：

```
Total Effect = C4a - C1
             = (C4a - C6) + (C6 - C1)
             = Sampling贡献 + Perception贡献

Movement vs Cognition:
  C4a - C7 = Movement选择自由的贡献
  C7 - C1  = 纯认知效应（控制了Movement差异后的残余效应）
```

#### 控制位置后的条件效应分析（v4新增）

为隔离Movement驱动效应与认知驱动效应，额外报告：

```
# 在同一位置-同一时间窗口内比较不同条件的行为
DV ~ agent_type + spatial_features + (1|run) + (1|agent_id) + (1|location)

# 关键：加入location随机效应后，agent_type的效应反映的是
# "同一位置上不同条件Agent的行为差异"——消除了位置选择偏差
```

### 6.1 两阶段分离评估（沿用v3）

阶段B：空间关联分析（研究者事后进行）。

### 6.2 因变量体系（v4扩展）

#### 主要DV

| DV | 测量方式 | 对应RQ |
|----|---------|--------|
| **行为空间响应性（BSR）** | 行为分布是否随空间特征系统性变化（χ²检验 + Cramér's V） | RQ1 |
| **交互模式差异** | 交互强度、信息敏感度在不同Agent条件间的分布差异 | RQ2 |
| **指标-行为相关强度** | 各指标与行为维度的偏相关系数 | RQ3 |

#### 辅助DV（v4新增）

| DV | 测量方式 | 理论意义 |
|----|---------|---------|
| **行为熵（Behavioral Entropy）** | 每个Agent在整个run中的行为类型分布的Shannon熵 | 空间信息是促进行为多样化（高熵）还是导致行为刻板化（低熵）？两种结果都有理论价值 |
| **空间一致性方向** | 在关联显著的情况下，关联方向是否与假设推导表中的预测一致 | 区分"有响应"与"响应方向正确" |

### 6.3 LLM Judge设计（沿用v3 + LLM同源偏见控制）

**交叉模型验证**（沿用v3）：Actor用统一模型（DeepSeek-V3推荐），Judge A用GPT-4o，Judge B用DeepSeek-V3。

**LLM同源偏见检测（v4新增）**：

所有大型LLM共享相似的互联网训练语料，可能具有相似的空间-社会常识偏见。检测方案：

1. **Shuffled条件作为偏见探针**：在Shuffled Signal条件下，空间信息与位置不匹配。如果LLM Judge仍然对Shuffled条件给出较高的"空间一致性"评分 → 说明Judge有先验偏见
2. **人类-LLM不一致分析**：在人类评估子集上，比较人类标注与LLM标注的条件间差异。如果LLM系统性地高估某些条件的效应 → 报告偏见方向和幅度
3. 在论文中报告LLM Judge偏见的方向和大小，作为结果解释的caveat

### 6.4 统计分析框架（v4修订 — 双层分析）

**v3问题**：功效分析中run-level与event-level样本单位混用。

**v4方案：明确区分两层分析**

#### 第一层：Run-Level验证性分析（主分析）

```
独立样本单位 = run
每个cell的样本量 = 20 runs
每个run汇总为一个数据点（如该run内的平均BSR、行为熵等）

模型：
  DV_aggregated ~ agent_type + (1|run_id)
  # 简单、干净、样本单位清晰

功效论证：
  20 runs/cell → 两组比较中能检测 Cohen's d ≥ 0.91（α=0.05, power=0.80）
  → 只能可靠检测到大效应量
  → 在论文中声明：本研究的验证性分析聚焦大效应，中小效应通过探索性分析报告
```

#### 第二层：Event-Level探索性分析（补充分析）

```
观测单位 = 每轮每个Agent的行为事件
每个cell的观测数 ≈ 20 runs × 200轮 × 10 agents = 40,000

模型：
  DV ~ agent_type + spatial_features + (1|run) + (1|agent_id) + (1|time_block)

功效论证：
  ICC ≈ 0.3, DE ≈ 60.7
  有效独立样本 ≈ 20 × (200/60.7) ≈ 66/cell → 足够检测 d ≥ 0.5
```

**关键规则**：

- **论文主结论仅基于Run-Level分析**
- Event-Level分析用于提供更细粒度的效应模式描述、估计效应量和置信区间
- 如果Run-Level不显著但Event-Level显著 → 报告为"存在微弱但可检测的效应，需更大样本量的验证性研究确认"
- **绝不在摘要或贡献声明中使用Event-Level的p值**

### 6.5 功效分析（v4修订版）

| 分析层级 | 独立单位 | 每cell样本 | 可检测最小效应 | 性质 |
|---------|---------|:----------:|:------------:|------|
| Run-Level（主） | run | 20 | d ≥ 0.91 | 验证性 |
| Event-Level（辅） | 有效独立观测 | ~66 | d ≥ 0.50 | 探索性 |
| 阶段3交互（辅） | run | 20/cell | η² ≥ 0.06 | 探索性 |

> **坦诚声明**：20 runs/cell的Run-Level功效仅足以检测大效应。如果空间化架构的真实效应为中等（d≈0.5），本研究的验证性分析可能无法达到显著。这是资源约束下的现实权衡。我们通过Event-Level探索性分析提供效应量估计和置信区间，为后续更大规模的验证性研究提供先验信息。

**H3的特殊考量**（沿用v3）：高Control Value节点太少则降级为描述性观察。
