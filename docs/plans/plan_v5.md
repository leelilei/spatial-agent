# SpatialAgent 研究计划 v5

## Where You Are Shapes Who You Become: Space Syntax-Informed LLM Agents for Spatially Believable Game Worlds

> 版本: 5.0  
> 日期: 2026-03-16  
> 作者: Li  
> 目标会议: AAMAS-27 (首选) / AAAI-27 (备选)  
> 本版本目标: 在 `v4` 基础上做最后一轮投稿前收口，压实主因变量、主对照和主证据链

---

## 修订说明：v4 → v5 核心变化

| 维度 | v4 | v5 | 修改理由 |
|------|----|----|---------|
| 主因变量 | `BSR` 为主，方向性分析为辅助 | **双主因变量**：Unsigned BSR + **Theory-Aligned Responsiveness (TAR)** | 仅测“有无响应”不足以支撑 Space Syntax 理论主张 |
| 阶段2主条件 | 8 条件并行 | **4 个验证性核心条件 + 4 个探索性机制条件** | 把资源集中到最关键比较，提高 run-level 功效 |
| `C2` 基线 | 每轮随机抽取非空间描述 | **每个 run 内位置稳定、runs 之间随机** | 避免把 `C2` 变成高噪声条件而非公平基线 |
| `Exp1C` 标签设计 | 2×2 因子，但标签未预标定 | **加入 lexical norming 预实验** | 避免“公共/私密”标签混入危险感、明亮度等额外维度 |
| 统计论证 | `20 runs/cell`，验证性仅能检出很大效应 | **核心阶段2增至 `30 runs/cell`** | 将 run-level 可检测效应降低到更可接受范围 |
| 阶段3定位 | 探索性，但仍较重 | **进一步降级为可选扩展**，不进入主论文必要贡献 | 防止主线失焦 |
| 论文主线 | 3 条核心证据链，但增强项较多 | **主 spine 固定为 3 条证据链 + 1 条探索补充** | 服务最终写作，而非服务计划完整性 |

## 第一部分：研究背景

### 1.1 问题的起源

现有 LLM Agent 在游戏和社会模拟中的研究，已经较好建模了两类信息：

- **WHO**：身份、人格、动机、背景故事
- **WHAT**：事件、记忆、当前任务、对话历史

但对第三类信息的建模依然薄弱：

- **WHERE**：空间构型、可达性、深度、瓶颈性、可见性

需要强调的是，这里的缺口不是“完全没有空间信息”，而是**缺乏构型级空间表征**。现有工作通常只利用地点名称、功能标签或简单邻接关系，而没有系统引入建筑学中的 Space Syntax 理论，将空间作为一种结构性约束条件进入 Agent 的决策循环。

### 1.2 研究空白

本研究针对三个明确的空白：

1. **表征空白**：现有 LLM Agent 缺乏来自 Space Syntax 的结构化空间表征。
2. **识别空白**：缺乏将“拓扑必然效应”与“空间化认知架构效应”分离的实验协议。
3. **理论空白**：建筑学 Space Syntax 与 LLM 多 Agent 社会模拟之间缺乏系统对话。

### 1.3 三个理论跳跃

| 跳跃 | 从 → 到 | 合理性论证 | 风险 |
|------|---------|-----------|------|
| 跳跃1 | 真实人类 → LLM Agent | LLM 训练数据可能编码了人类空间-社会常识 | 模型可能只模仿语言表面模式 |
| 跳跃2 | 物理空间 → 文本化空间 | 拓扑指标可在文本世界中被抽象为结构性描述 | 物理 affordance 可能在文本中丢失 |
| 跳跃3 | 个体空间行为 → 群体社会涌现 | 微观空间行为偏移可能通过交互累积成宏观网络结构 | 个体效应可能被群体动态稀释 |

> 本研究不预设这三个跳跃必然成立，而是把它们转化为待检验的实验问题。`v5` 的核心重点是先把跳跃1和跳跃2检验清楚，再决定是否投入更多资源到跳跃3。

## 第二部分：研究目标、问题与主张边界

### 2.1 总体目标

本研究的目标不是“证明 Space Syntax 在 LLM Agent 世界中完全成立”，而是：

1. 构建一种**空间化认知架构**，把 Space Syntax 衍生的结构性空间信息注入 Agent 决策循环；
2. 在严格对照下检验该架构是否带来**超越一般上下文增强**的行为变化；
3. 探索这些行为变化是否沿着 Space Syntax 理论预测的方向发生。

### 2.2 研究问题

**RQ1（验证性）**：结构化空间表征是否比无空间、地名标签、原始数值和非空间上下文更能诱发 Agent 对空间特征的系统性行为响应？

**RQ2（验证性）**：在控制拓扑必然效应的前提下，空间化架构是否相对 `Topology-Only` 带来显著增量？

**RQ3（验证性）**：在空间化架构中，`Perception` 与 `Action Sampling` 各自贡献多少？

**RQ4（探索性）**：观测到的空间行为响应更接近 Space Syntax 的结构性效应，还是更接近 LLM 已有的语义常识激活？

### 2.3 验证性 / 探索性分层

| 内容 | 性质 | 是否主论文核心 |
|------|------|:--------------:|
| 阶段1：表征有效性（Exp1A） | 验证性 | 是 |
| 阶段2：架构增量效应（Exp2） | 验证性 | 是 |
| 阶段2：模块分解（Full / Perception-Only / Judge-Only） | 验证性 | 是 |
| 阶段1：反直觉 2×2 因子（Exp1C） | 探索性但高价值 | 是 |
| 阶段2：Fixed-Path / Rule-Based / Shuffled | 机制探测 | 否，附录主报 |
| 阶段3：多地图涌现 | 探索性扩展 | 否，时间允许时进行 |
| 人类评估 | 外部有效性增强 | 否，若时间允许则做 |

### 2.4 主张边界

`v5` 明确只尝试支撑以下级别的结论：

- “结构化空间表征可以系统性影响 LLM Agent 行为”
- “这种影响在若干关键设置下超出一般上下文增强”
- “其中一部分影响与 Space Syntax 的方向性预测一致”

`v5` **不**预先声称：

- 证明 Space Syntax 在文本 Agent 世界中被完整验证
- 证明所有社会涌现现象都由空间构型因果决定
- 证明任何一个单独空间指标都具有跨环境普适性

## 第三部分：理论框架与主因变量

### 3.1 H1-H3 的推导链

#### H1：Integration 与社交频率

| 层级 | 内容 |
|------|------|
| Hillier 原始理论 | 高 Integration 空间吸引更多自然流动，形成公共活动中心 |
| 物理空间实证 | 高 Integration 街段和公共节点通常承载更高人流与更多面对面互动 |
| 文本 Agent 推导 | 若 Agent 得知某位置在全局上更可达、更像枢纽，则可能更倾向于主动接触、停留或公开交互 |
| 失效条件 | 角色内向性过强、地图过小、Movement 不受最短路径偏好影响 |

#### H2：Depth / Openness 与私密行为

| 层级 | 内容 |
|------|------|
| Hillier 原始理论 | 深层空间与隐私梯度相关，行为从公开转向私密 |
| 物理空间实证 | 深层或低可见空间承载更私密、更敏感的话题交换 |
| 文本 Agent 推导 | 当描述传达“此地远离主通路 / 不易被打断 / 深藏内部”时，Agent 更可能选择低声交流、分享敏感信息 |
| 失效条件 | `Openness` 与 `Connectivity` 共线、角色没有隐私需求、语义标签覆盖结构信号 |

#### H3：Control Value 与守门行为

| 层级 | 内容 |
|------|------|
| Hillier 原始理论 | 高 Control Value 节点控制邻近通行，是结构瓶颈 |
| 物理空间实证 | 瓶颈位置更易承载拦截、监视、信息中介等行为 |
| 文本 Agent 推导 | 当描述传达“此处控制多条通路的进出”时，Agent 更可能表现出巡视、阻拦、观察、筛选信息等守门行为 |
| 失效条件 | 高 Control 节点数量太少；角色设定不允许守门行为出现 |

### 3.2 H4 与 H5 的定位

- **H4（指标交互）**：保留为机制性探索，不进入主摘要贡献。
- **H5（整体涌现）**：仅在阶段3探索，不作为验证性主假设。

### 3.3 指标定义与决策树

保留四类核心空间指标：

- `Integration`
- `Connectivity`
- `Control Value`
- `Openness` 或 `Mean Depth`

#### Openness vs Mean Depth 决策树

在正式实验前先计算三种构型的指标相关矩阵。

```text
如果 Openness 与 Connectivity 的 Pearson r <= 0.8：
  保留 Openness

如果 r > 0.8：
  弃用 Openness
  改用 Mean Depth 作为 H2 主指标
```

> `v5` 主文默认使用 `Mean Depth` 作为 H2 的更稳健候选，因为它更接近“深层 / 隐蔽 / 远离主入口”的拓扑概念，也更容易在 20 节点图上与 `Connectivity` 分离。

### 3.4 双主因变量：BSR 与 TAR

#### 3.4.1 Unsigned BSR

`BSR`（Behavioral Spatial Responsiveness）衡量：

> Agent 行为是否随着空间特征变化而系统性变化。

它回答的是“**有没有空间响应**”。

典型实现：

- 行为分布在高 / 低特征节点间的 `chi-square`
- 效应量 `Cramer's V`
- 交互强度、信息敏感度等的分布差异

#### 3.4.2 Signed TAR

`TAR`（Theory-Aligned Responsiveness）衡量：

> 这种空间响应是否沿着理论预测方向发生。

它回答的是“**是否按 Space Syntax 预测方向响应**”。

对每个假设定义一个有方向的效应：

```text
TAR_H1 = sociality(high Integration) - sociality(low Integration)
TAR_H2 = privacy_behavior(high Depth/private) - privacy_behavior(low Depth/public)
TAR_H3 = gatekeeping(high Control) - gatekeeping(low Control)
```

约定：

- `TAR > 0`：与理论预测方向一致
- `TAR = 0`：无方向性差异
- `TAR < 0`：与理论预测方向相反

> `v5` 的核心改动是：**论文不能只报告 BSR，而必须同步报告 TAR。**  
> 否则最多只能证明“空间信息影响了行为”，而不能证明“这种影响与 Space Syntax 的方向性预测有关”。

### 3.5 辅助因变量

- **Behavioral Entropy**：行为类型分布的 Shannon 熵
- **平均交互强度**
- **信息敏感度比例**
- **守门行为比例**

行为熵只作为辅助结果，用来回答：

- 空间信息使行为更多样，还是更刻板？

## 第四部分：环境、NPC 与控制变量

### 4.1 环境设置

核心验证阶段只使用一张主地图：

- **Plaza**：用于阶段1和阶段2验证性分析

探索性扩展地图：

- **Labyrinth**
- **Bridge**

这三种构型的选择原则不是叙事名称，而是**指标分布的最大散布**：

- `Plaza`：中心化明显，Integration 高峰集中
- `Labyrinth`：Depth 高，Connectivity 低
- `Bridge`：多中心和瓶颈特征更强，Control 分布更不均匀

### 4.2 NPC 角色设计标准化

10 个 NPC 沿三个维度平衡设计：

| 维度 | 水平 | 分布 |
|------|------|------|
| 社交倾向 | 高 / 中 / 低 | 4 / 3 / 3 |
| 职业角色 | 公共型 / 中性型 / 隐蔽型 | 3-4 / 3 / 3-4 |
| 目标类型 | 社交型 / 信息型 / 独立型 | 3-4 / 3 / 3-4 |

设计约束：

1. 社交倾向与职业角色正交。
2. 角色描述中**不写入空间偏好**。
3. 背景故事不绑定固定地点。

### 4.3 位置随机化协议

为防止角色-位置混淆：

- 每个 run 中，NPC 初始位置随机分配
- 主分析默认排除前 `5` 轮作为 warm-up
- 附录同时报告包含 / 不包含前 5 轮的敏感性分析

### 4.4 Prompt 位置控制

空间描述在 prompt 中的位置可能影响其使用程度。预实验比较三个插入位置：

- 系统 prompt 末尾
- 当前情境中部
- 用户指令前

选取效果最稳定的位置，并在全流程固定。

## 第五部分：SpatialAgent-Lite 架构与条件矩阵

### 5.1 核心架构

`v5` 保留两个核心模块：

1. **Spatial Perception**
2. **Spatial Action Sampling**

不把 `Memory` 和 `Planning` 扩展写入主贡献，以避免归因污染。

### 5.2 Spatial Perception

主方案使用 **Absolute Structural** 表征：

```text
该位置与其他位置的平均拓扑距离为 1.8 步。
该位置直接连接 4 个相邻位置。
经过该位置可控制进出 3 个区域的通行。
此刻在场 2 人：Elara、Theron。
```

其优点：

- 不含百分位和隐含比较语义
- 不直接暗示“你该做什么”
- 易于和 `Name Only`、`Raw Numeric`、`C2` 对照

### 5.3 Spatial Action Sampling

流程：

1. Actor 先生成 `K=5` 个候选行为；
2. Judge 根据空间上下文对候选行为打分；
3. 使用 `softmax(score / tau)` 加权采样。

其中：

- 默认 `tau = 0.5`
- `Rule-Based Scorer` 只作为鲁棒性对照，不作为主方案

### 5.4 条件矩阵

#### 5.4.1 验证性核心条件

| 条件 | Movement | 对话空间描述 | Sampling | 用途 |
|------|----------|--------------|----------|------|
| `C1 Topology-Only` | 邻接 + 地名 + 在场数 | 无 | 无 | 主基线 |
| `C2 Stable Rich Non-Spatial` | 同 `C1` | 非空间但可行动描述 | 无 | 排除“一般上下文增强” |
| `C4 Full SpatialAgent` | 空间指标 + 邻接 + 地名 + 在场数 | Absolute Structural | 有 | 主方案 |
| `C6 Perception-Only` | 空间指标 + 邻接 + 地名 + 在场数 | Absolute Structural | 无 | 分离 Perception 贡献 |

#### 5.4.2 探索性机制条件

| 条件 | 作用 |
|------|------|
| `C3 Shuffled Signal` | 检验“正确信息是否必要” |
| `C5 Judge-Only` | 检验 Judge 先验知识是否足以制造大部分效应 |
| `C7 Fixed-Path` | 分离 Movement 驱动效应与到位后认知效应 |
| `Full-RuleScorer` | 检查 LLM Judge 是否放大效应 |

### 5.5 `C2` 的稳定随机化设计

`v4` 的问题是按轮随机抽取 `C2` 描述，容易把它做成噪声条件。`v5` 改为：

- 每个 run 开始时，为每个位置从非空间描述池中抽取一条描述
- 该描述在**整个 run 内固定**
- 不同 run 之间重新随机

因此 `C2` 满足：

- 与空间特征解耦
- 对行为有可行动信息
- 在单个 run 内具有情境稳定性

> 这使 `C2` 成为一个更公平、更强的“非空间但稳定的上下文基线”。

## 第六部分：实验设计

## 6.0 预实验

### 6.0.1 指标质量预检

报告：

- 相关矩阵
- 分布直方图
- 变异系数 `CV`
- 高 `Control` 节点数量

规则：

- 若某指标 `CV < 0.2`，则在该构型中标记为低区分力
- 若高 `Control` 节点少于 3 个，则 `H3` 在该构型中降级为描述性观察

### 6.0.2 LLM 空间理解门控

两层测试：

1. **Comprehension**：能否读懂事实和数值
2. **Behavioral Inference**：能否据此做出方向一致的行为推断

通过标准：

- Comprehension `>= 85%`
- Behavioral Inference `>= 70%`

### 6.0.3 Prompt 位置测试

在微任务上测试三个插入位置，选择效果最稳定的位置。

### 6.0.4 语义标签预标定（Exp1C 必做）

为 `Exp1C` 中候选标签做 lexical norming。

对每个标签，收集人类或独立 Judge 的五维评分：

- publicness
- privacy
- danger
- valence
- brightness

选择原则：

- “公共 / 私密”维度差异明显
- 其余维度差异尽量小

这样可以避免把 `semantic_label` 操作成一整包高维语义操控。

### 6.0.5 收敛性 pilot

在 `Plaza` 上先跑小规模模拟，观察：

- 网络密度
- 聚类系数
- degree Gini
- 平均交互强度

稳态判据：

> 连续 3 个窗口（每窗口 20 轮）内，关键指标变化幅度均小于 `5%`

如果 `200` 轮达不到稳态，则将阶段2 / 3 的正式轮次数提高到 `300`。

## 6.1 阶段1：表征有效性

### Exp1A：6 条件表征对比

| 条件 | 描述 |
|------|------|
| `C0` | No Space |
| `C1` | Name Only |
| `C2` | Stable Rich Non-Spatial |
| `C3` | Raw Numeric |
| `C4` | Absolute Structural |
| `C5` | Shuffled Signal |

微任务包括：

1. 是否透露敏感信息
2. 是否主动搭话
3. 在多个位置中选择去处
4. 是否停留 / 离开

主比较：

- `C4 > C0`
- `C4 > C1`
- `C4 > C2`
- `C4 > C3`
- `C4 > C5`

主报告指标：

- `BSR`
- `TAR_H1`
- `TAR_H2`

### Exp1C：理论归因 2×2 因子设计

两个因子：

- `Topology`: 高 / 低
- `Semantic Label`: 公共 / 私密

构成四个 cell：

| | 公共标签 | 私密标签 |
|---|:---:|:---:|
| 高拓扑中心性 | 一致 | 冲突 |
| 低拓扑中心性 / 高深度 | 冲突 | 一致 |

每个 cell：

- `5` 个独立场景
- 每场景 `20` 个微任务

分析模型：

```text
DV ~ topology_level * semantic_label + (1|scenario)
```

核心解读：

- `topology` 主效应：结构信号
- `semantic_label` 主效应：语义常识
- 交互项：冲突条件下的主导关系

> `Exp1C` 在 `v5` 中仍然是探索性高价值证据，而不是确认性主结论来源。

## 6.2 阶段2：架构增量效应与模块分解

### 6.2.1 范围收缩

阶段2只在 `Plaza` 上做验证性主分析。

这样做的目的很明确：

- 不在确认性阶段同时混入“跨地图泛化”问题
- 把资源集中到最关键的架构比较

### 6.2.2 核心验证性条件与样本量

验证性核心条件：

- `C1 Topology-Only`
- `C2 Stable Rich Non-Spatial`
- `C4 Full SpatialAgent`
- `C6 Perception-Only`

运行参数：

- `30 runs / cell`
- 每 run `200-300` 轮（由收敛性 pilot 决定）
- `10` 个 NPC

> 之所以能把 `runs/cell` 从 `20` 提高到 `30`，是因为 `v5` 把若干机制条件从验证性主链中移出。

### 6.2.3 阶段2主比较链

```text
C4 - C1  = 完整空间化架构增量效应
C6 - C1  = Perception 模块独立贡献
C4 - C6  = Action Sampling 独立贡献
C4 - C2  = 结构化空间信息 vs 一般非空间上下文
```

### 6.2.4 探索性机制条件

以下条件只做机制探测：

- `C3 Shuffled Signal`
- `C5 Judge-Only`
- `C7 Fixed-Path`
- `Full-RuleScorer`

其运行规模可降为：

- `10-12 runs / cell`

这些条件不参与摘要中的主结论，只用于：

- 判断 Judge 偏见
- 判断 Movement vs Cognition 的相对贡献
- 判断错误空间信号是否仍能制造假效应

### 6.2.5 控制位置后的条件效应

为了避免“空间效应其实只是位置选择效应”，额外做一项探索性分析：

```text
DV ~ agent_type + spatial_features + (1|run) + (1|agent_id) + (1|location)
```

这里 `location` 随机效应的作用是：

> 在同一位置上比较不同条件 Agent 的行为差异。

这能帮助判断：

- 效应来自“去了哪里”
- 还是来自“到了同一个位置后怎么做”

### 6.2.6 时间动态分析

阶段2必须报告：

1. 收敛曲线
2. 前半程 vs 后半程比较

模型：

```text
DV ~ agent_type * time_half + (1|run) + (1|agent_id)
```

若交互显著，说明空间效应具有时间依赖性。

## 6.3 阶段3：探索性扩展

### 6.3.1 启动条件

只有在阶段2至少满足以下条件之一时，才进入阶段3：

1. `C4 > C1` 在至少一个主 `TAR` 指标上达到显著或中等效应趋势；
2. `C6 > C1` 与 `C4 > C6` 的方向稳定，表明模块分解有解释价值。

### 6.3.2 多地图分析

使用三种构型：

- `Plaza`
- `Labyrinth`
- `Bridge`

但阶段3明确是探索性的，目的仅是：

- 看主效应是否在跨构型下保持方向一致
- 观察认知增量是否随地图结构变化

默认规模：

- `15 runs / cell`

若 pilot 失败：

- 降级为描述性案例
- 不进入统计推断

## 第七部分：评估与统计分析

### 7.1 两阶段分离评估

#### 阶段A：盲行为编码

标注者只看行为文本，不看空间信息。

标注维度：

- 行为类型
- 交互强度
- 信息敏感度
- 是否包含守门 / 监视 / 拦截行为

#### 阶段B：空间关联分析

研究者事后将盲编码结果与空间特征关联。

这样可以最大程度避免：

- 把理论假设直接写回评分规则

### 7.2 Run-Level 验证性分析

主结论只基于 run-level 汇总指标。

每个 run 形成一个数据点，例如：

- 平均 `BSR`
- 平均 `TAR_H1`
- 平均 `TAR_H2`
- 行为熵

主模型示例：

```text
TAR_H1 ~ condition + social_tendency + (1|run_id)
TAR_H2 ~ condition + social_tendency + (1|run_id)
entropy ~ condition + social_tendency + (1|run_id)
```

### 7.3 Event-Level 探索性分析

事件级分析只用于：

- 描述更细粒度的模式
- 估计中等效应量
- 解释 run-level 不显著但方向稳定的情况

不用于摘要主 claim。

### 7.4 功效分析

#### 验证性主分析

以 `30 runs/cell` 做两组比较，run-level 可检测效应下降到：

- 约 `d >= 0.74`

这仍然偏向检测中到大效应，但已经明显优于 `v4` 的 `d >= 0.91`。

#### 探索性补充

事件级分析在考虑依赖结构后，可帮助估计：

- `d ≈ 0.5` 量级的效应

### 7.5 统计规则

- 多重比较校正：`Benjamini-Hochberg FDR`
- 报告：`p 值 + 效应量 + 95% CI`
- 若 run-level 不显著但 event-level 显著：
  - 只能写成“存在中小效应迹象”
  - 不能上升为主结论

### 7.6 LLM Judge 偏见检测

通过三种方式检测：

1. `Shuffled` 条件作为偏见探针
2. 人类-LLM 标注一致性分析
3. `Rule-Based` 结果与 `LLM Judge` 的差异对照

## 第九部分：风险与应对
