## 一、执行摘要

本研究关注一个核心问题：

**当 LLM Agent 被提供结构化的空间描述时，它们的行为是否会系统性地响应这些描述，且响应方向是否部分符合空间理论预期？**

本研究的唯一主贡献是：

**提出并验证一种结构化空间表征方案，检验其是否能够系统性改变 LLM Agent 的行为模式，并使其中一部分行为变化沿着 Space Syntax 启发的理论方向发生。**

支撑这一主贡献的三个方法部件是：

1. `C6m / C6f / C4` 条件分解，用于识别效应进入系统的主要位置。
2. `BSR / TAR` 双指标设计，用于区分“是否响应空间”与“是否按理论方向响应空间”。
3. `MIC`（matched initial conditions）设计，用于控制初始世界状态差异并降低部分前期方差。

本研究不试图预先声称以下结论：

- 完整验证 Space Syntax 理论。
- 证明文本 Agent 等价于物理空间中的真实人类。
- 证明所有社会涌现都由空间构型因果决定。
- 排除所有小效应或不稳定效应的存在。

本文的证据目标是识别**稳健且具有实践意义的中到大效应**，并在此基础上判断结构化空间表征是否值得作为多 Agent 世界建模中的正式输入层。

## 二、研究动机与理论定位

### 2.1 问题背景

现有 LLM Agent 研究已经较好地建模了两类信息：

- `WHO`: 身份、人格、目标、背景
- `WHAT`: 事件、记忆、任务与互动历史

相对薄弱的是第三类信息：

- `WHERE`: 空间构型、深度、可达性、瓶颈性与结构角色

许多系统提供地点名、语义标签或局部邻接关系，但缺少对“位置在整体结构中扮演什么角色”的显式建模。本研究关注的不是“是否有地点信息”，而是**构型级空间表征**是否会对行为产生系统性影响。

### 2.2 三个理论跳跃

本研究涉及三个潜在跳跃：

| 跳跃 | 从 -> 到 | 本研究的处理方式 |
|------|----------|------------------|
| 跳跃1 | 真实人类 -> LLM Agent | 作为主要检验对象，判断模型是否习得空间-行为关联 |
| 跳跃2 | 物理空间 -> 文本化空间 | 需要明确论证其合理性，并通过门控实验验证 |
| 跳跃3 | 个体行为 -> 群体涌现 | 作为扩展方向，不作为主论文成立前提 |

本研究的证据重点放在前两个跳跃上。第三个跳跃只在前两个跳跃成立、且核心效应清晰时才进入扩展阶段。

### 2.3 为什么文本化空间描述可能保留有效信息

本研究采用文本化空间表征，不意味着它等价于物理空间体验。这里的关键论点是：Space Syntax 关注的核心对象是**位置在拓扑网络中的结构角色**，而不是材质、几何细节或感知质感本身。只要文本描述能稳定传达这些结构角色，它就可能对 Agent 的决策产生影响。

这一判断依赖三个层面：

1. 抽象层面  
   `Integration`、`Mean Depth`、`Control Value` 等指标本身就是抽象的网络角色度量。它们可以通过语言进行压缩表达，例如“靠近主通路”“深藏于内部”“控制多条进出路径”。

2. 认知层面  
   人类可以根据平面图、路径说明和空间文字描述形成心智模型并进行行为推断。LLM 的训练数据中也包含大量类似的语言关联。

3. 方法层面  
   本研究不会直接假设模型具备这种能力，而是通过前置理解门控与推理测试确认模型能够从文本空间描述中提取结构性线索。

这一前提仍然存在明确局限：

- 文本不能完整复现 embodied affordance。
- 文本空间可能更接近“语言化的空间常识”而不是“真实空间推理”。
- 因此本研究定位为 **proof of concept**，不是对物理空间理论的完备验证。

即使空间文本不能完整保留物理空间的因果机制，本研究仍有价值，因为它可以回答：**LLM 是否已经习得了足以用于 Agent 世界建模的空间-行为关联知识。**

## 三、研究问题与主张边界

### 3.1 研究问题

**RQ1（验证性）**  
结构化空间表征是否比无空间、地点名、行为 affordance 基线更能诱发空间响应行为？

**RQ2（验证性）**  
这种响应中有多少沿着 Space Syntax 启发的理论方向发生？

**RQ3（验证性）**  
空间效应主要来自到位后的认知判断、Movement 决策，还是 Action Sampling？

**RQ4（探索性）**  
观察到的效应更接近结构性推理，还是更接近模型已有的语义常识激活？

### 3.2 可支撑的主张

本研究尝试支撑以下结论：

- 结构化空间表征可以系统性影响 LLM Agent 行为。
- 这种影响在关键比较中超出行为 affordance 基线。
- 其中一部分影响沿着理论预测方向发生。

### 3.3 不支撑的主张

本研究不预先支撑以下结论：

- Space Syntax 已被完整验证。
- 文本 Agent 已等价于物理环境中的人类空间行为。
- 单一空间指标具有跨场景、跨模型、跨任务的普适性。
- 所有未显著结果都可以被解释为统计功效不足。

### 3.4 效应目标

本研究优先检测中到大效应。若结果仅表现为不稳定的小效应，将不会被提升为主结论。

## 四、理论框架与核心指标

### 4.1 三个理论假设

#### H1: Integration 与社交频率

高 `Integration` 位置更可能承载主动接触、停留和公开互动。

#### H2: Mean Depth 与私密行为

高 `Mean Depth` 位置更可能承载低声交流、敏感信息分享与相对私密的互动。

#### H3: Control Value 与守门行为

高 `Control Value` 位置更可能承载巡视、阻拦、筛选信息与观察进出等守门行为。

### 4.2 主因变量

主文只保留一对核心指标。

#### `BSR`（Behavioral Spatial Responsiveness）

衡量行为是否随空间特征发生系统性变化，不区分变化方向。

#### `TAR`（Theory-Aligned Responsiveness）

衡量行为变化是否沿理论预测方向发生。

主文中不再同时展开过多变体指标。熵、时间窗变体、假设特定子指标与其他诊断量统一进入附录或补充统计表。

### 4.3 `TAR_run` 的计算 protocol

每个 `run` 的 `TAR` 通过如下步骤生成：

1. 收集该 `run` 中全部行为事件。
2. 按 location 聚合行为。
3. 仅保留访问次数 `>= 5` 的 location。
4. 对每个 location 计算目标行为率。
5. 计算行为率与对应空间指标之间的 location-level Spearman 相关。
6. 对相关系数做 Fisher z 变换，得到 run-level `TAR` 标量。

对应形式如下：

```text
rho_H1_run = Spearman(sociality_rate, standardized_Integration)
rho_H2_run = Spearman(privacy_rate, standardized_MeanDepth)
rho_H3_run = Spearman(gatekeeping_rate, standardized_Control)

TAR_Hk_run = atanh(rho_Hk_run)
BSR_Hk_run = abs(TAR_Hk_run)
```

解释规则如下：

- `TAR > 0`: 行为变化与理论方向一致
- `TAR = 0`: 无明显方向性
- `TAR < 0`: 行为变化与理论方向相反

### 4.4 指标选择规则

H2 默认使用 `Mean Depth` 作为主指标。若 `Openness` 与其他核心空间指标不发生高共线，可作为附加分析保留在补充材料中。

## 五、核心实验设计

### 5.1 设计原则

本研究采用“一个验证中心，多个支撑部件”的结构。

- `Stage 2` 是论文中心。
- `Stage 1` 用于证明表征有效性并提供实验动机。
- `Stage 3` 仅作为 gated extension，不承担主论文成立责任。
- 人类评估是主要结果之一，而不是仅作装饰性补充。

### 5.2 条件设置

#### 主比较条件

| 条件 | Movement 信息 | 到位后空间描述 | Sampling | 角色 |
|------|---------------|----------------|----------|------|
| `C1 Topology-Only` | 邻接 + 地名 + 在场数 | 无 | 无 | 主基线 |
| `C2 Behavioral Affordance` | 同 `C1` | 行为 affordance 描述 | 无 | 直接行为提示基线 |
| `C4 Full Spatial` | 空间指标 + 邻接 + 地名 | 完整结构描述 | 有 | 完整系统 |

#### 机制分解条件

| 条件 | 作用 |
|------|------|
| `C6m Perception-Matched-Movement` | 固定 movement 条件下识别到位后认知贡献 |
| `C6f Perception-Free-Movement` | 识别 movement 贡献 |

### 5.3 分解逻辑

```text
C4 - C1 = 总系统效应
        = (C6m - C1)   # 到位后认知贡献
        + (C6f - C6m)  # Movement 贡献
        + (C4 - C6f)   # Sampling 贡献
```

这一分解服务于机制解释，但不改变主论文的核心命题：**完整结构化空间系统是否有效。**

### 5.4 `C2` 的定义

`C2` 被明确定义为 **behavioral affordance baseline**，而不是“纯粹的非空间控制”。

它提供的是行为倾向线索，例如“适合安静交流”“容易发生公开互动”，但不直接提供位置在整体空间网络中的结构角色。

本研究明确承认：

- affordance 与空间结构在真实环境中存在耦合；
- `C2` 更接近现象学或行为提示；
- `C6m` 更接近结构性信息；
- 因此 `C2` 与 `C6m` 的比较检验的是“直接行为提示”与“结构性空间提示”的相对效力，而不是一个绝对纯净的空间 / 非空间二分。

### 5.5 `C2b` 辅助对照

为了测试“结构性描述格式本身”是否会制造效应，本研究增加 `C2b`：

- 描述非空间结构性特征，如窗、门、材质与家具布置；
- 不提供拓扑结构角色或行为 affordance；
- 用于判断结构化文本格式本身是否已足以改变行为。

解释规则如下：

- 若 `C6m > C2` 且 `C6m > C2b`，更支持空间结构信息的独特作用。
- 若 `C2 > C6m`，说明直接行为提示比结构性推理更强。
- 若 `C2b ≈ C6m`，说明格式效应需要被严肃讨论。

### 5.6 地图、种子与轮次

`Stage 2` 采用以下核心设计：

- 地图: `Plaza`, `Labyrinth`, `Bridge`
- `MIC seeds`: 每张图 20 个
- 条件: `C1`, `C2`, `C6m`, `C6f`, `C4`
- 每个 run: 200 至 300 轮
- NPC 数: 10

总运行数：

```text
20 seeds × 3 maps × 5 conditions = 300 runs
```

### 5.7 功效定位

按保守独立组估计，本研究主要瞄准中到大效应。若 `MIC` 在前期带来额外方差缩减，则实际功效可能略高，但不将其作为最低功效承诺的一部分。

## 六、模型与评估配置

### 6.1 主模型配置

- `Primary Actor`: `Qwen3.5-Plus`
- `Primary Judge`: `Qwen3.5-Plus`

选择理由是可复现性、成本可控性与执行效率，而不是将其视为唯一最优模型。

### 6.2 鲁棒性模型

为了降低单模型依赖风险，设置两个鲁棒性通道：

| 角色 | 模型 | 作用 |
|------|------|------|
| 鲁棒性 Actor | `Llama 3.3 70B` | 检查西方训练语料背景下的效应方向 |
| 鲁棒性 Judge | `DeepSeek-V3.2` | 检查 Actor/Judge 同源偏差 |

鲁棒性子集规模：

```text
10 seeds × 3 maps × 3 conditions (C1 / C6m / C4)
```

若主模型与鲁棒性模型在效应方向上保持一致，则增强外部效度；若不一致，则明确报告模型依赖性，不将结论泛化过度。

### 6.3 跨语言分析

若资源允许，可增加中英文场景描述对照，用于评估模型在不同语言表达下的效应稳定性。该分析不承担主论文成立责任。

## 七、人类评估

### 7.1 人类评估的角色

人类评估用于回答一个关键问题：**即使统计指标显著，这些行为差异是否对人类观察者具有可辨识的实践意义？**

因此它是主要结果之一，而不是简单的附加验证。

### 7.2 评估任务

#### 任务一：行为可信度评分

- 参与者规模: 50 人
- 评分维度: `believability`, `spatial appropriateness`
- 量表: 7 点 Likert

#### 任务二：辨别任务

- 呈现来自不同条件的行为片段，重点比较 `C4` 与 `C1`
- 问题形式: “哪个行为更符合该空间情境？”

#### 任务三：Judge 校准

- 比较人类评分与 `LLM Judge` 的一致性
- 若某评分维度一致性过低，则该维度不得进入主结果

### 7.3 解释规则

| 人类评估 | LLM 指标 | 解释 |
|----------|----------|------|
| 人类偏好 `C4` | `BSR/TAR` 显著 | 强支持 |
| 人类无法辨别 | `BSR/TAR` 显著 | 效应存在，但实践意义有限 |
| 人类偏好 `C4` | `BSR/TAR` 不显著 | 指标可能未捕捉到有效差异 |
| 人类无法辨别 | `BSR/TAR` 不显著 | 零效应或弱效应 |

## 八、结果-主张决策矩阵

本节用于约束解释逻辑，避免事后合理化。

### 模式 1：完整成功

- 结果: `C4 > C1` 显著，`BSR` 显著，`TAR` 显著且方向正确，人类偏好 `C4`
- 可主张: 结构化空间表征能够系统性改变行为，且部分变化沿理论方向发生

### 模式 2：响应存在，但理论方向较弱

- 结果: `C4 > C1` 显著，`BSR` 显著，但 `TAR` 弱或不稳定
- 可主张: 空间表征影响行为，但理论对齐性有限

### 模式 3：完整系统有效，但机制不清晰

- 结果: `C4 > C1` 显著，`C6m/C6f` 分解不稳定
- 可主张: 系统级效应成立，但机制来源仍需进一步分析

### 模式 4：仅前期窗口有效

- 结果: 前 50 轮显著，后期衰减
- 可主张: 空间信息具有 priming 作用，但可能被记忆或历史路径吸收

### 模式 5：行为 affordance 强于结构提示

- 结果: `C2 > C6m`
- 可主张: 直接行为提示比结构化空间提示更强

### 模式 6：短任务有效，长时程弱化

- 结果: `Stage 1` 强，`Stage 2` 弱
- 可主张: 空间表征在低复杂度任务中有效，但在长时程社会模拟中被稀释

### 模式 7：整体零效应

- 结果: 主要比较均不显著，人类评估也不支持
- 可主张: 当前形式的结构化空间表征不足以稳定改变 LLM Agent 行为

### 不允许的解释

以下类型的解释不应在结果出来后临时上升为主张：

- 仅凭未预设的小效应宣称“理论上依然重要”；
- 借未预设子群体结果替代主分析；
- 用偶然显著的交互项替代不成立的主效应。

## 九、实验阶段安排

### 9.1 Stage 1：表征有效性

目的：证明表征格式是否值得进入长时程模拟。

包含两个部分：

- `Exp1A`: 微任务层面的多条件对比
- `Exp1C`: 补充性的 2×2 设计，用于观察 composite structural profile 与语义标签之间的竞争关系

`Exp1C` 不承担 `H1/H2` 独立因果检验责任，只作为 supporting evidence。

### 9.2 Stage 2：核心验证

这是整篇论文的证据中心。

主要比较包括：

1. `C4 vs C1`: 总系统效应
2. `C6m vs C1`: 到位后认知贡献
3. `C6m vs C2`: 结构提示与行为 affordance 的对比
4. `C6f vs C6m`: Movement 贡献
5. `C4 vs C6f`: Sampling 贡献

同时检查跨地图一致性：

- 效应方向是否在三张图上保持一致
- 效应量是否受到地图构型调节

### 9.3 Stage 3：扩展阶段

只有当 `Stage 2` 达到以下门槛时才进入：

- 至少一个主比较经 FDR 校正后 `p < 0.05` 且 `d >= 0.5`
- 或未达显著，但方向稳定且具中等效应量

`Stage 3` 不影响主论文的成立与否。

## 十二、主要风险与应对

| 风险 | 可能性 | 应对方式 |
|------|--------|----------|
| 文本空间不能保留有效结构信息 | 高 | 前置理解与推理门控；将结论限定为 proof of concept |
| `C2` 泄露空间语义 | 中 | reverse-inference audit + `C2b` |
| 主模型存在文化或训练语料偏差 | 中 | `Llama 3.3` 与 `DeepSeek` 鲁棒性子集 |
| `MIC` 价值有限 | 高 | 不将其写为主贡献，只作为方差控制工具 |
| 人类无法辨别 `C4` 与 `C1` | 中 | 在结果矩阵中按“实践意义有限”处理 |

| `TAR` 弱但 `BSR` 强 | 中 | 按“响应存在，但理论方向弱”解释，不扩大结论 |

## 附录 A：技术规格

### A.1 `TAR_run` 详细计算

1. 对每个 `run` 按 location 汇总行为事件。
2. 丢弃访问次数低于 5 次的 location。
3. 计算 location-level 行为率。
4. 将 location-level 行为率与对应空间指标做 Spearman 相关。
5. 用 Fisher z 变换得到 run-level 标量。

### A.2 `BSR` 的生成

```text
BSR_Hk_run = abs(TAR_Hk_run)
```

若需要 overall 指标，可对可检验假设的 `BSR_Hk_run` 做均值聚合，但主文不将其作为唯一证据来源。

### A.3 `MIC` 有效窗口预检

通过 matched 与 unmatched 条件的差异方差比较估计 `MIC` 的有效窗口，并报告不同时间段的 `ICC(seed)`。

建议至少报告三个窗口：

- `0-50`
- `51-100`
- `101-200+`

## 附录 B：编码信度 protocol

### B.1 编码对象

- 行为类型
- 交互强度
- 信息敏感度
- 守门行为

### B.2 编码流程

1. 编制 coding manual。
2. 使用 `200-300` 个样本进行双人独立 pilot 编码。
3. 计算各维度一致性。
4. 对低一致性维度修订定义或降级粒度。

### B.3 阈值

- 行为类型: `kappa >= 0.70`
- 交互强度: `kappa >= 0.67`
- 信息敏感度: `kappa >= 0.67`
- 守门行为: `kappa >= 0.60`

若 `LLM-human` 在某维度上 `kappa < 0.60`，该维度不得直接进入主结果。

## 附录 C：`Exp1C` 的定位

`Exp1C` 采用 2×2 设计：

| | 语义=公共 | 语义=私密 |
|---|:---:|:---:|
| public-structural profile | 一致 | 冲突 |
| private-structural profile | 冲突 | 一致 |

该实验的作用是检验：

- Agent 是否对结构 profile 与语义标签的冲突作出不同反应；
- 结构性线索是否在一定程度上能与语义线索竞争。

它不用于单独识别 `Integration` 或 `Mean Depth` 的独立因果效应。
