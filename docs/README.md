# SpatialAgent Docs Index

本目录是仓库唯一的文档目录，和 `assets/`、`scripts/`、`spatial-agent-core/` 处于同一级。

## Sections

- `plans/`: 主研究计划、历史版本、survey plan
- `experiments/`: 实验设计与 preflight 文档
- `background/`: Space Syntax 理论与 related work
- `reviews/`: reviewer challenge 与 plan review
- `guides/`: 项目搭建、研究推进、写作指导
- `references/`: 文献索引与资料来源说明
- `surveys/`: survey 正文与综述材料
- `vision/`: 方向构想
- `decisions/`: 关键决策记录
- `meeting_notes/`: 会议纪要

## Quick Start

1. `plans/README.md`
2. `reviews/README.md`
3. `plans/plan_v7.md`
4. `experiments/preflight_experiments.md`
