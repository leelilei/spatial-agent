# SpatialAgent Docs Index

本目录是仓库唯一文档目录，和 `spatial-agent-core/` 代码子项目处于同一级。

## 文档分区

- `plans/`
  - 当前总研究计划
  - 各版本迭代研究计划
  - survey 研究计划
- `experiments/`
  - 实验设计文档
  - preflight 预实验说明与报告
- `background/`
  - Space Syntax 理论笔记
  - related work 梳理
- `reviews/`
  - reviewer challenge 报告
  - 各版 research plan review
- `guides/`
  - 项目搭建指南
  - 研究推进与写作指导
- `references/`
  - 参考文献清单与资料来源
- `surveys/`
  - survey 正文与综述材料
- `vision/`
  - 愿景草案与早期方向探索
- `decisions/`
  - 关键决策记录
- `meeting_notes/`
  - 会议纪要
