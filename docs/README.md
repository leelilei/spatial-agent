# SpatialAgent Docs Index

`docs/` 是仓库唯一的文档主目录，与 `assets/`、`scripts/`、`spatial-agent-core/` 同级。

## Sections

- `plans/`: 主研究计划、历史版本、survey plan
- `reviews/`: challenge、review 与历史评审记录
- `experiments/`: 实验设计、preflight 文档与实验说明
- `guides/`: setup、研究执行、写作与使用指引
- `background/`: Space Syntax 理论、related work、survey 背景材料
- `project/`: 项目级辅助文档，如决策、会议纪要、参考索引、vision 记录

- `docs/` 只保留说明性文档。
