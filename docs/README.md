- `plans/`
  - SpatialAgent 各版本研究计划
  - Survey 研究计划
- `guides/`
  - 项目搭建指南
  - 研究与写作指导材料
- `references/`
  - 参考文献清单与论文资料来源

  - 各版 research plan 的评审与 review 文档
- `surveys/`
  - Survey 正文与相关综述材料
- `vision/`

- `decisions/`
  - 研究过程中的关键决策记录
- `meeting_notes/`
  - 会议纪要与讨论记录
