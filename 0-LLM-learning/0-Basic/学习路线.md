# CS 学习路线（零基础 → 看懂并能跑 AI 项目）

> 这是一份为「计算机小白」定制的精简学习计划。
> 目标：能读懂、跑通、并改改像 `nanochat` 这样的 AI 项目。
> 节奏：每周约 5 小时，预计 **3 个月** 达到目标。

---

## 这份计划的原则

1. **目标导向**：只学「跑通和读懂 AI 项目」真正用得上的东西，传统 CS 本科 90% 的内容暂时跳过。
2. **边学边用**：不空学理论，每个阶段都拿真实项目练手。
3. **够用就好**：数学和底层原理只学「直觉」，用到再深入，绝不一开始就啃硬骨头。
4. **能跑起来 > 完美理解**：先让东西动起来，建立成就感，再回头补原理。

---

## 五个阶段总览（每阶段配一门主线课程）

| 阶段 | 主题 | 主线课程 | 时长 | 学完能做什么 |
|------|------|----------|------|--------------|
| 1 | Python 基础 | MIT 6.100L | 4-6 周 | 看懂一段 Python 代码每行在干嘛 |
| 2 | 命令行 + 环境管理 | MIT Missing Semester（缺失的一课） | 1-2 周 | 把 GitHub 项目下载并成功跑起来 |
| 3 | 读懂一个真实项目 | nanochat 项目 + Karpathy micrograd | 2-3 周 | 改参数、跑小实验 |
| 4 | 够用的 AI 概念 | Karpathy《Zero to Hero》+ 3Blue1Brown | 4-6 周 | 明白 nanochat 每步在做什么 |
| 5 | 补数学直觉（可选） | 3Blue1Brown 本质系列 + StatQuest | 穿插 | 想深入时再补，不挡路 |

## 阶段 1：Python 基础 —— 跟 MIT 6.100L 走（4-6 周）

**为什么先学**：AI 项目几乎全用 Python 写，这是唯一绕不开的语言。

**主线**：用 **MIT 6.100L《Introduction to CS and Programming using Python》(Fall 2022)** 当教材。
它是 6.0001 的升级版，同一个老师 Ana Bell，专为零基础重做——节奏更慢、例子更多、每节更短，最适合「小白 + 每周 5 小时」。
- 视频播放列表（YouTube）：https://www.youtube.com/playlist?list=PLUl4u3cNGP62A-ynp6v6-LGBCzeH3VAQB
- 课程主页（OCW，免费讲义/作业）：https://ocw.mit.edu/courses/6-100l-introduction-to-cs-and-programming-using-python-fall-2022/
- **讲义/代码/习题集已下载到本地**：见 [`MIT-6.100L/`](MIT-6.100L/README.md)（视频在线看）

**关键原则：做减法，不为学课而学课。** 全课 26 节，但你的目标只需扎实学下面标 ✅ 的，
标 ⏸️ 的（复杂度、排序）暂时跳过，以后想深入再回来。

## 阶段 2：命令行 + 环境管理（1-2 周）

**为什么**：跑别人的项目，第一关就是「装环境、敲命令」。这一步卡住的人最多。

**主线课程**：**MIT《The Missing Semester of Your CS Education》（计算机教育中缺失的一课）**
专门教学校不教、但天天要用的工具——终端、Shell、Git。短小精悍，有官方中文版。
- 中文版：https://missing-semester-cn.github.io/
- 英文原版：https://missing.csail.mit.edu/

**只需看这几节**（其余对你超纲，跳过）：
- [ ] 第 1 课　Course overview + the shell（命令行基础）　✅
- [ ] 第 2 课　Shell Tools and Scripting（了解即可）　🔶
- [ ] 第 6 课　Version Control (Git)　✅ 重点
- 其余（编辑器 Vim、元编程、安全等）⏸️ 暂时跳过

### 配合要学的内容
- [ ] 终端基本命令：`cd`（切目录）、`ls`（看文件）、`pwd`（看当前位置）
- [ ] 用 `python xxx.py` 跑一个脚本
- [ ] 虚拟环境：理解「为什么每个项目要单独的环境」，会用 `venv` 或 `conda`
- [ ] 装包：`pip install 包名`
- [ ] Git 基础：`git clone`（下载项目）、`git status`、`git log`
- 补充：[菜鸟教程 Git](https://www.runoob.com/git/git-tutorial.html)（当速查手册）

### 自测：你应该能独立完成
> 从 GitHub 下载一个小项目 → 建好虚拟环境 → 装好依赖 → 成功运行

## 阶段 3：读懂一个真实项目（2-3 周）

**为什么**：直接拿手边的 `nanochat` 当教材，学以致用。

**主线**：以 **`../nanochat/` 项目本身** 为教材（它的作者 Andrej Karpathy 也是阶段 4 课程的老师，一脉相承）。
**热身可选**：Karpathy《Zero to Hero》第 1 集 **micrograd**——一个只有百来行、可完整读懂的迷你项目，
是「读懂真实代码」的最佳练手，也顺带过渡到阶段 4。
- 视频：https://www.youtube.com/watch?v=VMj-3S1tku0

### 要学的内容
- [ ] 看懂项目文件结构：`README` 怎么读、主要文件夹是干嘛的
- [ ] 找到「入口文件」，跟着代码读主流程
- [ ] 看懂报错信息：错误一般在最后几行，学会定位
- [ ] 改改配置/参数，重新跑，观察变化

### 怎么做
- 打开 `../nanochat/`，先读它的 `README`
- 遇到看不懂的代码/报错，直接问我，我帮你逐行解释
- 目标不是全懂，是「能动手实验」

## 阶段 4：够用的 AI 概念（4-6 周）

**为什么**：理解你在跑的东西到底是什么。只学直觉，不啃硬数学。

**主线课程**：**Andrej Karpathy《Neural Networks: Zero to Hero》**
他从零手写一个神经网络，一路搭到 GPT，每行代码都讲清楚。和 nanochat 同一个作者，最对口。
- 播放列表：https://www.youtube.com/playlist?list=PLAqhIrjkxbuWI23v9cThsA9GvCAUhRvKZ
- 建议顺序：micrograd（已在阶段 3 看）→ makemore 系列 → **Let's build GPT**

**配套建立直觉**（先看这个再去啃代码，事半功倍）：
- **3Blue1Brown 神经网络系列**（B 站有中文字幕，直觉一流）
- **3Blue1Brown「深度学习之 Transformer / 注意力机制」**（理解 LLM 核心）
- 文章：Jay Alammar「图解 Transformer」（搜中文翻译版）

### 要学的内容
- [ ] 基本词汇：什么是「模型」「参数」「训练」「推理」
- [ ] 神经网络的直观理解（不用算公式）
- [ ] 什么是 Token、词向量（文字怎么变成数字）
- [ ] Transformer / LLM 的基本思想：「注意力」在干嘛
- [ ] 训练一个语言模型大概是怎么回事

## 阶段 5：补数学直觉（可选，穿插进行）

**为什么**：想更深入时再补，不挡路。**建议用到时再学，不要一开始就啃。**

**主线课程**：**3Blue1Brown「本质系列」**——用动画讲数学直觉，不推公式，最适合补感觉。
- 「线性代数的本质」（向量、矩阵到底是什么）：B 站搜「线性代数的本质」
- 「微积分的本质」（导数、梯度——训练模型的核心）：B 站搜「微积分的本质」
- 概率/统计直觉：**StatQuest**（YouTube/B 站，号称「最通俗的统计课」）

### 要学的内容
- [ ] 向量、矩阵是什么（线性代数直觉）
- [ ] 导数 / 梯度是什么（模型怎么「学」）
- [ ] 概率基础：什么是概率分布

## 贯穿全程的横向技能：AI 辅助开发（vibe coding）

**这不是某一个阶段，而是一条贯穿 1-5 阶段的辅助线。** 你现在用 Claude Code 学习，本身就是 vibe coding。

**主线课程**：斯坦福 **CS146S《The Modern Software Developer》**
教怎么用 AI 工具（Cursor / Copilot / Claude Code 等）高效开发。
- 网站：https://themodernsoftware.dev/
- **建议时机**：阶段 2 之后再正式看（那时你已会基本命令行和写代码，学工具才接得住）。

### ⚠️ 一条铁律（最重要）
> **用 AI 帮你「解释 + 加速」，而不是「代替你理解」。**
> 你的目标是**看懂**代码——如果全靠 AI 生成、自己从不读懂，就永远到不了目标。

### 怎么用，分阶段
- **阶段 1-3（打基础）**：让 AI 当助教——解释概念、查报错、出练习题；但**代码尽量自己敲一遍**。
- **阶段 3-4（跑项目）**：放开用 AI 加速——读懂大项目、快速做实验、改参数。
- 自检：每次 AI 给你一段代码，问自己「我能逐行讲出它在干嘛吗？」答不上来就让它解释。
