# Chinese ASR Compression

Independent research workspace for cross-architecture Chinese ASR compression and on-device deployment.

## Scope

This project focuses on:

- Chinese ASR model compression across AR, NAR, and LLM-based architectures.
- Whisper, Paraformer, SenseVoice, and related mobile deployment baselines.
- Offline/mobile ASR evaluation under accuracy, latency, memory, and power constraints.
- Recorder-to-phone edge deployment scenarios.
