# Reference Collection Guide

Use this guide when collecting references for Telephone.

## Current Thesis

The paper is centered on:

- fidelity decay in LLM-agent societies;
- speech-belief dissociation;
- path-dependent entrenchment of early, broad social evidence;
- failed natural levers: capability, connectivity, memory swaps, and persistent authority;
- brute broadcast as an overwrite-style positive control, not a realistic cure.

## Collection Priorities

1. Find must-cite papers that make the setting legitimate: generative agents, Concordia,
   multi-agent LLM communication, and MAS failure work.
2. Find closest competing papers from 2025-2026: benign MAS misinformation, hallucination
   cascade, agent scaling laws, social simulations with LLM populations.
3. Build the mechanism backbone: continued influence, misinformation correction,
   first-mover advantage, path-dependence, serial reproduction, iterated learning.
4. Build the framing backbone: model collapse, self-consuming models, diversity collapse.
5. Build the metric backbone: LLM judge reliability, factuality/hallucination evaluation,
   provenance-aware scoring.

## Inclusion Rule

For every reference, write the exact paper sentence it supports. If no sentence is obvious,
keep it in a candidate list instead of promoting it to `paper/references.md`.
