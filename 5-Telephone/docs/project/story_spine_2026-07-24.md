# DAI 2026 story spine

## One-sentence argument

A fact can win the conversation without updating the society; fixed-evidence
interventions locate a consequential part of this failure in listener-side
integration, motivating a provenance-preserving and authenticated state-update
interface between communication and memory.

## Four-act evidence chain

1. **The apparent success:** an authoritative source makes the current value
   more visible in public event talk.
2. **The reversal:** population-wide private retrieval barely moves, so the
   transcript is not a sufficient proxy for the society's retrievable state.
3. **The diagnosis and repair:** fixed streams isolate listener-side memory;
   complete-pipeline replay gains 28.5 points, cross-source replay gains 26.0
   points, and the matched selector isolates a 9.0-point benefit from version
   priority over mention frequency.
4. **The protocol boundary:** the repair works only when provenance survives
   relay and is authenticated; missing and corrupted metadata fail differently.

## Main-figure jobs

- **Appendix figure — statistical detail:** seed-level Said/Held trajectories
  and overwrite control.

## Claim boundaries

- The headline is a society-level mismatch, not widespread within-agent
  “said then forgot” behavior.
- The 28.5-point replay contrast is a complete-pipeline effect, not a pure
  selector effect.
- The 9.0-point selector contrast is conditional on supplied versions.
- The experiments do not validate automatic provenance extraction or provide
  a general security guarantee.
- Controlled memory adaptations are mechanism comparisons under one harness,
  not official implementation leaderboards.

## Editorial rule

Every new experiment, table, or figure must advance one of the four acts above.
Supporting robustness that does not create a new turn in the argument belongs
in the appendix.
