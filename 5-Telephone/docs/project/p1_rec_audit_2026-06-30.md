# P1-rec 配置审计与撤回（2026-06-30）

## 结论

P1-rec 的“早期全体广播成功、晚期全体广播失败”对照无效，相关 entrenchment / recency
机制结论撤回。

## 原始日志证据

逐个读取 `sim/runs/p1rec/{r1_broadcast,r5_broadcast}/.../round_*.json` 的 `injected` 字段：

- `r1_broadcast`：5/5 runs 均在 round index 1 向 25/25 agents 注入，配置实际执行。
- `r5_broadcast`：5/5 runs、全部 round logs 的注入数均为 **0**。

最可能的原因是把第五轮写成 round index `5`，而五轮模拟只执行 `0..4`。因此原来的
`r5_broadcast ≈ baseline` 只是“无注入 ≈ baseline”，不能说明晚期纠正失败。

## 修正复现

使用当前代码把最后一轮正确指定为 index `4`，并锁定原配置：

- model: `gpt-5.4-mini`
- GA-equivalent memory: `thaw_ga`, `forget_rate=0`
- 25 agents, meetings=2, rounds=5, turns=3, seed=41
- scope=`broadcast`, `rebroadcast_rounds=4`

结果：**25/25 current, 0 stale, 0 unknown**。

数据：`../../../../7-Thaw/runs/h1_baseline_gate_2026-06-30/`。

## 影响范围

- 保留：fidelity decay、persistent single-source failure、SAY/HOLD operational distinction、
  broadcast positive control、PROV/APM comparisons（各自仍需独立审计）。
- 撤回：P1-rec 对 recency 的反驳；“晚期全体广播失败”；由该对照推出的早期/广泛
  path-dependent entrenchment 机制。
- Thaw 不能再以“修复已证明失败的晚期全体广播”为前提。必须先构造并验证一个真实失败、
  且在遗忘率为零时稳定复现的 late-correction condition（候选：晚期单一权威源，而非全体覆盖）。
