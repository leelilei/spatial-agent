# Reference Sources

Telephone keeps its local reference material under:

```text
../../assets/papers/
```

## Current Reference Files

- `../../paper/references.md`: curated working reference library for the paper.
- `../../assets/papers/metadata/reference-report.md`: broad reference discovery report
  generated from the current experiment conclusions and paper framing.
- `../../telephone-research.md`: earlier literature review used by proposal v1.

## Local Paper Library Layout

- `assets/papers/metadata/`: generated reports, search exports, candidate-paper lists.
- `assets/papers/pdf/`: selected PDFs only, grouped later by topic.
- `assets/papers/notes/`: short human-readable notes for papers we actually cite.

## Priority Buckets

1. **Must-cite setting:** Generative Agents, Concordia, communication-centric MAS surveys.
2. **Closest neighbors:** misinformation propagation in benign MAS, hallucination cascades,
   MAS failure taxonomies, scaling-agent-system work.
3. **Mechanism support:** serial reproduction, iterated learning, continued influence,
   first-mover/path-dependence, collective bias and convention formation.
4. **Framing support:** model collapse, self-consuming models, diversity collapse.
5. **Metric support:** LLM-as-judge reliability, hallucination/factuality benchmarks,
   provenance-aware evaluation.
6. **Memory/correction:** RAG, Reflexion, A-MEM/APEX-MEM, memory error propagation.

## Source Policy

Do not bulk-copy broad paper libraries into Telephone. Add a PDF, note, or BibTeX entry
only when it directly supports a paper claim, experiment design, metric, or related-work
positioning. Every included reference should answer: "What sentence in our paper does this
make stronger?"
