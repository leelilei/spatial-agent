# GA-generated cross-source integration audit (2026-07-23)

## Decision

The cross-source replay passes. On eight independently generated GA society
streams, replacing the complete listener pipeline with provenance-aware
integration raises current private answers from 15.0% to 41.0%. This reduces
the concern that the original +28.5-point replay effect exists only because its
source dialogue was generated by PROV.

The result remains conditional: GA dialogue contains no native structured
provenance, so the controlled task supplies versions for unambiguous current
and stale mentions. It is not an end-to-end provenance extraction result.

## Design

- Source streams: eight accepted one-shot-update GA societies, seeds 41--48.
- Independent unit: one realized society stream / schedule seed.
- Sample: 25 agents per seed; 200 paired listener streams.
- Frozen input: identical GA-generated text for both replay memories.
- Supplied metadata: current-only mentions receive version 1; stale-only
  mentions receive version 0; mixed mentions remain unannotated; the direct
  authoritative injection receives version 1.
- Manipulation: complete GA versus complete PROV listener pipeline.
- Failure policy: an incomplete condition is not scored; per-agent checkpoints
  resume missing agents.

## Results

| Listener | Current | Stale | Unknown | Pooled counts |
|---|---:|---:|---:|---:|
| GA | 15.0% [7.9, 22.1] | 8.0% [0.0, 16.0] | 77.0% [67.1, 86.9] | 30 / 16 / 154 |
| PROV | 41.0% [28.1, 53.9] | 19.0% [0.4, 37.6] | 40.0% [24.4, 55.6] | 82 / 38 / 80 |

Paired PROV-minus-GA current-answer differences by seed were
`+24, +32, +44, +32, +32, +8, +16, +20` percentage points. The mean paired
lift is **+26.0 points [16.5, 35.5]**. PROV is higher in 8/8 seeds; exact
two-sided sign-test `p = 0.0078125`.

PROV also converts some otherwise unknown listeners into stale answers when
only version-0 evidence reaches them. Consequently, the net
current-minus-stale paired interval is +15.0 points [−5.9, 35.9]. The main
supported outcome is increased current retrieval, not a general reduction in
all errors.

## Valid interpretation

Use:

> In a complementary replay over eight GA-generated society streams, with
> controlled-task versions supplied only to unambiguous value mentions,
> provenance-aware integration raised current private answers from 15.0% to
> 41.0% (paired difference +26.0 percentage points, 95% CI [16.5, 35.5];
> positive in 8/8 seeds). The listener-side effect therefore persists beyond
> PROV-generated dialogue support, conditional on correct version metadata.

Do not use:

- “The replay is architecture-neutral end to end.”
- “GA dialogue naturally preserves provenance.”
- “PROV reduces every error category.”
- “The experiment validates automatic version extraction.”
