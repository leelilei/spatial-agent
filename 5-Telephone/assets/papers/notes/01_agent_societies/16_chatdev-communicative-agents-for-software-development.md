# ChatDev: Communicative Agents for Software Development

## Deep Read Status

Deep-read note completed for Telephone. This note is written from the local
PDF/fulltext and is intended to support citation triage, related-work drafting,
and claim-boundary checking.

## Why This Paper Matters For Telephone

ChatDev is background for the idea that agents can communicate as members of a simulated organization. It helps explain why Telephone's society setting is realistic, but it is not a close conceptual neighbor.

## Core Question

The paper asks whether software development can be simulated as a virtual company of communicative LLM agents.

## Method / Evidence Base

It decomposes development into conversational phases among role-specialized agents, producing artifacts through dialogue.

## Core Claim / Result

The relevant point is that complex work can be coordinated through repeated agent messages. The paper does not study factual update fidelity or social belief formation.

## Evidence We May Cite

- Role-specialized LLM agents can use dialogue to coordinate multi-step work.
- Communication chains are a practical design pattern for agent systems.
- The paper gives examples of organization-like agent interaction.

## Telephone Bridge

- Fidelity vs reach: task dialogue is not evidence that factual state remains current.
- Speech vs belief: produced artifacts and conversations do not reveal later agent belief.
- Measurement / rigor: Telephone contributes a targeted probe absent from task-completion frameworks.

## What We Add Beyond This Paper

Telephone shifts from productivity-oriented collaboration to information-fidelity measurement inside a communicating group.
