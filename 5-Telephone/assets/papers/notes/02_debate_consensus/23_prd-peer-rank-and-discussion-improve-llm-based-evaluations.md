# PRD: Peer Rank and Discussion Improve LLM based Evaluations

## Deep Read Status

and claim-boundary checking.

## Why This Paper Matters For Telephone

PRD is only moderately relevant. It shows that peer discussion can improve LLM-based evaluation, but the endpoint is ranking candidate answers rather than factual state transmission.

## Core Question

The paper asks how to improve reference-free LLM evaluation of open-ended answers by combining peer ranking and discussion.

## Method / Evidence Base

It has multiple evaluator agents rank candidate responses and discuss disagreements before producing final evaluations.

## Core Claim / Result

The paper supports the idea that discussion can improve evaluation quality, but it also reinforces that multi-agent methods often measure final aggregate output rather than individual belief change.

## Evidence We May Cite

- Peer discussion is used as a mechanism for LLM evaluation.
- Multi-agent evaluation can be framed as ranking and consensus over candidate outputs.
- The paper is a methodological cousin, not a phenomenon neighbor.

## Telephone Bridge

- Measurement / rigor: useful if we discuss LLM-as-judge or group evaluation methods.
- Speech vs belief: evaluator discussion may produce a ranking without exposing durable beliefs.
- Fidelity vs reach: not about content propagation.

## What We Add Beyond This Paper

Telephone focuses on ground-truthed social transmission rather than evaluator aggregation.
