# Argument map

```text
官方特征框规模有限
        │
        ├─ 双人盲审发现稳定的新增同类构件
        │           │
        │           ├─ 原始标注召回明显低于 1
        │           └─ 漏标与尺度/遮挡/视角存在规律
        │                       │
        │                       ▼
        │          运行 PN / Ignore / PU / Oracle
        │                       │
        │           ┌───────────┴───────────┐
        │           │                       │
        │       Oracle 明显更好         无最终分类差异
        │           │                       │
        │       继续方法开发              停止或重构
        │
        └─ 未发现稳定漏标或一致性很低
                    │
                 停止该假设
```

模型部分成立所需的最小证据链：

1. 盲审证明存在真实漏标；
2. Oracle 相比 PN 改善局部定位；
3. Oracle 相比 PN 改善最终分类；
4. Ignore/现有 PU 尚未消除全部差距。
