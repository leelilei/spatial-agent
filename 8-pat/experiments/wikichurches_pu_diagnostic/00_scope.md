# 阶段一实验范围

## 本轮目标

验证 WikiChurches 的局部构件框是否足以支持“不完整正例标注”研究假设，并建立进入模型实验前的证据门。

本轮只回答：

1. 官方框标注的规模、类别分布、构件分布和空间尺度是什么；
2. 能否得到一个可复现、分层、双人盲审的 50 图样本；
3. 人工补全后，原始框的构件级召回率和新增正例比例是多少；
4. 是否值得启动 PN / Ignore / PU / Oracle 四组模型诊断。

## 暂不声称

- 框外区域已经被证明包含大量漏标正例；
- 普通 PU 风险估计适合真实的漏标机制；
- 新方法优于现有方法；
- CUB 的部件点可直接视为完整区域框。

## 阶段门

只有在双人盲审完成、争议项完成裁决，并且漏标现象跨多个风格或构件稳定存在后，才启动完整模型训练。
