# 实验目的

验证以下问题是否真实存在：

> 当最终类别标签对所有训练图像可用、但部件 mask 只在非随机选择的样本子集
> 中可用时，无条件使用部件监督是否比随机提供相同数量 mask 更容易造成最终
> 分类负迁移。

若问题成立，进一步检验最小 support-aware 机制能否在不完全关闭局部分支的
情况下减少伤害。

# 冻结协议

机器可读协议：

`experiments/mnar_privileged_part_learning/configs/PAT-C-260728-001_protocol.json`

核心边界：

- 使用官方 PartImageNet Seg split；
- pilot 只取 Quadruped 中 train 样本最多的 20 类；
- 完整 mask 只作为隐藏 Oracle；
- 部件标注率固定为 20%；
- 比较 MCAR、MAR-X、MNAR-Z 和 SI-Hard；
- 使用 3 个固定 seed；
- train-only 五折 OOF 选择候选；
- validation 在 manifest 和超参数冻结后只读取一次；
- test 禁止解码和编码。

协议在实际数据内容检查前完成一次操作性澄清：固定五折 seed、精确标注
数取整规则、无放回加权抽样算法，以及分层超参数选择顺序。当前冻结协议
SHA256 为
`c5ce3fc5dc11372c38babf3183c90250e8742df9b514967805a5b0aab011b914`。
OpenCLIP 的运行时检查显示 OpenAI 权重要求 QuickGELU 参考架构，因此在
读取任何实际样本前将编码器名称显式固定为
`ViT-B-16-quickgelu:openai`，避免静默使用不匹配的激活函数。

# Go / No-Go

必须同时满足：

1. Full-part Oracle 相对 Global 提高至少 2pp；
2. Naive 在偏置机制下呈现可重复额外负迁移；
3. Support-aware 平均相对 Global 提高至少 1pp；
4. 最差类别下降不超过 2pp；
5. 最困难机制相对 Naive 提高至少 2pp；
6. 激活率为 10%–90%，覆盖至少 80% 类别；
7. 三个 seed 的聚合方向一致。

若方法只通过关闭局部分支满足安全条件，同样判定 No-Go。

# 结果

官方 Seg archive 的大小和 SHA256 均通过校验。train-only 冻结清单包含
Quadruped 20 类、每类 80 张，共 1,600 张；validation 在超参数冻结后一次性
读取，共 170 张。

train-only 五折 OOF：

- Global balanced accuracy：91.8125%；
- 选中 Full-Part Oracle：93.8125%；
- Oracle 增益：+2.0000pp；
- 最差类别差：−1.2500pp。

一次性 validation、三个固定 seed：

| Seed | Global BA | Oracle BA | 增益 | 最差类别差 |
|---:|---:|---:|---:|---:|
| 1307 | 91.5972% | 92.1528% | +0.5556pp | −11.1111pp |
| 2607 | 91.0417% | 91.5972% | +0.5556pp | −11.1111pp |
| 5207 | 91.0417% | 92.1528% | +1.1111pp | −11.1111pp |

平均 Oracle 增益为 +0.7407pp，低于预注册 +2pp 门槛；所有 seed 虽然方向
为正，但均出现 −11.1111pp 的最差类别伤害。因此触发自动 No-Go。

# 裁决

停止当前“冻结 CLIP 线性部件注意力 + additive local-logit residual”机制，不再
运行 NAIVE、CLIPPED-IPW 与 SUPPORT_AWARE。该裁决不否定研究问题，只说明当前
机制没有足够的 full-part Oracle 上界，继续做缺失纠偏缺乏意义。

下一候选必须更换核心机制：先独立复现 Privileged Pooling 风格的训练期监督
注意力，并允许有限 backbone adaptation；推理时不使用 additive local logits。
新实验不得继续用 PAT-C-260728-001 validation 调参。
