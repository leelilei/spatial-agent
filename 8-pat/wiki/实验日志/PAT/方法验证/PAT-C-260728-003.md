# 目的

`PAT-C-260728-001/002` 已分别否定 additive local residual 和冻结 patch token
上的 Privileged-Pooling 风格小头。本实验执行预注册的最后一次机制升级：解冻
CLIP 视觉编码器最后一个 residual block 与 `ln_post`，检验部件监督在可改变
共享表征后是否建立正向 Oracle 上界。

# 冻结边界

- 沿用已冻结的 1,600 张 train 清单和五折；
- validation/test 均禁止读取和编码；
- 不做超参数搜索；
- 比较相同适配预算下的 Global 与 Full-Part Oracle；
- 预注册门槛：Oracle 相对 Adapted Global 至少 +2.5pp，最差类别不低于
  −2pp；
- 协议 SHA256：
  `e826034b58439087915f42cb1f784b2e5c3d0d1d63a409a71a822dcded960d08`。

# 结果

| Arm | OOF Balanced Accuracy | 相对强参考 | 最差类别差 |
|---|---:|---:|---:|
| Adapted Global | 94.5625% | — | — |
| Adapted PrPool Full-Part Oracle | 94.0625% | −0.5000pp | −2.5000pp |

Global 在有限适配后明显强于冻结特征版本，但完整部件监督没有进一步提高分类，
而是产生 0.50pp 平均下降和 2.50pp 最差类别下降。判定 No-Go。

# 裁决

依据预注册停止规则，停止 PartImageNet 上该方法族的开发，不运行
MCAR/MAR/MNAR correction arms，也不读取 validation/test。该结果否定当前
PartImageNet 机制路线，不否定“非随机缺失部件特权标注”这一问题本身。

下一步必须二选一：

1. 在已有正向部件监督先例的数据集上先复现正 Oracle，再研究选择性缺失；
2. 将工作定位为选择性部件标注导致负迁移的诊断/基准，而不是新方法。
