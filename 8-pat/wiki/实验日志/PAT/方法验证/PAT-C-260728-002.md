# 目的

`PAT-C-260728-001` 的 additive local-logit residual 未通过 full-part Oracle
门。核对 Privileged Pooling 论文和官方代码后，本实验更换整个局部机制，检验
论文式监督注意力池化能否在不读取 validation 的情况下建立足够 Oracle 上界。

# 冻结边界

- 沿用已冻结的 1,600 张 train 清单和五折；
- validation/test 均禁止读取和编码；
- 强参考为已有 CLIP CLS Global OOF；
- 预注册门槛：相对强参考至少 +2.5pp，最差类别不低于 −2pp；
- 协议 SHA256：
  `02dc3bb2ff6160d2502c404b0be59082e4b5a5e6e5ddb2063cbd4539e445d882`。

# 结果

| Arm | OOF Balanced Accuracy | 相对强参考 | 最差类别差 |
|---|---:|---:|---:|
| CLIP CLS Global | 91.8125% | — | — |
| Patch Average | 85.0000% | −6.8125pp | — |
| 最佳 PrPool-inspired Oracle | 93.4375% | +1.6250pp | −6.2500pp |

6 个 PrPool 候选中没有一个满足类别安全线，整体增益也低于 +2.5pp。判定
No-Go。

# 裁决

冻结 CLIP patch 上继续更换小头的路线结束。若继续该研究题目，下一核心变化
必须是有限 backbone adaptation，使部件监督改变共享表征，而不是只训练池化头。
若该升级仍不能建立 Oracle 上界，则停止 PartImageNet 方法开发，只保留选择性
部件标注问题与负结果。
