# Style guide

- Language: Chinese body text; English method names only when standard.
- Target reader: technically literate EI-conference reviewer.
- Tone: conservative, scientific-question-driven, evidence-first.
- Terminology: use `semantic part query`, `K0 uniform pooling`, `Full oracle`, `outer OOF`, and `official test locked` consistently.
- Forbidden expressions: 首次、填补空白、显著领先、保证安全、SOTA、革命性、充分证明.
- Supervisor preferences: show negative controls and stopping rules before expected contributions.
- Citation style: author-year in prose; DOI in audit/evidence files.
