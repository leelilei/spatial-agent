# Style guide

- Language: Chinese planning, English paper later.
- Tone: practical, conservative, evidence-led.
- Terms: frozen foundation feature, capacity scaling, task-local nested OOF, DCKS, endpoint selection.
- Forbidden expressions: 首次、填补空白、革命性、SOTA、显著领先（无统计证据时）.
- Reporting rule: always show B, L, and DCKS together; never report only DCKS vs B.
- Citation style: author-year with DOI in evidence/audit files.
