# Scope

- Project: PASAC — Permutation-Aware Sparse Attention Calibration.
- Mode: hybrid. Preserve all completed CUB evidence; create a new method line without rewriting prior No-Go decisions.
- Target: an EI-indexed conference paper, not a top-tier novelty claim.
- Core question: can one keypoint-annotated image per class assign semantic identities to a strong K0 attention model without harming classification?
- In scope: CUB train-only OOF screening, three-episode confirmation, then CCT20+ development validation if gates pass.
- Out of scope now: official CUB test, CCT Cis/Trans, tuning after a failed preregistered screen, absolute “first” claims.
- Primary audience: reviewers familiar with fine-grained recognition, weak supervision, keypoint learning, and privileged information.
