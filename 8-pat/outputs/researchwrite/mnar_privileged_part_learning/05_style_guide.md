# Style guide

- Language: 中文 proposal；英文题目、变量和标准术语保留英文。
- Target reader: 熟悉 FGVC、SSL、LUPI 与 knowledge distillation 的审稿人。
- Tone: scientific-question-driven + conservative。
- Terminology:
  - 使用“非随机缺失的部件特权标注”；
  - 使用“选择性覆盖偏差”而不是笼统“数据偏差”；
  - 使用“预注册范围内的安全迁移”而不是“理论安全”；
  - 区分“部件标注缺失”和“类别标签缺失”。
- Forbidden expressions:
  - 首次提出、填补空白、显著领先、彻底解决；
  - 现有方法都、完全没有研究、保证不退化；
  - 简单地、显而易见、众所周知。
- Supervisor preferences:
  - 先证明问题再设计网络；
  - 实验必须有端到端终点和消融；
  - 失败门槛写在运行之前。
- Citation style: 正文作者—年份；内部材料使用 experiment ID 与绝对路径。
