# SpatialAgent Research Plan v6 — Review 2

> 评审人定位：计算社会科学 + 因果推断方法学背景，熟悉LLM Agent系统与混合效应模型
> 日期：2026-03-16
> 总体评价：**Borderline Accept — 方法学框架已趋成熟，但若干关键假设未经验证，且存在可操作性风险**

## 一、总体印象

v6 是一份方法学上相当成熟的研究计划。Matched-seed 设计、C6-C2 升格为主比较、TAR 双轨实现、以及 run-level / event-level 的严格分层，都显示出作者对前几轮审稿意见的深度吸收。论文主线（核心4条件 + 模块分解 + Exp1C探索性归因）也比 v5 更加清晰。

但在"看上去干净"的框架之下，仍有**五个结构性问题**可能在实际运行或审稿时暴露。以下按严重程度排序。

---

## 二、P0 级问题（可能导致核心结论不成立）

### P0-§1：Matched-Seed 设计的有效性窗口被高估

**问题描述**：

Matched-seed 设计的核心假设是：固定 seed 后，不同条件之间的差异"尽量只来自架构本身"（§6.2.2）。这在 **Round 1** 是成立的——相同的NPC、相同的位置、相同的外部事件。但LLM Agent系统是**高度路径依赖**的：

- Round 1：C4的Agent A决定去高Integration节点，C1的Agent A随机去了另一个节点
- Round 2：由于位置不同，他们遇到了不同的NPC，产生了不同的对话
- Round 3：不同的对话写入了不同的记忆...
- Round N：两个条件的世界状态已经完全分叉

到第50轮时，"matched-seed"提供的方差缩减可能已经微乎其微——两个世界已经是完全不同的模拟实例了。

**这不意味着 matched-seed 没有价值**，但作者需要：

1. **量化seed matching的实际方差缩减**：在pilot中，比较 `Var(C4-C1)_matched` vs `Var(C4-C1)_unmatched`，计算 ICC(seed)。如果 ICC(seed) < 0.1，说明seed matching在200轮run中基本无效，d≥0.74的功效估计就不成立。

2. **区分"初始匹配"与"全程匹配"**：更诚实的说法是 "matched initial conditions" 而非 "matched-seed design"。在论文中声明：seed matching主要控制初始条件差异，不保证全程世界状态的可比性。

3. **考虑"短窗口匹配"策略**：如果分叉太快，可以把200轮切成若干短窗口（如每20轮reset到matched状态），但这会破坏时间动态分析——需要权衡。

**严重性**：如果 ICC(seed) 很低，v6 的统计功效估计（d≥0.74）将过于乐观，实际可检测效应可能回退到 d≥0.9 甚至更高。

### P0-§2：C6 vs C1 的Movement信息不对等

**问题描述**：

v6 的核心分解是：

```
Total = (C4 - C1) = (C4 - C6) + (C6 - C1)
                   = Sampling贡献 + Perception贡献
```

但检查条件矩阵（§5.4.1）：

| 条件 | Movement Policy |
|------|----------------|
| C1 | 邻接 + 地名 + 在场数 |
| C6 | **空间指标** + 邻接 + 地名 + 在场数 |

C6 的 Movement 决策比 C1 **多了空间指标信息**。这意味着 C6 的Agent在选择去哪里时，可以利用Integration等信息倾向于去"结构上更有利"的节点。

那么 `C6 - C1` 测量的不是纯"Perception对行为认知的影响"，而是：

```
C6 - C1 = Perception对行为认知的影响 + Perception对Movement决策的影响
```

如果Agent因为知道哪里Integration高就倾向于去那里，它自然会遇到更多人、产生更多社交——这是**Movement驱动的效应**，不是"到了一个地方后因为知道空间特征而改变行为"的认知效应。

**修复方案**：

需要一个 **C6m (Perception-Only, Matched-Movement)** 条件：
- 对话prompt中包含空间描述（同C6）
- Movement决策**不**使用空间指标（同C1）

这样：
```
C6m - C1 = Perception对到位后行为认知的纯影响
C6 - C6m = Perception对Movement决策的影响
```

或者，如果不愿增加条件数量，**至少利用C7(Fixed-Path)**来做三角验证：
```
C7 - C1(Fixed) = 控制Movement后的纯认知效应
```

但目前C7被定位为"探索性机制条件，仅10-12 seeds"，统计功效不足以支撑核心分解。建议至少把C7的seeds提升到20。

## 三、P1 级问题（削弱结论的可信度或可操作性）

### P1-§1：TAR连续型实现的线性假设未论证

TAR 的主验证实现是：

```
sociality ~ standardized_Integration
privacy ~ standardized_MeanDepth
gatekeeping ~ standardized_Control
```

这假设空间指标与行为之间是**线性关系**。但 Space Syntax 的实证文献中，Integration-行人流量关系经常是**非线性的**（log-linear或阈值型）：

- Hillier et al. (1993) 的原始数据显示 Integration 与行人流量之间更接近 log-linear
- Penn et al. (1998) 发现只有 Integration 排名前 20% 的街段才有显著高于均值的行人流量

在20节点图上，如果只有3-4个高Integration节点"表现不同"，线性回归会被中间大量节点的噪声稀释，导致系数偏小、显著性降低。

**建议**：

1. 在正式分析前，先画 Integration vs sociality 的散点图，视觉检查线性假设
2. 同时拟合线性和 log-linear 模型，比较 AIC
3. 考虑添加二次项或使用 GAM（广义加法模型）作为补充分析
4. 如果关系确实是阈值型的，高/低分组TAR反而可能是更灵敏的检验方式——这时"辅助实现"反而比"主实现"更有功效

### P1-§2：C2描述池的"非空间性"缺乏操作化验证

v6 将 C2 重新定义为 "stable non-spatial affordance baseline"，描述池中的条目如：

- "周围传来嘈杂的争吵声和酒杯碰撞声"
- "空气中弥漫着新鲜面包的香气"

但这些描述**隐含空间信息**：

- "嘈杂的争吵声和酒杯碰撞声" → 酒馆/室内/拥挤 → 隐含高Connectivity或高Integration的空间语义
- "新鲜面包的香气" → 面包店/市场 → 隐含公共空间语义

如果 C2 描述池中某些条目恰好与特定空间特征在语义上相关，那么即使描述与位置的映射是随机的，LLM仍可能从描述中"推断"出空间特征——C2就不再是纯"非空间"基线了。

**修复方案**：

1. **语义空间验证**：用LLM对每条C2描述生成"该地点的Integration/Depth/Control可能是高还是低？"的推断。如果某些描述被系统性地判断为"高Integration"，则这些描述泄露了空间信息，应被替换。
2. **反向推断测试**：给LLM看C2描述，问它"这个地方在空间网络中可能处于什么位置？"如果LLM能从C2描述中推断出空间位置类型，说明C2的非空间性不成立。
3. 在论文方法中报告这一验证步骤的结果。

### P1-§3：Agent记忆的累积效应未纳入理论框架

200+轮模拟中，Agent的记忆不断累积。到后期，Agent的行为可能主要由**记忆驱动**而非**当前空间描述驱动**。例如：

- Agent A在Round 10因为空间描述（高Integration）主动社交 → 记忆写入"我在广场和Elara愉快交谈"
- Round 100时，Agent A可能因为记忆中的正面社交经历继续在广场社交，即使此时移除空间描述也不会改变行为

这意味着：

1. **空间效应可能只在早期几轮真正"独立"起作用**，后期的空间一致行为实际是记忆的惯性延续
2. **时间分段分析**可以检测到这一点（前半程效应 > 后半程效应），但v6没有讨论这种结果模式的理论含义
3. 更关键的是：如果空间效应确实在后期被记忆吸收了，那么run-level汇总（平均200轮）可能**高估了空间描述本身的持续影响力**

**建议**：

1. 在理论框架中明确讨论"空间启动（spatial priming）vs 持续空间引导（sustained spatial guidance）"的区分
2. 报告**前50轮**的空间效应量，作为"空间描述的直接影响力"的更纯净估计
3. 如果前半程效应显著大于后半程：诚实讨论是"空间信息帮助Agent建立了正确的行为模式，之后记忆维持"还是"空间信息的直接影响力有限，仅起到初始启动作用"

### P1-§4：行为编码的信度标准缺失

两阶段分离评估（§7.1）提到"标注者只看行为文本"进行盲编码，但缺少关键的操作化细节：

1. **谁来标注？** LLM自动标注？人类标注者？如果是LLM标注，又引入了LLM同源偏见
2. **标注者人数**？最少需要2人以上才能计算inter-rater reliability
3. **信度标准**？Cohen's κ ≥ 多少才算可接受？行为类型、交互强度、信息敏感度这三个维度的标注难度差异很大
4. **标注指南**（coding manual）的开发流程？是否有pilot标注阶段？

如果行为编码的信度不够高（κ < 0.6），那么后续所有基于编码结果的统计分析都建立在不可靠的基础上。

## 四、P2 级问题（改善论文质量但不影响核心逻辑）

### P2-§1：LLM模型选择缺少讨论

v6 未指定使用哪个LLM模型作为Actor。不同模型的空间推理能力差异巨大：

- GPT-4系列在空间推理任务上表现远优于开源7B模型
- DeepSeek-V3 的空间理解能力与 GPT-4o 可能有显著差异
- 模型的Temperature敏感性也不同

**建议**：

1. 在方法中明确指定Actor模型，并说明选择理由
2. 至少讨论模型选择对结论泛化性的影响
3. 如果资源允许，在阶段1中用2个不同模型运行Exp1A的子集，检查效应方向是否一致

### P2-§2：Exp1C的5场景/cell统计功效存疑

Exp1C的2×2设计中，每个cell只有5个独立场景，scenario作为随机效应：

```
DV ~ topology_level * semantic_label + (1|scenario)
```

5个level的随机效应估计极不稳定。在混合效应模型中，随机效应的组数通常建议≥10-15个才能获得合理的方差估计。5个scenario可能导致：

- 随机效应方差被严重低估（向零收缩）
- 实际上退化为固定效应模型
- 交互项的检验功效非常低

**建议**：

1. 增加每cell的独立场景数到至少10个（如果生成成本不高）
2. 或者将scenario改为固定效应，承认场景间的差异不被视为从总体中随机抽取
3. 在论文中坦诚报告Exp1C的功效限制

### P2-§3：收敛性判据的稳健性

"连续3个窗口（每窗口20轮）内，关键指标变化幅度均<5%"——这个判据有几个问题：

1. **"变化幅度<5%"相对于什么基准？** 绝对值？前一窗口？全程均值？
2. **多个指标同时满足的联合概率？** 如果4个指标独立地各有80%概率满足，联合概率只有41%
3. **假稳态风险**：系统可能在某段暂时稳定后再次变化（如某NPC突然改变策略导致连锁反应）

**建议**：

1. 定义清楚：变化幅度 = |窗口均值 - 前一窗口均值| / 全程标准差
2. 考虑使用更正式的时间序列平稳性检验（如 ADF 检验）
3. 对"假稳态"风险做敏感性分析：在声称达到稳态后继续运行50轮，检查是否保持稳定

### P2-§4：阶段3启动条件过于宽松

§6.3.1 的启动条件是"C4>C1在至少一个主TAR指标上达到显著或稳定中等效应"。"稳定中等效应"没有操作化定义——什么是"稳定"？什么是"中等"？

**建议**：

明确定义：
- 显著 = p < 0.05 (FDR校正后)
- 中等效应 = d ≥ 0.5
- 稳定 = 效应在前半程和后半程方向一致

### P2-§5：保底论文贡献的第4条过度包装

保底贡献第4条"一套 matched-seed 的 LLM Agent 对照实验协议"——matched-seed在LLM Agent实验中并不新颖，Generative Agents (Park et al., 2023) 和 AgentSims 等工作都使用了seed控制。将其作为独立贡献点可能被审稿人质疑。

**建议**：将第4条合并到第2条中，作为实验框架的一部分，而非独立贡献。

## 五、值得肯定的亮点

1. **Matched-seed设计的引入方向正确**：即使P0-§1指出了其有效性窗口问题，这仍然是比v5的无配对设计显著更好的方案。关键是量化其实际效益。

2. **C6-C2升格为主比较**：这是v6最重要的修正。v5中C4-C2的不干净比较终于被正确识别和修复。

3. **TAR双轨实现**：连续型为主、分组为辅的策略既保证了统计严谨性，又保留了可解释性。

4. **主张边界的显式声明**（§2.4）：明确列出"不预先声称"的内容，这在研究计划中非常罕见也非常有价值。

5. **验证性/探索性的严格分层**：表格化呈现，每个分析的性质一目了然。

6. **C2的重新定义**：从模糊的"rich non-spatial"到精确的"stable non-spatial affordance"，语义更准确，也更利于论文写作时的精确讨论。

## 七、一句话总结

> v6在方法学框架上已接近投稿水准，但**matched-seed的有效性窗口**和**C6-C1的Movement信息不对等**是两个必须在实施前解决的结构性问题——前者决定功效估计是否可信，后者决定模块分解的归因是否干净。
