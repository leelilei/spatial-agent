# Four-Framework Adapter Smoke Archive

This directory is the immutable first shared-world smoke run for the verified
GATSim, SOTOPIA, Generative Agents, and AgentSociety decision-layer adapters.

- `run_config.json`: exact run scope, command, timing, and limitations
- `traces.json` / `traces.jsonl`: complete actions, raw model responses,
  provenance, world outcomes, and deterministic scores
- `summary.csv`: scenario-level metrics
- `aggregate.json` / `summary.md`: two-scenario aggregate

Interpretation is archived in
`docs/experiments/cityagency_four_official_frameworks_smoke_2026-06-30.md`.
These results are smoke evidence, not a stable leaderboard.
