# Reference Sources

The curated paper archive lives in:

- `assets/papers/metadata/reference_index.md`
- `assets/papers/pdf/`
- `assets/papers/fulltext/`
- `assets/papers/notes/`

Use `reference_index.md` as the source map for local PDF paths, paper titles, and
official URLs. Project-level strategy notes and decisions should stay in
`docs/project/`; raw PDFs, generated fulltext, and per-paper reading notes should
stay in `assets/papers/`.
