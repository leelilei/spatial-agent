# CityAgency Reference Benchmark Comparison

Date: 2026-06-27

## Purpose And Scope

This document compares the references that most directly shape CityAgency. The comparison asks four
questions for every work:

1. What does the benchmark or evaluation attempt to measure?
2. How is the test constructed and executed?
3. Which metrics determine success?
4. What empirical conclusion does the paper report?

The main table includes formal benchmarks and empirical validation studies. CitySim and GATSim are
marked as evaluated simulation systems rather than benchmark suites, because their experiments still
define important competing claims about human-like urban agents.

changes only the LLM provides model-comparison evidence; one that holds the LLM fixed and changes
the agent design provides stronger architecture-comparison evidence. The final column distinguishes
direct urban evidence from methods that CityAgency can transfer into urban research.

## Cross-Benchmark Reading

The references validate four different objects that should not be conflated:

| Validation object | Representative work | What a passing score proves | What it does not prove |
|---|---|---|---|
| Urban capability answer | CityBench, USTBench | The model can answer or optimize a defined urban task | The agent can live through a continuous city episode |
| Social interaction quality | SOTOPIA, AgentSense | Dialogue plausibly pursues a private social goal | Physical actions and claimed outcomes occurred |
| Mobility realism | MobiSim-Bench, When Plausible Is Not Realistic | Generated populations resemble human mobility under selected statistics | A particular agent maintained and completed its intention |
| Executable outcome | ChinaTravel, tau-bench, AppWorld | A plan or final environment state satisfies explicit predicates | The intermediate urban trace is continuous, credible, and appropriately replanned |

This produces a narrower and defensible CityAgency gap:

> Existing work can test urban reasoning, social goals, empirical mobility distributions, or executable
> final states. CityAgency tests whether an agent can turn a plausible private plan into a continuous,
> environment-valid urban trace whose goal completion is supported by state-changing evidence.

The claim is the combination, not that every component is individually new. In particular, CityAgency
should not claim the first micro-level mobility metric, the first city-agent benchmark, or the first
feasibility benchmark.

## Evaluation Components CityAgency Should Borrow

| CityAgency component | Reference precedent | Proposed CityAgency implementation |
|---|---|---|
| Goal evidence | tau-bench, AppWorld | Deterministic predicates over location, inventory, budget, messages, co-presence, and deadlines |
| Compositional constraints | ChinaTravel | Machine-readable hard constraints and soft preferences attached to each scenario |
| Infeasibility awareness | FeasiGen | Paired feasible/infeasible variants; false continuation, justified stopping, and repair success |
| Private goals and social pressure | SOTOPIA, AgentSense | Hidden goals, relationships, interruptions, and separate social-quality scoring |
| Information boundaries | Misleading Success | Agent observation state separated from authoritative world state |
| Longitudinal memory | Lifelong-SOTOPIA | Linked episodes involving remembered places, promises, and prior disruptions |
| Trace realism | MobiSim-Bench, empirical mobility validation | Continuous edge-valid trajectories first; empirical human-mobility comparison in a later data-backed track |
| Repeated reliability | tau-bench | Repeated trials and an all-runs-success reliability measure rather than one lucky rollout |
| Soft believability | SOTOPIA, GATSim | LLM/human judge used only for plausibility and social quality, never as the sole completion verifier |

## Bottom Line

The most useful comparison is not "Which paper already built CityAgency?" No single reference does.
The useful comparison is which proof obligation each benchmark covers:

- MobiSim-Bench and empirical mobility studies ask whether generated movement resembles human mobility.
- SOTOPIA and AgentSense ask whether agents pursue private social goals convincingly.
- ChinaTravel, tau-bench, and AppWorld ask whether requirements or authoritative states are satisfied.
- CityAgency should join these obligations inside one controlled urban episode and expose where the
  chain breaks: planning, action validity, goal maintenance, replanning, or completion evidence.
