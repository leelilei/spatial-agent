## 0. 北极星与 Claim A

- **北极星**：可信的多智能体**社会模拟**（Generative Agents 谱系）。记忆是杠杆，不是目的。
- **Claim A**：*改进的结构化社交记忆（SMGA）让一个 agent 社会在长程上更**连贯**。*
- 准绳（见 `README.md` Working Principles）：坚持大 claim；发现问题就解决不抛下；不要欠功效的 null。

不做：纯记忆 QA（丢北极星）；成本优化（AGA 做过）。我们要的是**社会连贯性**这条轴。

## 1. 核心概念框架：信息的"交换"层 vs "留存"层（2026-06-18）

一个社会能否保持一致的共享现实，取决于两个**可分离**的层：

| 层 | 现实类比 | 在 GA/sim 里 | 失败的样子 |
|---|---|---|---|
| **交换 / 扩散** (communication) | 短信、电话、面对面交谈 | 谁遇见谁 + 对话 + 听到（`schedule`/`converse`/`observe`，连通度 `meetings_per_round`） | 信息根本没传到（"没听到"） |
| **留存 / 表示** (memory) | 听到后记没记住、记成什么、要用时捞不捞得出 | GA 反思 vs SMGA 登记表（`consolidate`/`retrieve`） | 听到了却**丢了**（遗忘）或**记成旧值**（stale） |

**SMGA 改的是留存层，不是交换层。** GA 与 SMGA 在我们的实验里用**完全相同的交换层**（同一相遇日程、同一对话提示），唯一变量是记忆。

### GA 的交换框架（厘清）

GA（Park 2023, Smallville）没有短信/电话/广播，交换 = **空间共处 + 面对面对话 + 感知**：
1. 每个 agent 一条只增的 **memory stream**（带时间戳的自然语言观察）。
2. **感知**：移动中看到附近的人/物、**听到附近对话** → 写进自己的 stream。
3. **对话**：相遇时各自基于**检索出的记忆**生成台词；说出的话被双方观察（进入各自 stream）。
4. 信息**一跳一跳地通过对话链扩散**（Isabella 情人节派对邀请传遍小镇 = 这个机制的涌现）。
   我们的 sim 是其极简版（无空间地图，但 `meetings_per_round` = 社交网连通度，同构）。

## 2. "current-rate" 度量的意义，以及为什么条件于 receiver

- 访谈"现在 drive 在哪/何时"：**current** = 改后真相（周日/社区中心）；**stale** = 改前旧值；**unknown** = 不知道。
- **current-rate = 一次中心事实变更后，社会里多少 agent 真正持有并能说出最新共享现实**。
- **为什么对 GA**：GA 是可信智能体记忆的**领域标准基线**。在 GA 上提升 current = 指出默认方案的可量化缺陷并证明结构能补，而非又一个 QA 刷分。
- **为什么条件于 receiver（只看"事件流里出现过周日"的 agent）**：这把**交换层固定/扣掉**——"信息有没有传到你"被控制住，于是 current 改善是**纯留存层**的主张，不被扩散噪声污染。

**GA 的失败模式 = 遗忘**：receiver 里 GA 仅 ~25–31% current，~57% unknown——信息传到了，GA 的自由文本反思在 consolidate 时把"周日/社区中心"压缩没了。不是没收到，是**收到后记忆扔了**。

**关键不是"更自信"而是"更对"**：任何结构记忆都可能变得**自信地答错**（我们的 v2：stale 33%）。理想态是 current↑ 且 stale↓。v3 做到了（见 §4）。

## 3. 更深一层：记忆**反作用于**交换（多跳中继耦合）

在 GA 里 **agent 只能把"检索得出"的东西再讲出去**。于是：
- 一个健忘的 agent = **坏掉的中继站**：它把更新忘了，之后跟别人聊就传不出"周日"，只传旧值或空。
- **留存差 → 中继坏 → 正确值在全社会的扩散也跟着烂。** 反之，current 提升不只是"这个 agent 答得对"，而是**让整张传话网持续传播当前正确值**。
- ⇒ **这才是记忆对"社会"而非"个体"的意义。** 也是 Claim A 完整形态：更好的记忆 → 更好的留存与中继 → 整个社会更连贯。

> 诚实边界：我们目前的**固定流回放（C）故意切断了这个耦合**（记忆不反作用于 agent 说什么），以**干净隔离留存层**。耦合（健忘中继污染下游）只在**活体 sim** 里显现——那是下一步、也是 Claim A 真正兑现处。

## 4. 证据链现状（截至 2026-06-18）

1. **诊断 regime（单轮短上下文）排不出架构高下**——强模型当场重推，任何结构创新对准确率是 null。⇒ 必须活体多智能体社会。
2. **活体 5-seed 主结果：raw 指标不支持 Claim A**——current GA 17% vs SMGA-v2 25%（Δ+2/25，95%CI 含 0）；v2 stale 34% >> GA 9%。根因：fact 级 currency 不传播到挂在旧值上的副承诺。
3. **方法论**：sim 混沌随机（temp 0 也无比特复现）⇒ 任何 claim 必须重复+功效。
4. **C 低方差测量台**（`replay_eval.py`，固定事件流回放）+ **receiver-conditioned 指标**（隔离扩散）⇒ 看见真信号。
5. **B 实体中心记忆 v3**（事件登记表单一真相 + 晚绑定 + 确定性 guard 防"顺带提及"冲刷）：
   **跨 5 条独立日志（receiver-conditioned，配对 n=5 logs）**：

   | 条件 | receiver current | stale | per-log current 95%CI |
   |---|---|---|---|
   | GA | 25% | 27% | [11%, 42%] |
   | SMGA v2 | 35% | 33% | [10%, 60%] |
   | **SMGA v3** | **69%** | **15%** | **[51%, 88%]** |

   配对差：**v3−GA +43pp（95%CI [+25,+61]，显著）**；**v3−v2 +35pp（[+11,+58]，显著）**；
   v2−GA +8pp（[−15,+31]，**不显著**）。

   —— 两个核心结论：(i) Claim A 核心首次拿到**有功效、跨日志、统计显著**的正向证据：信息一旦传到，
   v3 把知情 agent 留在当前真相的比例从 GA 的 ~25% 提到 ~69%，同时 stale 最低（不掉进"自信答错"）。
   (ii) **赢在 v3 的实体登记表，不在"结构化"本身**——v2 对 GA 仅 +8pp 不显著。贡献被精确定位到
   "单一真相 + 晚绑定"，而非泛泛的"给模型结构化记忆"。

6. **活体 sim（S5j，记忆×交换耦合，n=3 seed 41-43）**——固定流隔离了"留存"；活体让记忆反作用于行为
   （好中继转发当前值 → 记忆也塑造扩散）。结果**比固定流更强**：

   | 条件 | raw 全社会 current | 中继到达(听到周日) | receiver 内 current |
   |---|---|---|---|
   | GA | 16% | 9.7/25 | 41% |
   | SMGA v2 | 24% | 8.7/25 | 69% |
   | **SMGA v3** | **68%** | **20.3/25** | **84%** |

   配对(n=3)：**v3−GA raw current +52pp（95%CI [+6,+98]，排除0）**；v3−v2 +44pp；v2−GA +8pp(ns)。
   **分解**：v3 同时赢在 (i) **中继**——触达 20.3 vs GA 9.7（健忘 GA = 坏中继；v3 登记表 surface 权威"周日"行→
   v3 agent 主动转发），(ii) **留存**——receiver 内 84% vs 41%。**中继红利是 v3 登记表独有**：v2 中继 −1.0、
   raw +8pp 不显著。⇒ §3"记忆即中继"耦合在活体里被直接证实，且优势(+52pp)>固定流(+43pp)。

诚实边界：单一场景（drive 改期）、mini 模型；固定流显著性跨 schedule seed 但同场景；活体目前 n=3（补 n=5 中）、
CI 偏宽；登记表锚点**含场景特异逻辑**（`_extract_repair_drive_schedule`）。完整 Claim A 需跨场景 + 去场景特异化 + 更大 n。

## 5. 论文一句话（当前形态）

> 在可信多智能体社会里，主流 GA 式自由文本反思对**时效性共享事实是有损的**（收到却遗忘），使社会在一次变更后失去一致现实；一个**显式单一真相 + 晚绑定**的结构化社交记忆在"收到更新"的 agent 上把当前真相保持率从 ~25% 提到 ~67%（且不增加自信错误），并因"记得住的 agent 才是不坏的中继"而提升整个社会的长程连贯。我们提供一个低方差、receiver-conditioned 的社会诊断来量化它。
